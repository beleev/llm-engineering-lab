# Hyper-Connections 与 mHC — 把 1 条残差流加宽成 n 条

[llm_models 目录](../../../README.md) · [交互实验](https://beleev.github.io/llm-engineering-lab/#/models/hyper-connections)

## 直觉

- Pre-LN 的残差主路只有 1 条: `x = x + F(norm(x))`。每一层都是全读全写, 层与层之间的连接强度恒为 1, 模型没有调整它的余地。
- **Hyper-Connections (HC)** 把残差加宽成 `n` 条流, 把 "怎么读" 和 "怎么写" 都变成可学的权重: 宽度连接 `H_pre` 把 n 条流混成这一层的那一个输入, 深度连接 `H_post` 把层输出按不同强度写回 n 条流, `H_res` 决定流之间怎么互相混。
- 麻烦在于: 第 j 层到第 k 层的有效连接是中间每一层 `H_res` 的连乘。不加约束时这个乘积不再是恒等映射, 信号在深度方向上被整体放大或衰减。
- **mHC** 用 Sinkhorn-Knopp 把每个 `H_res` 投到双随机矩阵 (元素非负、每行与每列的和都是 1)。这类矩阵对乘法封闭、谱范数不超过 1, 所以连乘多少层, 复合映射的最大绝对行和还是 1。

## 核心原理

### 一层的三个矩阵

```
x_{l+1} = H_res · x_l + H_post^T · F(H_pre · x_l)         # mHC 式 3
```

`x_l` 是 `[n, D]` 的 n 条残差流。`H_pre` 是 `1×n`, `H_post` 是 `1×n`, `H_res` 是 `n×n`。`F` 是这一层的残差分支; 本库的 block 自带残差主路, 所以代码里取 `block(inp) − inp`。

三个矩阵都按 "静态偏置 + 输入相关项" 参数化 (mHC 式 7):

```
H̃ = α · (RMSNorm(vec(x)) · φ) + b
```

`φ` 初始为 0、`α` 初始 0.01 (mHC 表 5), 所以起步时只有静态偏置 `b` 起作用。HC 论文的初始化是 `H_pre = e_{l mod n}`、`H_post = 1`、`H_res = I`: 第 l 层只读第 l mod n 条流, 输出写回每条流, 流之间不混。

n 条流在最开始数值相同, 而这组偏置满足 "`H_pre` 的各条权重加起来是 1、`H_post` 全是 1、`H_res` 的行和是 1", 所以流的共同值被原样传过去, 整个模型与普通 Pre-LN 残差逐位一致。普通残差就是 `n = 1`、三个值都为 1 的那一格。

### 连乘与 Amax 增益

把式 3 展开, 第 j 层的输出传到第 k 层要先被中间每一层的 `H_res` 乘一遍, 所以有效连接是这些矩阵的乘积。mHC 用乘积的最大绝对行和衡量它偏离恒等多少, 叫 Amax Gain Magnitude: 前向看最大绝对行和, 反向看最大绝对列和。

乘积的增益大致按最大特征值的 L 次方走: 谱半径略大于 1 就指数放大, 略小于 1 就指数衰减、底层的信号传不到顶层。mHC 论文在 27B 上实测不加约束时峰值约 3000, 加约束后约 1.6。

### 双随机投影

```
H_pre  = σ(H̃_pre)                   # 非负
H_post = 2σ(H̃_post)                 # 非负, 限在 (0, 2)
H_res  = Sinkhorn-Knopp(H̃_res)      # 双随机

M = exp(H̃_res)
重复 20 次: M ← 按列归一化, 再按行归一化
```

`H_pre` 与 `H_post` 只要求非负, 论文的理由是防止不同流的信号互相抵消。`H_res` 投到双随机矩阵构成的 Birkhoff 多胞形: 它仍有 `n²` 个自由度可学, 不是退回成固定的单位矩阵, 但乘法封闭保证了连乘的增益不跑掉。

迭代 20 次只是近似。每轮先按列归一化再按行归一化, 收手时行和恰为 1、列和只是上一次归一化的残留, 所以前向增益严格为 1、反向增益只是近似为 1。

mHC 论文没有写静态偏置怎么初始化。本库给 mHC 选了一组不饱和的值: `H_pre` 每条流取 `1/n` (加起来恰为 1), `H_post` 的 logit 取 0 (`2σ(0) = 1`), `H_res` 的 logit 取 `2·I` (投影后偏向单位矩阵)。`σ` 和 Sinkhorn 在饱和处梯度几乎为 0, 偏置取在饱和区的话三个矩阵会一直卡在初值上。

## 运行

论文: Zhu et al., "Hyper-Connections" (ByteDance Seed, arXiv 2409.19606, ICLR 2025); DeepSeek-AI, "mHC: Manifold-Constrained Hyper-Connections" (arXiv 2512.24880, ICML 2026)。DeepSeek-V4 (arXiv 2606.19348) 用 `n_hc = 4` 的 mHC 替换了残差连接, Sinkhorn 迭代 20 次。层代码: `llm_models/layers/core/hyper_connections.py`, 模型代码: `llm_models/models/language_models/hyper_llama.py`。

```bash
python -m llm_models.run_models.language_models.hyper_connections.infer_hyper_connections   # 约 2 s, 不训练
python -m llm_models.run_models.language_models.hyper_connections.train_hyper_connections   # 约 190 s, 3 个模型各 800 步
```

## 与真实系统的差距

- **规模和任务**: 6 层、d_model = 64, 合成的求和任务。HC 论文在 OLMo-1B / OLMo-7B / OLMoE-1B-7B 上训 500B token, mHC 论文在 3B / 9B / 27B 的 MoE 上比较, DeepSeek-V4 是 1.6T 总参数、49B 激活。
- **一层只包一次**: 本库一个 HyperConnection 包一整个 Pre-LN block, block 内部注意力与 FFN 之间仍是普通残差。真实实现把每一处残差连接都换成宽度连接加深度连接, 一层有两个。
- **动态项的参数化**: 统一用 mHC 式 7 的线性形式。HC 论文的动态权重用 tanh 加可学缩放, 两篇的写法不完全相同; HC 的静态版 (SHC) 等价于把 `α` 固定为 0, 本库没有单独的开关。
- **没有算子融合**: n 条流是显式的 `[B, T, n, D]` 张量, 访存和显存按 n 倍算。mHC 用 TileLang 写了融合与混合精度算子, 才把 `n = 4` 的训练时间开销压到 6.7%。
- **参数开销的比例不可外推**: 输入相关项的投影作用在 `n·D` 维的展平向量上, 玩具配置下参数多 12%; HC 论文在 OLMo-1B 上 `n = 4` 只多约 0.03% 参数、约 0.2% FLOPs, 因为真实模型的 D 大得多。
- **读出取均值**: 论文把 n 条流求和, 本库取均值。两者只差一个常数因子、被最后的 RMSNorm 吸收。
- **本库约定**: Pre-LN、weight tying、embedding 乘 √D、N(0, 0.02²) 初始化, 不代表原模型的做法。

## 常见误区

1. **"加宽残差流会让 KV cache 变成 n 倍"**: 注意力只看 `H_pre · x` 这一个输入, K/V 的形状与 n 无关。infer 脚本里 hc 与 mhc 的 KV cache 都是 262,144 个元素, 和普通 LLaMA 相同。变大的是残差处的激活与访存。
2. **"双随机约束就是把 `H_res` 固定成单位矩阵"**: 双随机矩阵有 `n²` 个自由度, 单位矩阵只是其中一点; 本库给 mHC 的起点就带一点流间混合 (对角约 0.71, 非对角约 0.096)。不过 train 脚本实测它在 800 步里只动了 0.0099, 投影之后的梯度确实比不约束时小得多。
3. **"单层的 `H_res` 行和是 1, 信号就不会放大"**: 行和为 1 的矩阵连乘后行和仍是 1, 但这需要元素非负。允许负数时行和可以相消, 绝对值的和反而变大, 这正是 mHC 对 `H_pre`、`H_post` 也要求非负的原因。
4. **"Sinkhorn 迭代完就是严格的双随机矩阵"**: 20 次迭代只是近似。实测行和偏差 1.2e-07、列和偏差 5.6e-05, 因为最后一步是行归一化。前向增益严格为 1, 反向增益只是近似。
5. **"HC 在玩具上学得快, 说明不用加约束"**: 6 层看不出连乘增益的害处, mHC 论文报告的是 27B 上增益峰值约 3000、训练中出现 loss 抬升。玩具规模的排序推不到那个规模。

## 自测题

1. n 条流在初始化时数值相同的话, `H_res` 为什么不必是单位矩阵也能让整个模型与普通 Pre-LN 残差逐位一致?
   **答**: n 条流都等于 x 时, 混合后第 i 条是 `Σ_j H_ij · x = (Σ_j H_ij) · x`, 行和为 1 就恰好还是 x。双随机矩阵的行和就是 1, 所以 mHC 可以用一个偏向单位矩阵但不饱和的起点; `H_pre` 只要各条权重加起来是 1, 层输入就等于流的共同值。
2. 为什么 mHC 只给 `H_res` 加双随机约束, 而 `H_pre` 和 `H_post` 只要求非负?
   **答**: 只有 `H_res` 会在层与层之间连乘, 它决定复合映射偏离恒等多少, 所以需要一个对乘法封闭的集合。`H_pre` 和 `H_post` 各自只在本层用一次, 不参与连乘; 非负是为了防止不同流的信号在加权求和时互相抵消。
3. infer 脚本实测 Sinkhorn 20 次迭代后行和偏差 1.2e-07、列和偏差 5.6e-05。这个不对称意味着什么?
   **答**: 每轮先按列归一化再按行归一化, 收手时行和恰为 1、列和是上一次归一化的残留。所以前向的 Amax 增益 (最大绝对行和) 严格是 1, 反向的 (最大绝对列和) 只是近似为 1; 迭代次数不够时双随机只是近似成立。
