# 语音信号: 波形、Mel 与 codec

## 直觉

本组实验使用一段由 440 Hz 与 880 Hz 双正弦波叠加而成的合成音频 (非真实人声), 完整执行语音前端信号处理流程, 对比量化压缩与加性噪声各自造成的信号损失。输入音频时长 0.5 秒、采样率 8000 Hz, 共含 4000 个采样点; 经分帧与频谱投影后得到 47 帧 × 24 个 Mel 通道的时频表示, 帧移步长为 10 ms, 末帧起始位置为 460 ms, 其中 Mel 通道按人耳非线性频率感知刻度划分频带。
三种实验条件下的波形重建结果如下:
- 线性量化至 ±127 级后解码还原: 重建 SNR 为 45.853 dB。
- 量化级数缩减至 ±7 级: 重建 SNR 降至 19.875 dB。
- 保持 127 级量化并叠加标准差 $\sigma = 0.15$ 的高斯噪声: 重建 SNR 降至 9.213 dB。
SNR (信噪比) 定义为原始信号能量与重建误差能量的分贝比值, 数值越高越接近原信号, 每降低 10 dB 意味着误差能量相对放大 10 倍。语音链路同时承载连续声学特征与时间轴约束, 量化精度、环境噪声与流式缓冲延迟会从不同维度损耗可用信息。

## 核心原理

本实验从合成波形依次执行分帧、Hann 加窗、STFT、24 通道三角 Mel 滤波与对数动态范围压缩, 并精确计算各帧起始时间戳 (帧移 hop 为 80 个采样点, 即 10 ms, 末帧起点为 460 ms)。
前端特征提取共分五步:
1. 分帧: 在 8000 Hz 采样率下, 每隔 80 个采样点 (对应 10 ms) 截取长度为 256 个采样点的局部窗口。
2. 加窗: 对每帧信号乘以 Hann 窗衰减两端幅值, 抑制截断引起的频谱泄漏。
3. 频谱变换: 通过 STFT 计算各帧在不同离散频率上的能量分布。
4. Mel 滤波: 使用 24 个三角形 Mel 滤波器将线性频率能量聚合为符合听觉感知刻度的 24 个频带通道。
5. 对数压缩: 对滤波能量取 log 以压缩动态范围。
长度为 4000 点的波形按窗长 256、步长 80 切分可得到 47 帧, 末帧起始于第 3680 个采样点, 对应音频内 460 ms。
工程实现上还需区分两项物理边界:
- 奈奎斯特采样上限与抗混叠: 8000 Hz 采样率最高仅能无失真表达 4000 Hz 频率分量, 本实验的 Mel 滤波器组上限亦设为 4000 Hz; 降采样前若未做低通滤波, 高频分量会折叠混入低频形成混叠失真。
- 内容时间戳与系统可用时刻: 460 ms 仅代表末帧信号在原始音频中的起点位置, 不等于系统完成特征计算并向用户输出结果的墙钟时刻。

本实验将归一化采样点线性量化至 ±127 级后再解码还原为波形, 实测重建 SNR 为 45.853 dB, 而缩减至 ±7 级量化时重建 SNR 降至 19.875 dB。线性量化将 [-1, 1] 区间内的连续采样值乘以 127 并四舍五入为整数 token, 解码时再除以 127 恢复浮点幅值。舍入操作会引入不超过半个量化步长的截断误差: ±7 级量化的步长为 1/7, 粗糙度超过 ±127 级的 18 倍以上, 导致重建 SNR 下降约 26 dB。
真实神经音频 codec 并非逐采样点直接取整, 而是通过端到端训练的三个模块学习紧凑离散表示:
1. 编码器将局部波形片段压缩为低帧率隐向量。
2. 量化器将连续隐向量映射为离散码本索引 (音频 token)。
3. 解码器由离散 token 序列重建连续时域波形。
实验边界: 本实验实现的是逐点均匀 PCM 量化, 仅作为可解码重建的最小基线, 不构成神经 codec 复现。

语音理解评测需明确区分 ASR、说话人识别与说话人日志 (diarization) 三类不同任务, 并按声学条件分切片报告指标。
三类任务的目标与度量各自独立:
- ASR: 将语音转写为文本, 通过序列编辑对齐统计替换、删除与插入错误占比, 以 WER 或 CER 度量。
- 说话人识别: 判定给定语音片段归属的说话人身份, 即回答「是谁」。
- Diarization: 对多人连续录音切分时间边界并标注各段说话人身份, 即回答「谁在何时说话」, 其中多人同时发声的重叠语音是主要难点。
评测集必须按口音、语种、背景信噪比与采集麦克风信道切分统计, 不能仅依赖纯净单人录音的总体均分掩盖长尾退化。实验边界: 本实验输入为纯合成双频正弦波, 不涉及语音转写与说话人任务。

TTS 与音频生成评测必须多维核查音质与交互时延, 不能将模型输出文本或音频 token 的时刻等同于终端发声时刻。生成质量需分别评估四个正交维度:
- 可懂度: 语音内容能否被准确听清与转写。
- 韵律表现: 停顿节奏、重音与语调起伏是否自然合理。
- 说话人相似度: 合成音色与目标参考声纹的匹配程度。
- 主观自然度: 人工听感评分是否接近真实录音。
边生成边播放的流式交互系统还需拆解记录四项延迟与吞吐指标:
- 首包延迟: 从请求发出到首段可播放音频送达客户端的耗时。
- 实时率: 生成一秒音频所需的实际计算耗时。
- 端点检测延迟: 识别用户话轮结束的响应时间。
- 打断延迟: 用户插话后系统停止当前播报并切换状态的耗时。
模型产出文本 token 或离散音频 token 后, 仍需经历声学解码与播放缓冲区填充, 才能驱动扬声器输出连续声波。

## 怎样验证

固定同一段合成双频信号与同一套分帧及 Mel 提取链路, 采用单变量对照比较波形重建 SNR:
- 噪声对照: 保持 ±127 级量化不变, 叠加标准差 $\sigma = 0.15$ 的高斯白噪声。
- 量化对照: 无额外噪声, 将量化级数从 ±127 级降至 ±7 级。
判定标准: 重建 SNR 应随噪声注入与量化变粗而单调下降, 而总帧数、Mel 通道数与各帧时间戳只取决于信号长度及分帧参数, 必须严格保持不变。实验边界: 本实验不训练 ASR 或 TTS 模型, 话轮打断与快慢响应由仓库内的语音交互状态机独立验证, 两者结合共同覆盖底层信号链与上层交互链。

## 与真实系统的差距

真实数值信号处理，但输入是合成音调，不是语音。没有声纹识别、ASR/TTS 或神经 codec 能力；音频输出必须和说话人授权一起管理。

## 常见误区与自测

模型已经生成音频 token, 能否据此认定终端用户已经听到声音?

<details><summary>展开解析</summary>

不能。离散音频 token 必须经过 codec 解码与播放缓冲才能转化为可听声波, 且量化精度直接影响还原音质 (本实验中 ±7 级量化解码后的重建 SNR 仅为 19.875 dB)。模型输出的离散索引序列到扬声器发声之间隔着两个物理环节:
1. 波形解码: 需由 codec 解码器将离散编号映射回连续时域采样点 (本实验中对应反量化除法), 解码耗时与失真度取决于编解码器结构及量化粒度。
2. 播放缓冲: 连续波形需写入客户端音频缓冲区并累积至起播阈值后才能平滑输出, 避免欠载爆音。
因此, 模型生成首个 token 的时刻、首段音频包送达时刻与终端用户实际听见声音的时刻并不等价, 工程监控中必须分别采集记录。
