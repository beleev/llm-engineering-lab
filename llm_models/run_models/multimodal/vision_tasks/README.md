# 视觉任务: OCR、图表与不确定性

## 直觉

同一个 5×3 的字形 "3", 清晰时像素差 0、前两候选差 2, 读出 "3"; 中间三行被遮住后像素差 5, 2 和 3 的混合字形像素差 2 但前两候选差 0, 两种情况都答 "证据不足"。柱图从像素连通列读出位置 [1, 5, 9]、高度 [3, 6, 4], 最高的是第 2 根。看到图像 token 不代表读对了字, 读对了字也不代表理解了坐标轴, 感知错误和推理错误要分开查。

## 核心原理

demo 从像素算 5×3 字形距离做小词表 OCR: 像素差 ≤ 2 且前两候选差 ≥ 2 才输出标签, 否则 "证据不足"; 柱形图从前景连通列读位置 [1, 5, 9], 再算高度 [3, 6, 4]、数量 3 和左右关系。所有结果来自像素运算, 不是读答案字段。

文档理解要处理文字、布局、表格单元关系和跨页引用; 图表还要认图例、单位、坐标尺度与截断轴, demo 里 "每像素 1 单位" 是显式给出的假设。VQA 要把答案对应到图中可定位的证据, 不能靠语言先验猜中。

计数要分清实例与部件, 空间关系要固定观察视角。评测要包含旋转、裁剪、低分辨率、文字扰动和歧义, 同时报告准确率、拒答覆盖率与置信校准; demo 的距离差只是拒答规则, 不是校准过的正确概率。

## 运行

```bash
python -m llm_models.run_models.multimodal.vision_tasks.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

固定同一套 4 个模板和同一张柱图, 只切换清晰 / 遮挡 / 歧义三种输入, 看 OCR 是正确读出还是合理拒答 (像素差、前两候选差), 柱图读数保持 [3, 6, 4] 不变; 模板 OCR 只认 4 个合成字形, 真实 VLM 还要独立图像集、未见字体和文档版式。

## 与真实系统的差距

已知字体和合成柱图的像素算法，不是通用 VLM 或真实 OCR；距离差只是拒答规则，不是校准后的正确概率。

## 常见误区与自测

图表数值读对, 回答仍可能错在哪里?

<details><summary>展开解析</summary>

错在解释数值的那一步。demo 读出高度 [3, 6, 4] 靠的是 "每像素 1 单位" 这个显式假设; 换成真实图表, 单位、尺度、图例、截断轴和问题约束都决定这个数该怎么用。
