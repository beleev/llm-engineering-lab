# 视觉任务：OCR、图表与不确定性

## 直觉

看到图像 token，不代表已经读对文字或理解坐标轴。任务级检查要把感知错误和推理错误分开。

## 核心原理

本例从像素计算 5×3 字形距离完成小词表 OCR，从柱形图像读取高度、数量和左右位置；遮挡与混合字形检验拒答门限。所有结果来自像素运算，不是读取答案字段。

文档理解需要文字、布局、表格单元关系和跨页引用；图表还要识别图例、单位、坐标尺度与截断轴。VQA 应把答案同图中可定位证据对应，避免靠语言先验猜中。

计数需区分实例与部件，空间关系需固定观察视角。评测包含旋转、裁剪、低分辨率、文字扰动和歧义；同时报告准确率、拒答覆盖率与置信校准。

## 运行

```bash
python -m llm_models.run_models.multimodal.vision_tasks.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

切换遮挡和歧义，检查正确读取与拒答是否合理。模板 OCR 只识别四个合成字形；真实 VLM 还需独立图像集、未见字体和文档版式。

## 与真实系统的差距

已知字体和合成柱图的像素算法，不是通用 VLM 或真实 OCR；距离差只是拒答规则，不是校准后的正确概率。
