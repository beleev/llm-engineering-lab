# 视觉任务: OCR、图表与不确定性

## 直觉

本组实验不依赖神经网络, 仅通过基础像素运算完成两项微型视觉任务, 考察视觉感知何时应当主动拒答。第一项是字符识别: 数字 0 至 3 各对应一个 5×3 像素模板, 输入字形后计算其与各模板的不一致像素数 (像素差) 并取最小值, 同时记录次优候选与最优候选的像素差间隔 (前两候选差)。
对同一个 5×3 字形「3」测试三种输入条件:
- 清晰字形的像素差为 0、前两候选差为 2, 识别输出「3」。
- 遮挡中间三行后像素差升至 5。
- 2 与 3 的混合字形像素差为 2, 但前两候选差为 0。
后两种情形均不满足门限, 系统返回「证据不足」。
第二项是柱状图读取: 从前景像素连通列提取出柱体位置 [1, 5, 9] 与高度 [3, 6, 4], 判定第 2 根柱体最高。
多模态模型通常将图像切块编码为视觉 token 输入主干网络, 但接入视觉 token 不代表文字识别准确, 文字识别准确也不代表正确解析了坐标轴语义, 评估时必须将感知错误与推理错误拆解排查。

## 核心原理

本实验基于 5×3 像素字形距离实现仅含 0、1、2、3 四个字符的小词表 OCR, 仅当最优候选像素差 $\le 2$ 且前两候选差 $\ge 2$ 时输出标签, 否则返回「证据不足」; 柱状图则从前景连通列提取位置 [1, 5, 9], 进而计算高度 [3, 6, 4]、柱体数量 3 与左右相对关系。
两条拒答门限分别约束不同风险:
- 最优像素差 $\le 2$: 保证首位候选与输入字形本身足够接近。
- 前两候选差 $\ge 2$: 保证首位候选显著优于次优候选, 排除边界歧义。
两类典型拒答情形如下:
- 遮挡中间三行后, 输入与模板「2」「3」的像素差均为 5, 两条门限均不满足。
- 2 与 3 的混合字形 (两模板逐像素取均值, 仅第四行存在差异) 与两个模板的像素差均为 2, 虽满足绝对距离门限但前两候选无间隔。
柱状图定义为 10×12 像素矩阵, 至少含一个前景像素的列记为前景列, 连续前景列的起始列索引对应柱体位置, 列内点亮像素数对应柱高。全部读数均由像素阵列直接计算得出, 不读取预设答案字段。

文档与图表理解必须在字符识别之外解析版面结构、表格行列关系、跨页引用及坐标轴元数据, 本实验中「每像素 1 单位」属于显式给定的简化假设。字符识别只是起点: 文档中的同一数字处于表格不同行列、归属不同章节标题或带有跨页引用时, 其业务含义完全不同。
同理, 像素高度为 6 的柱体需结合以下坐标信息才能换算为真实物理量:
- 纵轴刻度步长。
- 物理或业务单位。
- 纵轴是否从 0 起算 (中途截断的纵轴会放大微小差异的视觉比例)。
本实验显式设定每像素对应 1 单位, 因此像素计数直接等于数值读数。
VQA 评测还需验证回答是否锚定于图像中的可定位证据, 防止模型仅凭语言先验猜中答案: 语言先验指模型从文本语料中习得的高频搭配 (例如提问天空颜色时不看图像直接回答蓝色), 此类命中不能证明模型具备真实的视觉感知能力。

视觉计数任务必须区分独立实例与局部部件, 空间关系判断则必须明确参考视角; 视觉评测需同时报告准确率、拒答覆盖率与置信校准, 而本实验的距离差仅为启发式拒答规则而非校准概率。统计车辆数量时不能将单辆车的四个车轮误计为四辆车; 判断杯子位于盘子左侧时必须先固定相机视角或主体视角。
完整评测集应覆盖旋转、裁剪、低分辨率、文字扰动与语义歧义样本, 并联合核查两项核心指标:
- 拒答覆盖率: 模型给出实质回答而非拒答的样本比例, 必须与准确率联合评估, 否则全部拒答即可获得零错误率。
- 置信校准: 模型输出的把握程度与真实准确率的一致性, 例如自称九成把握的样本子集实际正确率也应约为九成。
本实验中的前两候选差只是人工设定的硬门限, 未在验证集上做概率校准, 不能直接解释为预测正确的概率。

## 怎样验证

固定同一组 4 个字符模板与同一张柱状图, 仅切换清晰、遮挡、歧义三种输入条件, 核查 OCR 的识别输出与拒答门限读数 (最优像素差与前两候选差), 并验证柱状图高度读数稳定保持 [3, 6, 4]。
验收判定标准如下:
- 清晰输入必须准确识别为「3」。
- 遮挡与歧义输入必须触发「证据不足」拒答, 不得强行输出低把握标签。
- 三种条件下输入同一张柱状图, 提取高度应恒为 [3, 6, 4]。
实验边界: 模板 OCR 仅覆盖 4 个合成像素字形, 评估真实 VLM 还需引入独立图像测试集、未见字体与复杂文档版式。

## 与真实系统的差距

已知字体和合成柱图的像素算法，不是通用 VLM 或真实 OCR；距离差只是拒答规则，不是校准后的正确概率。

## 常见误区与自测

图表中的柱体高度数值提取正确, 最终回答仍可能错在哪个环节?

<details><summary>展开解析</summary>

可能错在数值语义解释与下游推理环节。图表问答包含两个独立阶段:
1. 感知阶段: 从像素阵列中定位柱体位置并提取像素高度。
2. 推理阶段: 结合坐标元数据将像素读数映射为业务数值并完成题目计算。
本实验直接输出高度 [3, 6, 4], 依赖的是「每像素 1 单位」这一显式假设; 在真实图表中, 单位、刻度尺度、图例映射、截断轴与问题约束共同决定数值含义:
- 刻度与单位换算: 若纵轴每格代表 10 万元, 像素高度为 6 的柱体实际对应 60 万元。
- 截断轴效应: 若纵轴未从零点起算, 柱高 3 与 6 的真实相对差距小于视觉比例。
- 图例绑定: 需依赖图例确认各柱体对应的实体类别。
- 问题约束: 题目可能询问相对增长率而非绝对高度。
上述任一环节解析错误, 即便底层像素读数完全准确, 最终答案依然会出错。

</details>
