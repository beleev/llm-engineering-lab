# 视觉任务: OCR、图表与不确定性

## 直觉

这组实验不用神经网络, 只用像素运算做两件视觉小任务, 看感知 (看清图上有什么) 在什么情况下该停下来。第一件是读字: 数字 0 到 3 各有一个 5×3 像素的模板, 输入一张字形后, 数它和每个模板有几个像素不同 (像素差), 取最少的那个; 前两候选差是第二名比第一名多差几个像素。同一个 5×3 的字形 "3", 清晰时像素差 0、前两候选差 2, 读出 "3"; 中间三行被遮住后像素差 5, 2 和 3 的混合字形像素差 2 但前两候选差 0, 两种情况都答 "证据不足"。第二件是读柱状图: 柱图从像素连通列读出位置 [1, 5, 9]、高度 [3, 6, 4], 最高的是第 2 根。多模态模型会把图像切块编码成图像 token 送进去, 但看到图像 token 不代表读对了字, 读对了字也不代表理解了坐标轴, 感知错误和推理错误要分开查。

## 核心原理

demo 从像素算 5×3 字形距离做小词表 OCR: 像素差 ≤ 2 且前两候选差 ≥ 2 才输出标签, 否则 "证据不足"; 柱形图从前景连通列读位置 [1, 5, 9], 再算高度 [3, 6, 4]、数量 3 和左右关系。OCR (光学字符识别) 在这里只认 0、1、2、3 四个字形, 字形距离就是输入和模板逐像素比较后不相同的个数。两条门限各管一件事: 像素差 ≤ 2 保证第一名本身足够像, 前两候选差 ≥ 2 保证第一名明显比第二名像, 不是险胜。中间三行被遮住后, 字形和 "2"、"3" 都差 5 个像素, 两条都不满足; 2 和 3 的混合字形 (两个模板逐像素取平均, 只有第四行不同) 和两者都差 2 个像素, 第一名够像但没有领先。柱图是一张 10×12 的像素图, 至少有一个像素点亮的列叫前景列, 一段连续前景列的起点就是一根柱子的位置, 那一列点亮的像素个数就是柱高。所有结果来自像素运算, 不是读答案字段。

文档理解要处理文字、布局、表格单元关系和跨页引用; 图表还要认图例、单位、坐标尺度与截断轴, demo 里 "每像素 1 单位" 是显式给出的假设。把字读对只是第一步: 文档里同样一个数字, 放在表格哪一行哪一列、属于哪个标题、是否引用了另一页, 含义都不同。图表也一样, 柱子高 6 个像素, 要知道纵轴每格代表多少、单位是什么、纵轴是不是从 0 开始 (从中间截断的纵轴会把小差别画得很大), 才能换成真实数值。demo 直接假设每像素代表 1 单位, 所以高度读数就是像素个数。VQA 要把答案对应到图中可定位的证据, 不能靠语言先验猜中: VQA (visual question answering) 是看图回答问题, 语言先验是模型从文字里学到的常见搭配, 比如问天空是什么颜色, 不看图也能答蓝色, 这样答对不能说明模型看了图。

计数要分清实例与部件, 空间关系要固定观察视角。数几辆车时, 一辆车的四个轮子不能数成四辆车; 说杯子在盘子左边时, 要先说清是从谁的视角看。评测要包含旋转、裁剪、低分辨率、文字扰动和歧义, 同时报告准确率、拒答覆盖率与置信校准; demo 的距离差只是拒答规则, 不是校准过的正确概率。拒答覆盖率是有多少题给出了回答而不是拒答, 它要和准确率一起看, 否则全部拒答就永远不会答错。置信校准是说模型给出的把握和实际正确率对得上, 比如自称九成把握的那些题真的约九成答对。demo 的前两候选差只是一条手工定的硬门限, 没有在数据上校准过, 不能读成答对的概率。

## 怎样验证

固定同一套 4 个模板和同一张柱图, 只切换清晰 / 遮挡 / 歧义三种输入, 看 OCR 是正确读出还是合理拒答 (像素差、前两候选差), 柱图读数保持 [3, 6, 4] 不变。判定标准是: 清晰输入必须读出 "3", 遮挡和歧义输入应该答 "证据不足" 而不是硬猜; 柱图在三种情形下是同一张, 读数应一直是 [3, 6, 4]。模板 OCR 只认 4 个合成字形, 真实 VLM (vision-language model, 能看图的语言模型) 还要独立图像集、未见字体和文档版式。

## 与真实系统的差距

已知字体和合成柱图的像素算法，不是通用 VLM 或真实 OCR；距离差只是拒答规则，不是校准后的正确概率。

## 常见误区与自测

图表数值读对, 回答仍可能错在哪里?

<details><summary>展开解析</summary>

错在解释数值的那一步。读图表分两步: 先从像素里读出柱子的位置和高度 (感知), 再把这些读数换成题目要的数值并回答问题 (推理)。demo 读出高度 [3, 6, 4] 靠的是 "每像素 1 单位" 这个显式假设; 换成真实图表, 单位、尺度、图例、截断轴和问题约束都决定这个数该怎么用。比如纵轴每格代表 10 万元, 高 6 的柱子就是 60 万元; 纵轴从中间截断时, 柱高 3 和 6 的真实差距没有看上去那么大; 图例说明每根柱子代表什么; 题目问的可能是增长率而不是高度。任何一项理解错, 读数再准, 答案也会错。

</details>
