# 递归记忆与分层读取: 压缩丢了什么

## 直觉

本组实验使用一个 8×8 整数矩阵模拟分块长序列输入: 共 8 个分块, 每块含 8 个取值在 0 至 99 之间的整数 token。针对每个分块分别查询第 0、3、7 号位置的具体数值 (共 24 条精确位置查询), 对比三类长程记忆机制:
- 全量留存 (full): 24/24 查询全部命中, 单次查询需扫描全部 64 个单元。
- 递归均值压缩 (recurrent): 每块压缩为单个均值标量, 查询读取降至 8 个单元, 但命中数为 0/24; 其中第 1 块设为第 0 块的逆序排列, 两块摘要均值完全相同而各位置真值全部不同。
- 分层路由读取 (hierarchical): 先按块 ID 检索块级索引再读取目标分块内部位置, 保持 24/24 命中且将单次查询读取降至 16 个单元, 但因必须同时保留原始序列与块级索引, 持久存储开销增至 72 个单元。
压缩摘要能够建立跨块高层连接, 却未必保留细粒度 token 信息; 架构上的计算图连通性与实际的信息无损保存必须分开验证。

## 核心原理

本实验在 8 个分块共 24 条精确位置问答 (每块查询第 0、3、7 位) 上对比全量、递归压缩与分层路由三类长上下文机制的准确率与读写代价:
- full 模式: 对应标准全量注意力, 常驻保留全部原始 token 并在每次查询时扫描全部 64 个单元, 命中 24/24。
- recurrent 模式: 对应固定状态递归记忆, 处理完每个分块后将其压缩为固定维度的状态 (本例取块内 8 个整数的算术均值) 并丢弃原始 token, 每次查询仅读 8 个单元, 但因标量均值无法还原逐位数值, 命中为 0/24。
- hierarchical 模式: 对应粗细两级分层读取, 先在粗粒度索引层按块 ID 定位目标分块, 再下探读取该块内部元素, 单次查询读取 16 个单元并实现 24/24 命中。
实验边界: 查询读取单元数与持久存储单元数均为实验显式定义的代价账本, 并非硬件实测 FLOPs 或墙钟延迟。

固定维度的压缩状态在数学上无法单射编码任意长度的离散序列, 本实验将第 1 块构造为第 0 块的逆序排列即给出了显式的摘要碰撞反例 (碰撞块均值相同判定为 true)。将块内 8 个元素逆序排列不会改变总和与算术均值, 但第 0 位与第 7 位元素互换、第 3 位变为原第 4 位元素, 导致三条位置查询的真值全部改变。由于两个分块压缩后的隐状态完全一致, 下游无论采用何种解码函数都只能对两块输出同一组预测, 必然至少答错其中一块, 证明有损压缩不可逆。状态压缩保留何种统计量、舍弃何种细节完全取决于学习目标: 均值聚合保留了幅值总量而抹除了排列顺序, 足以回答块级总量问题, 却无法支撑精确位置检索。

分层路由节省的是单次查询的计算读取量而非持久存储空间: 本实验中单次查询读取从 64 降至 16 (先扫描 8 个块级索引定位分块, 再读取目标块内的 8 个元素), 但为保留精确细节仍需常驻全部 64 个原始单元并额外维护 8 个块索引, 持久存储总量反而增至 72。
实验边界: 本实验在查询中直接给出了目标块 ID, 属于零误差理想路由; 真实分层注意力系统的实际收益受四项因素共同制约, 不能仅凭网络结构的理论感受野下结论:
- 路由召回误差: 粗粒度路由一旦选错分块, 底层保留的原始细节即无法进入当前计算。
- 摘要表征容量: 块级摘要向量维度有限, 难以概括块内多主题异构事实。
- KV cache 驻留预算: 原始分块 KV cache 的显存留存与卸载调度存在吞吐折中。
- 跨块多跳推理: 当回答需联合两三块的分散证据时, 仅路由至单个分块不足以覆盖所需上下文。
结构上的理论感受野仅代表信息传递路径存在, 不代表模型能够有效检索并利用远端细节。

## 怎样验证

固定同一组 8×8 整数矩阵与 24 条位置查询, 仅切换 full、recurrent 与 hierarchical 三种读取机制, 联合报告精确命中数、单次查询读取单元数与持久存储单元数。
三项指标必须组合审视以避免片面结论:
- 精确命中数: 度量细粒度位置信息是否得以保留。
- 查询读取单元数: 度量单次推理访问的计算开销。
- 持久存储单元数: 度量记忆结构常驻占用的空间开销。
实验边界: 本实验查询直接给定目标块 ID, 不评测基于语义相似度的近似块检索; 面向真实检索与噪声干扰的有效上下文评测参见 agent-context-engineering 模块。

## 与真实系统的差距

可控数组读写对照，不是 Transformer-XL 或训练过的分层注意力。读取单元是本例算法账本，不是端到端 FLOPs 或 GPU 延迟。

## 常见误区与自测

两个输入序列映射得到相同的压缩摘要, 能否认定它们对所有下游查询的答案都相同?

<details><summary>展开解析</summary>

不能。有损压缩是多对一映射, 会将不同原始序列映射至同一个隐状态: 本实验中第 1 块为第 0 块的逆序排列, 两块均值完全相同, 而 24 条精确位置查询在均值记忆上的命中数为 0。将 8 个离散整数压缩为 1 个均值标量时, 元素总和不变但排列顺序与逐位数值被抹除; 当下游查询第 3 位元素值时, 解码器仅能观测到相同的标量均值, 对两个分块必然输出同一预测, 无法同时答对。摘要一致仅证明摘要所保留的宏观统计量一致, 被压缩丢弃的局部细节与相对顺序仍可能截然不同; 评测长上下文压缩机制时应主动构造摘要碰撞样本, 检验任务所需的细粒度信息是否真正留存。
