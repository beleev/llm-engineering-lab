# 递归记忆与分层读取：压缩丢了什么

## 直觉

摘要能连接前后两段，却不一定能还原原来的细节。结构连通和信息保存需要分别证明。

## 核心原理

对八个块做精确位置问答：全量保留读取所有单元；递归压缩仅保留块均值；分层路径先用块 ID 路由，再读块内位置。

反转一块的顺序不改变均值，但改变细节答案，构成压缩不可逆的反例。固定大小状态无法无损保存任意长的离散输入；选择保留什么取决于任务和学习目标。

分层路径减少本例访问量，却仍存原始块并增加索引。实际分层注意力的路由误差、摘要容量、KV 保留和跨块多跳都影响收益；不能只看理论感受野。

## 与真实系统的差距

可控数组读写对照，不是 Transformer-XL 或训练过的分层注意力。读取单元是本例算法账本，不是端到端 FLOPs 或 GPU 延迟。

## 常见误区与自测

两个序列有相同摘要，可以认为所有问题的答案相同吗？
