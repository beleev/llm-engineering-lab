# 激活引导 — 能读出的方向, 不一定是能改变行为的方向

[llm_models 目录](../../../README.md) · [交互实验](https://beleev.github.io/llm-engineering-lab/#/blocks)

## 直觉

- 激活引导 (activation steering) 不改权重, 只在推理时往某一层的残差流里加一个向量, 让模型的行为朝某个方向偏。
- 引导向量通常是两组对照样本的平均激活之差: ActAdd 只用一对提示 (如 "Love" 和 "Hate"), CAA 对很多对只在目标行为上不同的样本取平均, persona vectors 用对照的系统提示自动抽出 "性格" 方向。
- 机制解释的研究回放 ([可读出, 不等于起作用](../interpretability/README.md)) 讲过: 探针能从激活里读出一个属性, 不代表模型在用它。引导是这件事的另一面: 读得出的方向加进去, 不一定能改变行为。
- 引导有代价: 系数越大, 行为改得越多, 与目标无关的任务也被推得越远。

## 核心原理

### 引导向量和加法

```
d = mean(h_ℓ | 对照组 A) − mean(h_ℓ | 对照组 B)        # 第 ℓ 层残差流, 提示之后各位置的平均
h_ℓ ← h_ℓ + c · d                                     # 推理时加到提示之后的每个位置, c 是引导系数
```

`d` 是两组样本在第 ℓ 层的平均激活之差; `c` 控制强度, 正负决定方向。对照组怎么选决定了 `d` 是什么方向: 两组只差目标属性时, 差出来的才是那个属性。

### 本 demo 的设定

一个 3 层、d_model=48 的小 LLaMA, 在两类合成序列上训练 800 步:

- **情感序列** `[情绪, 话题, 形容词, 名词, 形容词, 名词, ...]`: 情绪 (POS / NEG) 决定形容词从正面词组还是负面词组出 (90%), 话题 (运动 / 食物) 决定名词从哪组出。
- **计数序列** `[NEU, d, d+1, d+2, ...]` (mod 10): 与情绪无关, 用来量副作用。

在第 1 层的输出上取两个方向, 都用 "只差一个属性" 的对照样本 (CAA 的做法): `d_mood` 是 POS 减 NEG (话题相同), `d_topic` 是运动减食物 (情绪相同)。再在一份 **混杂数据** 上训练一个逻辑回归探针: 这份数据里 POS 总配运动、NEG 总配食物, 情绪和话题完全混在一起。

## 运行

```bash
python -m llm_models.run_models.foundation.steering.demo    # 约 12 s, 单线程 CPU, 内部先训练 800 步
```

- 在混杂数据上, 情绪方向、话题方向和逻辑回归探针都能 100% 读出情绪标签。探针的方向更接近话题方向 (余弦 0.20 对 -0.08), 换一份话题与情绪反着配的数据, 它的准确率掉到 0.000: 它读的其实是话题。
- 把向量加进残差流, 只有 `d_mood` 能改情绪: 系数 2 时 NEG 提示后的正面词概率从 0.101 升到 0.690。同样长度的话题方向在系数 4 以内都不改情绪 (最多 0.13), 它改的是名词 (系数 4 时运动名词概率 1.00); 探针方向在系数 4 以内也只到 0.15。
- 系数 1 (正好补上两类均值之差) 时几乎没变化: 只加在提示之后的位置, 最后一层仍能从未被引导的情绪标记那里读到 "NEG"; 连提示位置一起加, 同样系数下升到 0.307。加在哪些位置和加多大一样要调。
- 副作用随系数单调上升: 与情绪无关的计数任务, loss 从 0.181 起, 系数 2 时多 0.484, 系数 8 时多 1.514; 而正面词概率在系数 4 以后只从 0.78 涨到 0.82。
- 这个玩具里一对样本的差已经与 256 对平均的方向很接近 (余弦 0.96 以上), 因为对照样本只差情绪标记和对应的形容词, 其余 token 完全相同。

断言: 混杂数据上 `d_mood` 和 `d_topic` 都能读出情绪 (> 0.99); `d_mood` 系数 4 时正面词概率比不引导高 0.5 以上; `d_topic` 和探针方向在系数 0 到 4 时正面词概率变化都小于 0.1; `d_topic` 系数 4 时运动名词概率高 0.3 以上; 系数到 4 之前行为改变单调增加; 计数任务的 loss 增加随系数严格上升。

## 与真实系统的差距

- **规模和数据**: 3 层、d_model=48、词表 31 的合成任务, 单种子。情绪和话题是植入的两个因素, 真实模型里一个行为往往牵连很多方向。
- **行为的量法**: 用 "下一个形容词落在正面词组的概率" 做教师强制下的读数, 没有做开放生成, 也没有让评审模型打分 (CAA 用 GPT-4 给开放回答打分)。
- **层和位置**: 只在第 1 层输出上加, 没有扫层; CAA 报告 Llama 2 7B 上最有效的层在第 13 层附近。本 demo 里加在哪些位置对结果影响很大 (0.130 对 0.307)。
- **副作用的量法**: 只看一个无关任务的 loss。persona vectors 论文报告系数大时 MMLU 下降; CAA 报告 MMLU 基本不变。不同任务、不同系数下结论不同。
- **persona vectors 的其他用途没实现**: 用投影值在生成前预示行为 (监控)、微调时预防性地加向量、按投影差筛训练数据, 都只在正文里讲。
- **本库约定**: weight tying、embedding 乘 √D、N(0, 0.02²) 初始化。

## 常见误区

1. **"探针准确率 100%, 这个方向就是模型的情绪开关"**: 探针在混杂数据上读到的是话题, 加进去改不了情绪。能改行为的方向要用只差目标属性的对照样本去找, 再用干预验证。
2. **"引导系数取 1 就够了, 正好是两类之差"**: 本 demo 里系数 1 几乎没效果, 系数 2 才有明显变化; 系数、层、位置都要扫。
3. **"引导是免费的, 不改权重就不伤能力"**: 系数越大, 无关的计数任务 loss 涨得越多 (系数 8 时 +1.514), 行为收益却在系数 4 以后趋平。
4. **"两个方向余弦接近 0, 所以加一个不会动另一个"**: `d_mood` 和 `d_topic` 的余弦是 -0.12, 系数小时确实互不影响; 但话题方向加到 8 倍时正面词概率从 0.10 降到 0.05, 探针方向加到 8 倍时升到 0.21。系数大到把激活推离训练时的分布以后, 方向之间会互相牵连。

## 自测题

1. 逻辑回归探针在混杂数据上准确率 1.000, 换一份话题与情绪反着配的数据后变成 0.000。这说明了什么?
   **答**: 混杂数据里话题和情绪完全相关, 探针可以只读话题就拿满分; 反着配的数据把两者拆开以后, 才看出它读的是话题 (它的方向与 d_topic 的余弦 0.20, 与 d_mood 的余弦 -0.08)。读出准确率说明不了读的是哪个因素。
2. 为什么同样长度的 d_topic 加进残差流不改情绪, 却能把名词全改成运动类?
   **答**: 模型用话题方向决定名词从哪组出, 用情绪方向决定形容词; 两者在残差流里是不同的方向 (余弦 -0.12)。d_topic 推动的是模型读来选名词的那部分表示, 所以系数 4 时运动名词概率到 1.00, 正面词概率仍是 0.13。
3. 系数从 4 加到 8, 正面词概率只从 0.78 到 0.82, 计数任务的 loss 增加从 1.156 到 1.514。实际使用时应该怎样选系数?
   **答**: 在目标行为和副作用之间取舍: 同时量目标行为的变化和无关任务 (或通用能力) 上的退化, 选行为已经足够、副作用还能接受的最小系数, 而不是越大越好。
