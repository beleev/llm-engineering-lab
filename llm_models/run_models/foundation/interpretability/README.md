# 机制解释: 可读出, 不等于起作用

## 直觉

这组实验想说明: 从模型内部读得出某个信息, 不等于模型在用它。demo 造了一个最小的「模型」: 4 个样本, 每个样本的激活 (模型中间层算出的数值) 有两个通道, 输出等于第一通道乘 2 加第二通道乘 0, 这组系数叫读出权重, 写成 [2, 0]。demo 里两个通道都和标签完美相关, 线性探针 (从激活猜标签的简单分类器) 在第二通道上准确率 1.0, 但第二通道的读出权重是 0, 它根本不参与输出。把第一通道取反弄坏输出后, 恢复第一通道, 输出误差回到 0.0; 只动第二通道, 误差还是 4.0。能读出来可能只是旁观者, 要说明它参与决策, 得改它再看输出。

## 核心原理

线性探针从表示预测标签, 测的是信息可读出性。表示是模型中间层的激活向量; 探针是另外训练的一个简单分类器, 只看激活能不能猜出标签, 本例用最简单的探针, 直接拿第二通道的正负号去猜, 4 个样本全对, 准确率 1.0。可读出只说明这个信息存在于激活里, 不说明后面的计算用了它。demo 造了两个同样相关的通道, 输出只依赖第一个 (读出权重 [2, 0]); 先破坏第一通道, 再分别干预两个通道, 比较输出恢复了多少: 恢复因果通道误差 0.0, 只改相关通道误差 4.0。具体数字是这样来的: 干净输出是 [-2, 2, -2, 2]; 第一通道取反后输出变成 [2, -2, 2, -2], 每个样本差 4; 把第一通道换回干净值, 输出完全复原, 误差 0.0; 在受损的激活里把第二通道清零, 输出不变, 误差仍是 4.0。

Activation patching 用干净运行的激活替换受损运行的对应位置; causal tracing 扫描位置与层, circuit analysis 进一步检验路径和组件集合。activation patching (激活修补) 要跑两遍模型: 一遍用正常输入 (干净运行), 一遍用被改坏的输入 (受损运行), 然后把干净运行里某一处的激活抄进受损运行, 看输出能恢复多少, 恢复得越多, 这一处对输出越关键。本例恢复第一通道就是一次最小的激活修补。causal tracing (因果追踪) 把这种修补在每个 token 位置、每一层都试一遍, 找出关键位置; circuit analysis (电路分析) 再检查几个组件连成的路径是不是共同完成某个功能。干预分布异常 (off-manifold)、冗余通路和补偿效应都会干扰解释: 抄进去的激活组合可能是模型正常运行时从不出现的, 结果不代表正常行为; 模型可能有两条路算同一件事, 修补一条另一条还在; 改掉一处, 别处可能自动补上, 让这一处看起来不重要。

SAE 用过完备特征重建激活, 目标是重建误差加 L1 稀疏项; decoder 列范数约束为 1, 防止 decoder 放大、encoder 缩小来钻 L1 的空子。SAE (sparse autoencoder, 稀疏自编码器) 想把一个激活向量拆成若干特征的加权和: encoder 把激活变成每个特征的强度, decoder 用这些强度把激活拼回去。过完备是指特征数比激活维度多, demo 用 8 个特征表示 3 维激活。L1 稀疏项是把特征强度取平均再乘 0.025 加进损失, 逼大多数特征保持为 0。如果不约束 decoder, 训练可以把特征强度缩小、把 decoder 里的向量放大, 重建结果不变而 L1 项变小, 这就是钻空子; 每步训练后把每个特征在 decoder 里那一列的长度固定为 1, 就堵住了这条路。demo 实际训练了 3→8→3 的 SAE: MSE 从 0.07831 降到 9e-05, 激活比例 0.2148; 再把最活跃的特征清零, 重建输出平均变化 0.06169。激活比例是所有样本、所有特征里强度不为 0 的比例, 约两成; 训练用的 128 个激活由 5 个稀疏的隐藏来源投影到 3 维得到。

重建误差低不等于特征有稳定语义。重建误差低只说明这些特征拼得回原来的激活, 不说明每个特征对应一个人能理解的概念; demo 的代码注释也写明真实语义未知, SAE 特征不会自动获得名字。还要看代表样本、反例、跨上下文激活和干预效应: 代表样本是这个特征最强时的输入长什么样, 反例是看起来该激活却没激活的输入, 跨上下文是换个语境它还亮不亮, 干预效应是把它清零或放大后输出怎么变, demo 的消融只做了最后这一项。多义特征、特征拆分和不同随机种子都要检验: 一个特征可能同时对应几个不相干的概念, 一个概念也可能被拆成好几个特征, 换个随机种子重训, 得到的特征可能不一样。

## 怎样验证

固定同一个读出权重 [2, 0] 和同一组激活, 先破坏第一通道, 再分别干预两个同样相关的通道 (恢复第一通道、清零第二通道), 比较输出误差 (0.0 对 4.0), 再看 SAE 的重建与稀疏权衡和消融一个特征后的输出变化。判定标准是: 动了一个通道, 输出跟着恢复或改变, 才算它对输出有因果作用; SAE 要同时看重建误差降没降、激活比例够不够低。这里用的是已知小网络做因果校验, 不宣称解释了真实 LLM 的全部机制。

## 与真实系统的差距

线性读出与合成激活。SAE 特征没有自动获得语义名称；注意力图、相关探针或可读 CoT 都不能单独证明模型机制。

## 常见误区与自测

探针准确读出一个属性, 为什么还不能断言模型使用它?

<details><summary>展开解析</summary>

因为可读出只是相关证据。探针准确, 只说明这个属性的信息存在于激活里; 模型后面的计算用不用它, 是另一回事。demo 里两个通道都和标签完全一致, 第二通道探针准确率 1.0, 但输出的读出权重是 [2, 0], 第二通道乘的是 0。所以第一通道被破坏后, 在第二通道上怎么改都修不回输出 (误差 4.0), 只有恢复第一通道误差才回到 0.0。要靠有控制的干预、消融与恢复来检验它对实际输出的作用: 改它, 输出跟着变, 才能说模型用了它。
