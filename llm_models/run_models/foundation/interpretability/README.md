# 机制解释：可读出，不等于起作用

## 直觉

某个激活能预测答案，可能只是旁观者。要说明它参与决策，需要改变它并观察输出是否改变。

## 核心原理

线性探针从表示预测标签，测的是信息可读出性。实验构造两个相关通道，但输出只依赖其中一个；破坏输入后分别恢复通道，比较输出恢复量。

Activation patching 用干净运行的激活替换受损运行对应位置；causal tracing 扫描位置与层，circuit analysis 进一步检验路径和组件集合。干预分布异常、冗余通路和补偿效应都会影响解释。

SAE 用过完备特征重建激活，目标是重建误差加 L1 稀疏项；约束 decoder 列范数防止缩放投机。本例实际训练 SAE，并消融一个活跃特征检查重建变化。

低重建误差不等于特征有稳定语义。需要代表样本、反例、跨上下文激活和干预效应；多义特征、特征拆分及不同随机种子都要检验。

## 怎样验证

先比较两个同样相关的通道在干预后的差别，再看 SAE 的重建与稀疏权衡。这里使用已知小网络做因果校验，不宣称解释真实 LLM 的全部机制。

## 与真实系统的差距

线性读出与合成激活。SAE 特征没有自动获得语义名称；注意力图、相关探针或可读 CoT 都不能单独证明模型机制。
