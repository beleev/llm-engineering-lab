# 机制解释: 可读出, 不等于起作用

## 直觉

能够用探针从模型中间激活里准确读出某项属性, 并不等同于模型在下游决策中实际使用了该属性。本实验构造了一个权重透明的受控双通道微型网络: 共 4 个样本, 每个样本的中间激活包含两个标量通道, 最终输出等于第一通道乘以 2 加上第二通道乘以 0, 即下游读出权重向量为 [2, 0]。实验设定两个通道的数值均与样本标签完全正相关, 因此线性探针 (从中间层激活预测外部标签的浅层分类器) 仅凭第二通道即可取得 1.0 的分类准确率, 但由于第二通道的读出权重为 0, 它对模型输出没有任何贡献。
将第一通道取反以构造受损运行后, 分别对两个通道施加受控干预:
- 将第一通道替换为干净激活值后, 输出误差立即恢复至 0.0。
- 仅改变第二通道 (如将其置零), 输出误差依然停留在 4.0。
高探针准确率揭示的可能只是伴随变化的旁观特征; 要证明某处内部表征真正参与模型决策, 必须对其施加因果干预并观测下游输出的实际响应。

## 核心原理

线性探针衡量的是目标属性在中间层表征中的线性可读出性, 属于相关性证据而非下游因果证据。探针是在冻结的主干网络激活之上独立训练的浅层分类器, 仅检验激活向量是否包含足以区分标签的信息; 本例直接依据第二通道的正负号判定类别, 在全部 4 个样本上取得 1.0 的准确率。然而信息存在于激活中, 并不保证后续网络层读取并利用了该方向。
实验令两个通道与标签具有完全相同的相关性, 但将下游读出权重固定为 [2, 0] 使输出仅依赖第一通道; 破坏第一通道后再分别干预两个通道, 恢复因果通道后误差归零为 0.0, 仅干预相关旁观通道则误差仍为 4.0。
该数值对照的具体推导如下:
- 正常输入下的干净输出序列为 [-2, 2, -2, 2]。
- 将第一通道取反后受损输出翻转至 [2, -2, 2, -2], 每个样本的绝对偏差均为 4。
- 将受损运行的第一通道修补回干净值, 输出序列完全复原, 平均误差降至 0.0。
- 在受损激活上仅将第二通道清零, 由于其读出权重为 0, 输出毫无变化, 平均误差维持在 4.0。

激活修补 (activation patching) 通过将干净运行的局部激活代入受损运行来定位因果关键节点, 因果追踪与电路分析则在此基础上系统扫描时空位置与最小功能子图。
一次标准 activation patching 包含两个对照步骤:
1. 分别前向运行正常输入 (干净运行) 与关键信息被扰动的对照输入 (受损运行), 缓存各层中间激活。
2. 在受损前向传播过程中将指定层与位置的激活覆写为干净运行的对应张量, 测量最终目标输出恢复的比例。
输出恢复越显著, 说明被修补位置对目标行为的因果贡献越关键; 本例恢复第一通道即是一次最小规模的激活修补。causal tracing (因果追踪) 将上述单点修补遍历扫描序列中的每个 token 位置与每个网络层以绘制因果热力图, circuit analysis (电路分析) 则进一步验证由若干注意力头与 MLP 组件构成的子图路径是否协同实现特定算法功能。
解释干预实验结果时还须警惕三类常见混杂效应:
- 分布外伪影 (off-manifold): 跨运行强行拼接的混合激活可能偏离模型自然流形, 诱发异常非线性响应。
- 冗余备份通路: 模型内部可能存在多条并行子路计算同一信息, 单点消融被备份通路掩盖。
- 下游自发补偿: 抹除上游某一组件后, 下游层可能触发抑制解除或补偿机制而低估原组件的作用。

稀疏自编码器 (SAE) 利用过完备隐层将叠加态激活分解为稀疏特征组合, 训练目标联合最小化重建误差与 L1 稀疏惩罚, 并强制约束 decoder 列范数为 1 以防止尺度退化。SAE 由两层线性-非线性映射组成:
- encoder 将输入激活向量投影并经非线性阈值化得到各稀疏特征的激活强度。
- decoder 将稀疏特征强度按对应字典特征方向线性加权还原为重建激活。
过完备是指字典特征数大于原始激活维度, 本例使用 8 个字典特征表征 3 维输入激活; L1 稀疏正则项将特征激活强度的均值乘以系数 0.025 计入总损失, 促使绝大多数特征在单次输入上保持为 0。若不对 decoder 施加约束, 优化器可通过同步缩小 encoder 输出幅值并等比例放大 decoder 列向量模长, 在保持重建输出不变的同时任意压低 L1 惩罚项; 每步更新后将 decoder 每一列的范数归一化为 1, 即可消除这一尺度缩放退化。
本实验在由 5 个稀疏隐变量随机投影生成的 128 条 3 维合成激活上实际训练了「3 维输入、8 维特征、3 维输出」的 SAE:
- 重建 MSE 从初始的 0.07831 降至 9e-05, 全体样本与特征上的非零激活比例收敛至 0.2148 (约两成特征被激活)。
- 进一步将平均激活最强的单个字典特征置零消融后, 重建输出的平均变化量为 0.06169。

SAE 的重建误差极低仅证明过完备字典能够无损拼回原始激活张量, 并不自动保证学出的每个特征维度都对应稳定、单义的人类可理解概念。实验代码注释亦明确指出合成字典特征的真实语义预先未知, 稀疏特征不会因为收敛良好就自动获得可信的概念标签。
确认单个 SAE 特征的机制含义必须联合核查四类证据:
- 高激活代表样本: 触发该特征取最大响应时的典型输入分布。
- 边界反例排查: 表面相似但并未触发该特征激活的近似样本。
- 跨语境一致性: 更换句式、领域或上下文模板后该特征是否仍稳定响应同一底层概念。
- 下游因果干预效应: 将该特征定向清零或钳位放大后模型输出分布的实际偏移 (本例仅演示了其中的置零消融读数)。
此外还须系统检验三类字典学习固有缺陷:
- 多义混合特征: 单个字典维度仍然同时响应多个互不相干的语义概念。
- 特征过度拆分: 同一个连贯概念被分裂至多个细碎字典维度共同承担。
- 随机种子敏感性: 更换初始化种子重新训练后该特征方向是否依然稳定重现。

## 怎样验证

实验固定同一组已知下游读出权重 [2, 0] 与受控中间激活, 按三步顺序执行机制核验:
1. 将第一通道取反以构造输出受损的基线运行。
2. 分别对两个与标签同等相关的激活通道执行受控干预 (将第一通道修补回干净值、将第二通道置零), 对比输出恢复后的平均误差 (0.0 对比 4.0)。
3. 在合成叠加态激活上训练过完备 SAE, 联合记录重建 MSE、非零激活比例以及消融最活跃特征后的重建输出偏移量。
判定标准明确区分相关与因果: 只有对某一表征维度施加受控干预后下游输出随之发生预期恢复或偏移, 才能认定该表征对输出具备因果作用; SAE 质量则须同时考核重建误差下降幅度与特征稀疏度。实验边界在于本例使用结构完全透明的微型合成网络做因果逻辑校验, 不宣称已完整解释真实大规模预训练 LLM 的内部电路。

## 与真实系统的差距

线性读出与合成激活。SAE 特征没有自动获得语义名称；注意力图、相关探针或可读 CoT 都不能单独证明模型机制。

## 常见误区与自测

探针准确读出一个属性, 为什么还不能断言模型使用它?

<details><summary>展开解析</summary>

因为线性探针的高准确率仅构成表征层面的统计相关证据, 不能证明下游网络计算实际读取并依赖了该方向。探针预测准确只说明目标属性的信息被保留在当前层的激活子空间内, 至于后续权重矩阵是否将该子空间投影至最终输出 logits 则是完全独立的问题。
在本例中, 两个激活通道均与样本标签完全一致, 第二通道上的线性探针准确率达到 1.0, 但下游输出层的读出权重为 [2, 0], 作用在第二通道上的系数恒为 0。因此当第一通道受损后, 无论如何干预或清零第二通道都无法修复模型输出 (误差维持在 4.0), 唯有将第一通道修补回干净值才能使输出误差归零为 0.0。要确立内部表征对模型行为的因果作用, 必须结合受控激活修补、定向消融与输出恢复实验加以检验。

</details>
