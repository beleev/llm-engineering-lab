# 机制解释: 可读出, 不等于起作用

## 直觉

demo 里两个通道都和标签完美相关, 线性探针在第二通道上准确率 1.0, 但输出的读出权重是 [2, 0], 它根本不参与。破坏输入后恢复第一通道, 输出误差回到 0.0; 只动第二通道, 误差还是 4.0。能读出来可能只是旁观者, 要说明它参与决策, 得改它再看输出。

## 核心原理

线性探针从表示预测标签, 测的是信息可读出性。demo 造了两个同样相关的通道, 输出只依赖第一个 (读出权重 [2, 0]); 先把输入破坏, 再分别恢复两个通道, 比较输出恢复了多少: 恢复因果通道误差 0.0, 只改相关通道误差 4.0。

Activation patching 用干净运行的激活替换受损运行的对应位置; causal tracing 扫描位置与层, circuit analysis 进一步检验路径和组件集合。干预分布异常 (off-manifold)、冗余通路和补偿效应都会干扰解释。

SAE 用过完备特征重建激活, 目标是重建误差加 L1 稀疏项; decoder 列范数约束为 1, 防止 decoder 放大、encoder 缩小来钻 L1 的空子。demo 实际训练了 3→8→3 的 SAE: MSE 从 0.07831 降到 9e-05, 激活比例 0.2148; 再把最活跃的特征清零, 重建输出平均变化 0.06169。

重建误差低不等于特征有稳定语义。还要看代表样本、反例、跨上下文激活和干预效应; 多义特征、特征拆分和不同随机种子都要检验。

## 怎样验证

固定同一个读出权重 [2, 0] 和同一组激活, 分别恢复两个同样相关的通道, 比较输出误差 (0.0 对 4.0), 再看 SAE 的重建与稀疏权衡和消融一个特征后的输出变化; 这里用的是已知小网络做因果校验, 不宣称解释了真实 LLM 的全部机制。

## 与真实系统的差距

线性读出与合成激活。SAE 特征没有自动获得语义名称；注意力图、相关探针或可读 CoT 都不能单独证明模型机制。

## 常见误区与自测

探针准确读出一个属性, 为什么还不能断言模型使用它?

<details><summary>展开解析</summary>

因为可读出只是相关证据。demo 里第二通道探针准确率 1.0, 恢复它却修不回输出 (误差 4.0), 只有恢复第一通道误差才回到 0.0。要靠有控制的干预、消融与恢复来检验它对实际输出的作用。
