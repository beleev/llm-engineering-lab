# Causal 3D VAE — 视频 DiT 的时空压缩器

因果 3D VAE 的视频路径：

```mermaid
flowchart LR
  A[视频帧] --> B[因果 3D Encoder]
  B --> C[时空 latent 分布]
  C --> D[重参数采样]
  D --> E[因果 3D Decoder]
  E --> F[重建视频]
```


## 直觉

视频 token 数 = T·H·W, 注意力 O(N²) 吃不消, 先用 3D VAE 在时间和空间上一起压缩。
"Causal" = 第 t 帧的编码/解码只依赖 ≤ t 的帧: 第一帧可以单独当图像处理 (图像/视频联合训练), 长视频可以分块流式编解码。

## 核心原理

### 核心公式

- 因果卷积: 时间维只在左侧 pad `k_t − 1` 帧, 输出帧 t 的感受野是 `[t−2, t−1, t]`
- 压缩比: `[B,3,T,H,W] → [B,C,T/2^a,H/2^b,W/2^b]`, token 数 ÷ `2^(a+2b)`
- loss 与图像 VAE 相同: `MSE + kl_weight · KL`

python -m llm_models.run_models.generative.vae3d.infer_vae3d

## 运行后应该看到什么

- `x (1,3,8,16,16) → z (1,4,4,4,4)`: token 数 2048 → 64
- 改 x 的第 6-7 帧 → latent 各帧变化 `[0.000, 0.000, 0.000, 0.055]` (只有最后一帧变)
- 改 z 的第 3 帧 → 输出各帧变化 `[0, 0, 0, 0, 0, 0, 0.044, 0.072]`
- 40 步背一段固定低频视频: recon 0.3380 → 0.0189 (只验证梯度通路)

## 与真实系统的差距

- **没有独立的训练脚本**: 只有 `infer_vae3d`, 末尾顺带在一段固定视频上训 40 步, 用来检查梯度通路。
- **规模**: `base_channels=8`, 输入 8 帧 16×16, 时间 ÷2、空间 ÷4。
- **首帧没有特殊处理**: 第一帧和其他帧一起做时间下采样。"首帧单独当图像" 是因果性允许的用法, 本库没有实现这条分支。
- **帧数要整除**: 帧数不是 `2^time_levels` 的整数倍时, 重建的帧数和输入对不上 (`time_levels=1` 时 9 帧进, 10 帧出)。
- **没有分块编解码**: 整段视频一次前向。长视频要用的流式缓存和分块拼接都没有。
- **loss 只有 MSE + KL**: 没有感知 loss 和对抗 loss。每级只有一个因果卷积块, 没有残差块和注意力。

## 常见误区

- "卷积因果了, 整个网络就因果了": 不够。GroupNorm 直接作用在 5D 张量上时, 均值/方差跨全部帧统计, 未来帧经统计量泄漏 (实测过去帧输出变化 0.4+); 本实现把 T 并进 batch 逐帧归一化。出口卷积若用对称 `padding=1` 也会偷看 t+1。
- "时间下采样 2× 后 latent 第 i 帧只对应原始第 2i 帧": 它覆盖的是一段因果窗口 (≤ 2i 的若干帧)。
- 上采样用 nearest (第 i 帧 → 第 2i、2i+1 帧) 是因果的; 线性插值会用到 i+1 帧。

## 自测题

1. `F.pad(x, (0,0,0,0,2,0))` 补的是哪一维的哪一侧? —— F.pad 从最后一维往前数: W、H 不补, T 维左侧 (过去) 补 2 帧。
2. `spatial_levels=2, time_levels=1` 的 token 压缩比? —— 2^(1+2·2) = 32 (2048 → 64)。
3. 怎样用一个 assert 检验因果性? —— 只改第 t 帧之后的输入, 断言 t 之前的输出逐元素完全不变 (== 0, 不是 "很小")。
