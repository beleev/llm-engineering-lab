# 媒体生成：一致性、水印与来源

## 直觉

单帧漂亮不代表视频连贯；检测到水印，也不代表画面内容真实。

## 核心原理

生成任务分开检查提示遵循、局部编辑保持、身份一致、运动连续与镜头控制。相机移动和物体移动会混淆，需在固定背景/相机轨迹的对照里测运动。

本例实际生成八帧移动矩形并统计外观漂移，嵌入弱扰动水印再计算相关；使用 HMAC 记录内容摘要并检查篡改。简化水印依赖干净参考，不能外推为鲁棒检测。

图像编辑可用掩码、条件控制或反演，评估目标区域变化与非目标区域保持。音画同步需对齐事件时间或嘴形，不是两条流长度相等；音频 token→codec→波形路径见音频实验。

水印表示某种可检测信号，签名来源链证明某个身份对记录负责，深伪检测是可能跨域失效的分类器。三者都不能独立证明事实为真；来源缺失也不等于造假。

## 运行

```bash
python -m llm_models.run_models.generative.media_evaluation.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

分别修改身份属性与字节内容，检查时序指标和签名验证反应。公开教学密钥不能保护真实来源；完整内容凭证还需要身份、密钥管理和编辑链。

## 与真实系统的差距

合成短片与公开演示密钥，不是安全水印、C2PA 实现或通用深伪检测器；签名验证的是完整性与密钥持有者，不证明内容真实。
