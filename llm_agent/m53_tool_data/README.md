# 工具学习: 从候选调用到训练数据

## 直觉

工具学习数据用于训练模型掌握「什么时候该调用工具」的决策边界, 每条轨迹记录调用插入位置、工具名称、输入参数与返回观察结果。本组实验设置单一加法工具与两类任务: 算术题要求计算 a+b, 复述题要求原样输出 a; 每类各 60 题, 其中 40 题用于构造训练样本, 20 题作为独立留出集验收。
对比三种候选调用收录规则在 40 道留出题上的表现:
- 无过滤全量收录: 凡执行成功的调用一律保留, 习得策略在留出集全部 40 题上均调用加法工具, 导致复述题被误答为 a+b, 仅答对 20 题。
- 似然收益过滤: 仅保留插入工具结果后正确答案对数概率上升的调用, 习得策略仅在 20 道算术题上触发调用, 40 题全部答对。
- 过高成本阈值: 将似然收益收录门槛提高至 6 后, 算术题收益亦无法过线, 留出集触发 0 次调用, 仅靠无工具直答做对 20 道复述题。
工具执行成功并不代表该次调用值得写入训练集; 数据筛选必须量化调用对后续预测的实际增益, 并与调用成本综合权衡。

## 核心原理

Toolformer (2023) 通过自监督似然过滤自动构造工具调用训练数据, 无需人工逐条标注调用位置。其核心数据合成流水线包含四步:
1. 候选采样: 由语言模型在文本序列中提议潜在的工具调用插入位置与参数。
2. 工具执行: 实际运行外部工具获取返回结果。
3. 损失比对: 对比插入工具返回结果前后, 后续目标 token 的条件交叉熵损失变化。
4. 阈值筛选: 仅保留能使后续预测损失显著下降的调用样本。
安全边界上, 工具返回内容必须以只读外部观察角色封装注入上下文, 严禁混同为用户指令或系统级权限授权。

本实验真实执行加法工具, 并使用显式定义的读出概率替身 (在 200 个候选答案中赋予正确答案的概率) 替代神经网络语言模型, 以精确刻画过滤机制:
- 无工具基线分布: 算术题赋予正确答案概率 0.005, 复述题赋予正确答案概率 0.9。
- 插入工具结果后分布: 若工具返回值等于目标真值则赋予概率 0.9, 否则正确答案仅分得剩余概率 0.1/199。
定义单样本似然收益为 $\log p_{\text{有工具}} - \log p_{\text{无工具}}$, 用于度量注入工具观察后目标答案条件概率的对数提升倍数, 大于 0 代表调用提升了预测准确度:
- 算术题似然收益为 $\log(0.9/0.005)$, 约为 5.19。
- 复述题因加法工具返回 a+b 而非目标值 a, 似然收益约为 -7.49。
随后基于 80 道训练题的收录标签统计两类题型各自的经验调用率作为习得策略, 并在 40 道留出题上评估端到端准确率。实验边界: 本实验采用解析概率替身与确定性筛选规则, 未对参数化语言模型执行梯度训练。

筛选阈值直接决定工具调用策略的召回与误触发平衡, 过低会引入有害调用, 过高则会抑制必要调用:
- 阈值过低 (全量收录): 复述题上的负收益加法调用混入训练集, 诱导策略在复述题上盲目调用工具并输出 a+b 导致答错。
- 阈值过高 (门槛设为 6): 用于折算单次调用的延迟与权限开销, 但算术题似然收益 $\log(0.9/0.005) \approx 5.19$ 低于 6, 导致全部正收益调用被清空, 留出集调用次数降至 0。
生产级工具学习数据管线还需配套四项工程治理:
- 轨迹去重: 避免高频相似模板主导策略分布。
- 防止答案泄漏: 严查目标真值经提示词或异常字段提前混入前缀上下文。
- 完整记录元数据: 留存工具版本号、超时状态与异常返回样本。
- 精确配置 SFT loss mask: 屏蔽工具返回的外部观察片段梯度, 仅对模型生成的调用动作与最终回答计算监督损失。

## 怎样验证

固定同一批任务数据集 (算术题与复述题各含 40 道训练题与 20 道留出题) 及同一加法工具, 仅切换三种数据筛选策略:
- no-filter: 执行成功的候选调用全部收录。
- loss-filter: 仅收录似然收益大于 0 的调用。
- cost-aware: 仅收录似然收益大于 6 的调用。
统一比较各策略在 40 道留出题上的工具调用次数与最终答对题数。实验边界: 真实 Toolformer 系统中的自回归候选位置采样、大规模语言模型条件似然重打分与全参数再训练开销均未包含在本最小实验内。

## 与真实系统的差距

Toolformer 数据构造机制的最小对照。工具输出按观察而不是用户指令插入; 真实场景还要隔离执行、去重, 并计入延迟与权限成本。

## 常见误区与自测

只要外部工具调用执行成功且无报错, 就应当将该条调用轨迹加入训练集吗?

<details><summary>展开解析</summary>

不应当。工具执行成功仅证明外部函数调用未发生运行时错误且按定义返回了计算结果, 属于执行层事实, 并不证明该观察结果有助于模型预测下游正确答案。本实验中复述题的加法调用全部正常返回 a+b, 但任务要求原样复述 a, 注入工具输出反而使目标答案似然大幅下降; 若无差别收录进训练集, 习得策略会在复述题上错误发起调用, 导致留出集准确率降至 20/40。数据筛选必须综合评估后续预测似然收益、任务目标一致性以及权限与延迟资源成本。
