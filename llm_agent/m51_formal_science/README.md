# 形式证明与科学假设：三种正确

## 直觉

一个数算对了、一个命题证出来了、一条现实规律成立了，依赖的是不同证据。

## 核心原理

最小证明内核只接受假设和 modus ponens：已有 P 与 P→Q 才能推出 Q。每条引用必须指向更早的合法证明，拒绝未来引用和负索引，不能把自然语言“显然”当证据。

完整 theorem prover 闭环由模型提出 tactic，证明器更新 goal，失败返回错误，最终由可信 kernel 验证。Lean 等系统还要审计公理和未完成占位；形式正确仅相对于定义、公理与形式化命题。

科学实验路径是提出假设→拟合参数→给出可区分预测→在独立数据或实验上验证。训练集上高阶多项式更准可能只是过拟合噪声；本例用隐藏点验证线性与二次假设。

模拟器验证只支持其建模假设；真实科学还需要量纲、误差条、测量偏差、可重复实验与对照。把观测规律写进模拟器，再宣布模型发现规律，是循环论证。

## 怎样验证

伪造证明必须被拒；拟合误差与留出误差分别显示。本例是命题逻辑和合成数值实验，不冒充数学竞赛解题器或真实科研发现。

## 与真实系统的差距

有限命题逻辑内核与合成测量，不是通用定理证明器或科学发现系统。证明只相对于假设成立，现实假设仍需实验检验。

## 常见误区与自测

形式证明通过，能直接说明现实科学假设正确吗？
