# 形式证明与科学假设: 三种正确

## 直觉

引用写成 (0, 0) 的伪造证书, 最后一行同样是 Q, 内核逐步核对引用后拒绝; 引用 (0, 1) 的证书通过。三点测量里有一处异常, 二次式把训练 MSE 拟到 0.0, 在独立模拟器的 4 个留出点上 MSE 3.06; 线性假设训练 MSE 0.14222, 留出 0.07111。算对一个数、证出一个命题、发现一条现实规律, 靠的是三种不同的证据。

## 核心原理

最小证明内核只接受假设和 modus ponens: 已有 P 与 P→Q 才能推出 Q。每条引用必须指向更早的合法步骤, 未来引用和负索引都被拒; demo 里 (0, 0) 这条把 P 当成 P→Q 用, 证书不通过, 自然语言的 "显然" 不算证据。

完整的 theorem prover 闭环是: 模型提 tactic, 证明器更新 goal, 失败返回错误, 最后由可信 kernel 验证。Lean 等系统还要审计公理和未完成的占位; 形式正确只相对于定义、公理与形式化后的命题成立。

科学实验的路径是提出假设 → 拟合参数 → 给出可区分的预测 → 在独立数据或实验上验证。训练集上更准的高阶多项式可能只是拟了噪声: 二次式训练 MSE 0.0, 留出 MSE 3.06; 线性假设训练 0.14222, 留出 0.07111。demo 用隐藏点验证线性与二次两个假设。

模拟器验证只支持模拟器自己的建模假设; 真实科学还要量纲、误差条、测量偏差、可重复实验与对照。把观测到的规律写进模拟器, 再宣布模型发现了规律, 是循环论证。

## 怎样验证

固定同一组假设 (P, P→Q) 和同一份三点测量, 分别换证书引用 ((0, 0) 还是 (0, 1)) 和拟合阶数 (1 还是 2), 以证书是否通过、拟合 MSE 和独立模拟器 MSE 判定; 伪造证明必须被拒, 本例是命题逻辑和合成数值实验, 不冒充数学竞赛解题器或真实科研发现。

## 与真实系统的差距

有限的命题逻辑内核和合成测量, 不是通用定理证明器或科学发现系统。证明只相对于假设成立, 现实假设仍要实验检验。

## 常见误区与自测

形式证明通过, 能直接说明现实科学假设正确吗?

<details><summary>展开解析</summary>

不能。证明只保证结论在形式系统和公理下成立; 现实系统满不满足这些假设要靠独立观测, demo 里训练 MSE 0.0 的二次式在留出点上 MSE 3.06 就是例子。
