# 形式证明与科学假设: 三种正确

## 直觉

这组实验区分三种「正确」: 算对一个数、证出一个命题、发现一条现实规律, 各要各的证据。形式证明是把证明写成一串步骤, 每步写明用了哪条推理规则、引用了前面哪几步; 检查器 (也叫证明内核) 是一个规则写死的小程序, 逐步核对这些引用。demo 里两份证书 (候选交上来的证明步骤) 最后一行都是要证的命题 Q, 引用写成 (0, 0) 的那份被内核拒绝, 引用 (0, 1) 的通过, 光看最后一行分不出真假。
科学那一半用三个测量点找规律, 其中一处有异常:
- 二次式把训练 MSE (预测与实测之差的平方的平均) 拟到 0.0, 在独立模拟器的 4 个留出点 (拟合时没用过的点) 上 MSE 3.06。
- 线性假设训练 MSE 0.14222, 留出 0.07111。

## 核心原理

最小证明内核只认两条规则:
- 直接写下题目给的假设。
- modus ponens (假言推理), 已经有 $P$, 又有 $P\to Q$ (如果 P 那么 Q), 就可以写下 $Q$。
demo 的假设是 $P$ 和 $P\to Q$, 证书有三步:
- 第 0 步写 $P$。
- 第 1 步写 $P\to Q$。
- 第 2 步用 modus ponens 推出 $Q$, 并写明引用哪一步当前提、哪一步当蕴含式。
内核要求每条引用都指向更早的、已经核对过的步骤, 引用未来的步骤或负数编号直接拒绝。
两份证书的差别只在引用:
- 引用 (0, 1) 时前提是 $P$、蕴含式是 $P\to Q$, 规则成立, 证书通过。
- 引用 (0, 0) 时把第 0 步的 $P$ 同时当前提和蕴含式用, 而 $P$ 并不是 $P\to Q$, 证书不通过。
自然语言里的 "显然" 不算证据, 内核只认能逐步核对的引用。

真实的定理证明器 (theorem prover) 是一个闭环:
1. 模型提出一步 tactic (一条证明指令)。
2. 证明器执行它并更新还剩下要证的目标 goal, 失败就返回错误让模型重来。
3. 全部目标证完后再由可信的 kernel (规则最少、最容易审查的那部分核对代码) 核一遍。
Lean 这类系统还要审计证明用了哪些公理, 以及有没有留下未完成的占位 (先跳过不证的地方)。形式正确只相对于定义、公理和形式化之后的命题成立: 如果把自然语言的命题翻译成形式命题时译错了, 证得再严, 证的也是另一件事。

科学假设的检验分四步:
1. 提出假设。
2. 用数据拟合参数。
3. 给出能区分不同假设的预测。
4. 在独立的数据或实验上验证。
demo 的三个测量点在 x = -1、0、1, 真实规律是 $y=2x+0.5$, 但 x = 0 那个点多了 0.8 的测量异常。两个假设的表现:
- 二次式有三个参数, 能精确穿过三个点, 训练 MSE 是 0.0, 可它把异常也当成了规律, 在 x = -2、-0.5、0.5、2 这 4 个留出点上 MSE 3.06。
- 线性假设只有两个参数, 穿不过三个点, 训练 MSE 0.14222, 但它没有去迁就异常点, 留出 MSE 0.07111。
训练集上更准的高阶多项式可能只是拟了噪声; demo 用这些隐藏的留出点验证线性和二次两个假设, 选假设看留出误差, 不看拟合误差。

模拟器验证只能支持模拟器自己的建模假设。demo 的独立模拟器就是公式 $y=2x+0.5$, 留出点的标准答案由它算出; 线性假设在它上面误差小, 说明假设和这个模拟器一致, 不说明现实世界就是这样。真实科学还需要量纲 (单位对不对得上)、误差条、测量偏差、可重复的实验和对照组。把观测到的规律写进模拟器, 再用这个模拟器宣布模型发现了规律, 是循环论证。

## 怎样验证

固定同一组假设 ($P$ 和 $P\to Q$) 和同一份三点测量, 分两部分换条件:
- 证明部分只换证书的引用, (0, 0) 还是 (0, 1)。
- 科学部分只换拟合阶数, 1 次直线还是 2 次曲线。
判定看三个读数: 证书是否通过、训练集上的拟合 MSE、独立模拟器留出点上的 MSE; 伪造证明必须被拒。本例是命题逻辑和合成数值实验, 不冒充数学竞赛解题器或真实的科研发现。

## 与真实系统的差距

有限的命题逻辑内核和合成测量, 不是通用定理证明器或科学发现系统。证明只相对于假设成立, 现实假设仍要实验检验。

## 常见误区与自测

形式证明通过, 能直接说明现实科学假设正确吗?

<details><summary>展开解析</summary>

不能。形式证明只保证一件事, 在给定的定义和公理下, 结论确实推得出来; 现实系统满不满足这些假设, 证明本身管不了, 要靠独立的观测和实验。demo 的科学部分就是例子: 二次式在训练数据上 MSE 0.0, 看起来完美, 拿到没用过的留出点上 MSE 3.06, 比线性假设的 0.07111 差得多。
