# 形式证明与科学假设: 三种正确

## 直觉

本实验严格区分数值计算正确、形式命题得证与经验科学规律成立三类不同性质的「正确」, 展示各自所需的独立验证准则。在形式证明部分, 候选证明被表示为显式步骤序列 (证明证书), 每步声明所调用的推理规则及引用的前序步骤编号, 由规则最小化的可信证明内核逐步机械核验: 实验构造的两份证书末行结论均为目标命题 Q, 其中引用编号写为 (0, 0) 的伪造证书被内核当场拒绝, 引用 (0, 1) 的合法证书顺利通过, 说明仅核对末行结论完全无法识别跳步或循环引用。
在经验科学建模部分, 实验基于包含一处测量异常的 3 个采样点拟合函数规律:
- 二次多项式将训练集 MSE 精确拟合至 0.0, 但在独立模拟器生成的 4 个未见留出点上 MSE 升至 3.06。
- 线性假设的训练集 MSE 为 0.14222, 而在独立留出点上的 MSE 仅为 0.07111。

## 核心原理

最小证明内核仅信任显式公理前提与确定性推理规则, 逐步核验每条引用的前序合法性而不采信任何自然语言断言。本例内核仅内置两条许可规则:
- 假设引入: 直接声明题目给定的已知前提。
- modus ponens (假言推理): 若前序步骤中已分别证出命题 $P$ 与蕴含式 $P\to Q$, 则允许推导得出结论 $Q$。
实验给定前提集合为 $P$ 与 $P\to Q$, 待检证明证书包含 3 个编号步骤:
- 第 0 步引入已知前提 $P$。
- 第 1 步引入已知前提 $P\to Q$。
- 第 2 步调用 modus ponens 推导目标 $Q$, 并显式提供前提步骤索引与蕴含式步骤索引。
内核强制校验所有引用索引必须严格小于当前步骤编号且为非负整数, 任何指向自身、未来步骤或负数索引的引用一律拒绝。
两份测试证书的差异完全体现在第 2 步的引用对:
- 合法证书引用 (0, 1), 对应前提 $P$ 与蕴含式 $P\to Q$, 满足假言推理结构, 核验通过。
- 伪造证书引用 (0, 0), 企图将第 0 步的 $P$ 同时充当前提与蕴含式, 因类型结构失配被内核直接拒绝。
自然语言推导中常见的「显然成立」不构成形式证据, 内核只接受可机械回溯的步骤引用链。

现代交互式定理证明器 (如 Lean) 通过策略提议与最小可信内核复核分离的闭环架构保障演绎严密性:
1. 语言模型根据当前证明状态提出下一步策略指令 tactic。
2. 证明引擎执行该 tactic 并将当前目标拆解更新为剩余待证子目标 goal, 若指令类型不匹配或超时则立即返回错误反馈供模型重搜。
3. 当全部待证 goal 清空后, 完整证明项仍须交由代码体量极小、便于人工形式审查的底层核心检查器 kernel 独立重验一遍。
工程审计中还必须核查证明项实际依赖了哪些底层公理, 以及源码中是否残留未完成的跳步占位符 (例如强制跳过证明的占位标记)。更关键的边界在于形式证明的正确性仅相对于所给定的定义、公理及形式化命题陈述成立: 若将自然语言数学问题翻译为形式化定理陈述时本身发生了语义曲解, 即便底层 kernel 核验通过, 所证出的也只是偏离原意的另一个命题。

经验科学假设的评估必须以未参与参数拟合的独立留出数据为准, 训练集拟合误差更低的高自由度模型可能只是吸收了测量噪声。科学建模与证伪遵循四步规范流程:
1. 明确提出待检验的候选数学假设族。
2. 利用有限观测样本拟合模型参数。
3. 导出能够区分竞争假设的可检验外推预测。
4. 在独立留出样本或新受控实验上核验预测误差。
本例观测集在 $x$ 取 -1、0、1 三处采样, 底层真实生成规律为 $y=2x+0.5$, 但在 $x$ 为 0 处混入了幅值为 0.8 的单点测量异常。两类候选假设的对比表现如下:
- 二次多项式拥有 3 个自由参数, 能够精确插值穿过全部 3 个训练采样点使训练 MSE 达到 0.0, 但也将单点异常完全固化进二次曲率中, 导致在 $x$ 取 -2、-0.5、0.5、2 共 4 个独立留出点上的 MSE 高达 3.06。
- 线性假设仅有 2 个自由参数, 无法同时迁就异常点, 训练 MSE 为 0.14222, 但准确恢复了主干线性趋势, 在 4 个留出点上的 MSE 仅为 0.07111。
因此科学模型选择必须以独立留出验证误差为准绳, 不能凭训练集插值误差做裁剪。

基于计算模拟器的验证只能证明候选模型与模拟器内置假设一致, 不能直接替代真实物理世界的实验证伪。本例中的独立留出评估器本质上仍是解析公式 $y=2x+0.5$, 留出点的基准真值直接由该方程生成; 线性假设在留出集上误差极低, 仅证明其准确还原了该合成模拟器的生成规则, 并不自动代表真实自然系统遵循同一定律。真实的科学发现工程还必须核验物理量纲一致性、测量不确定度误差棒、传感器系统性偏差, 并通过可重复的受控物理实验与基线对照组加以检验。若先将某条经验公式写入仿真器, 再凭模型在该仿真器上的高分宣称发现了新物理规律, 在逻辑上属于典型的循环论证。

## 怎样验证

实验固定同一组逻辑前提 ($P$ 与 $P\to Q$) 及同一份含单点异常的 3 点观测数据, 分为两个正交子实验切换受控条件:
- 形式证明部分仅切换证书第 2 步的步骤引用对, 对比非法引用 (0, 0) 与合法引用 (0, 1)。
- 科学建模部分仅切换多项式拟合阶数, 对比 1 阶线性模型与 2 阶二次曲线模型。
验收联合核查三项读数: 证明内核核验是否通过、训练集拟合 MSE、独立模拟器留出集 MSE, 并断言伪造证明证书必须被内核拒绝。实验边界在于本例仅为最小命题逻辑内核与一维合成数值回归演示, 不等同于完整数学竞赛自动解题器或真实自然科学发现流程。

## 与真实系统的差距

有限的命题逻辑内核和合成测量, 不是通用定理证明器或科学发现系统。证明只相对于假设成立, 现实假设仍要实验检验。

## 常见误区与自测

形式证明通过, 能直接说明现实科学假设正确吗?

<details><summary>展开解析</summary>

不能。形式证明内核核验通过仅严格保证一件事: 在预先给定的形式定义、公理集合与命题陈述之下, 目标结论可以经由合法推理规则无歧义地演绎导出; 至于外部物理现实系统是否真正满足这套前提公理与建模假设, 演绎逻辑本身无从裁定, 必须依靠独立的现实观测与受控实验加以检验。
本例的科学建模对照直观体现了经验规律验证的独立性: 二次多项式在观测训练集上虽然实现了 0.0 的零误差精确拟合, 但在未见独立留出点上的泛化 MSE 却高达 3.06, 远逊于留出 MSE 仅为 0.07111 的线性假设。无论内部数学推导多么自洽, 脱离外部独立经验证据都无法确认现实科学假设成立。
