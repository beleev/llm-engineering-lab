# 安全与治理：误拒、漏拦和责任记录

## 直觉

正常文档可以讨论攻击，恶意文档也可以不含攻击关键词。权限需要依据可信的用户授权，而不是文档措辞。

## 核心原理

模型越狱试图改变模型回答边界；间接注入通过网页、PDF、邮件、图片或工具返回影响系统行为。分别建立威胁模型、受保护资产与成功判据，不能只测同一组关键词。

实验配对正常引用和恶意改写，比较误拒与越权。服务端固定 allowlist 在工具执行前核对权限；文档内容不能自行扩展授权。模型层有害输出仍需独立安全训练和测试。

安全训练应把正常/有害请求按意图配对，避免学会主题级一律拒绝；评测拆开有害服从、过拒、迎合、事实欺骗与群体差异。红队样本按载体和攻击家族留出，修复后回归原本正常任务。

数据卡记录来源、用途、授权、版本、切分与哈希；模型卡记录适用人群、失败切片、成本与限制。一个发布闭环是：登记风险及责任人→离线验证→小流量验收→监控阈值→暂停/回滚→更新版本记录。缺字段的记录应退回补齐，不能伪造同意。

## 运行

```bash
python -m llm_agent.m48_safety_governance.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

四个合成案例只验证具体授权与误报逻辑。生产应把策略版本、决策日志、人工复核与撤销测试纳入验收；这不构成通用防越狱保证或法律合规判定。

## 与真实系统的差距

公开合成夹具与动作门，没有实际攻击或真实安全模型。字符规则不能解决通用提示注入；字段齐全也不等于获得法律授权或通过合规认证。
