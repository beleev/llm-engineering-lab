# RAG：答案误差如何反传到检索器

## 直觉

检索器选错文档时，只训练生成器可能让它背答案；让答案损失影响检索，才有机会改进证据选择。

## 核心原理

边缘似然 p(a|q)=Σd p(d|q) p(a|q,d)。对负对数反传，检索概率获得来自答案正确性的梯度；固定生成器可隔离该路径，两侧共同训练则允许两组参数一起变化。

共同优化不保证使用证据。生成器若对所有文档都记住答案，损失会降但检索可能不改善。应加入证据替换、无证据和反事实文档对照，独立测召回、生成和引用支持。

查询改写需保留实体、版本、否定与权限范围。别名表只覆盖已知映射；通用生成式改写要用改写前后检索与最终答案联合验收，不能只比语言是否流畅。

真实 top-k 检索是离散候选门，本例精确遍历三篇文档。未召回文档没有直接梯度；更新索引、困难负样本与候选覆盖是另一层工程问题。

## 怎样验证

先比较冻结与只更新检索，再看共同训练是否走向记忆捷径。检查不同模式实际更新的参数和 top-1，不以“joint”命名代替梯度证据。

## 与真实系统的差距

三篇文档、一个答案的可微机制实验；不是通用 RAG 模型或端到端自然语言生成。固定 generator 的对照用来识别答案记忆捷径。

## 常见误区与自测

共同训练后答案 loss 下降，检索一定更好吗？
