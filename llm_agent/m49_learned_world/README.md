# 学习世界模型：预测和反馈的差别

## 直觉

世界模型根据动作预测下一步；控制器还需要在预测出错后重新观察。能生成连贯视频，并不等于能控制真实世界。

## 核心原理

用 120 条转移样本拟合 x_next=A x+B a，再枚举有界动作做一步 MPC。部署时改变执行器增益，比较相信预测状态的开环和每步使用实际观测的闭环。

多步误差会累积；需要同时测一步误差、固定动作序列 rollout 和闭环任务成功率。相同状态下改变动作，检查预测差异；有混杂的观察数据不能直接证明真实因果。

3D 表示需明确坐标系：相机点通过旋转 R 和平移 t 变到世界坐标，姿态可用旋转矩阵/四元数。点云、体素、mesh、隐式场各有分辨率和拓扑代价；空间关系必须指定参考系，不能只背“左/右”。

VLA 把视觉、语言与动作连接起来；动作 token 需定义坐标、单位、频率与量化误差，分层策略区分高层子目标和低层控制。真实训练还要示教、时间对齐、接触状态、延迟和安全约束；一维 MPC 不能替代这些。

## 运行

```bash
python -m llm_agent.m49_learned_world.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

检查拟合参数、同状态反向动作差异和部署漂移下的预测误差。迁移机器人时需真实传感/执行延迟、部分可观测和接触任务，先离线验证再受控执行。

## 与真实系统的差距

一维线性、全状态可观测、无延迟环境。学习到的是此分布下的转移近似，不能推断掌握真实物理因果或安全机器人控制。

## 常见误区与自测

部署动力学变化后，闭环为什么可能优于开环？
