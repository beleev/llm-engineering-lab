# 学习世界模型: 预测和反馈的差别

## 直觉

demo 用 120 条转移样本拟合出 A/B = 0.9002/0.7007, 动力学匹配时一步 MPC 把状态从 2 收到 0.0062。部署时执行器增益从 0.7 掉到 0.35: 开环照着预测走, 预测说已经到 0.006, 真实状态还在 0.286, 终态 0.28553; 每步重新观察的闭环终态 0.00706。世界模型负责预测, 控制器还得在预测出错后回去看现实。

## 核心原理

demo 用 120 条转移样本最小二乘拟合 x_next = A x + B a, 模型没有读过真实的 A/B; 规划时枚举 [-1, 1] 内 41 个有界动作做一步 MPC。部署时把执行器增益改成 0.35, 比较只信预测状态的开环和每步用实际观测的闭环。

多步误差会累积: 开环 12 步的平均预测误差 0.47642, 闭环 0.12118。所以要同时测一步误差、固定动作序列的 rollout 和闭环任务成功率; 同一状态下把动作从 -1 换到 1, 预测差 1.4014, 这只说明模型里有动作依赖, 有混杂的观察数据不能直接证明真实因果。

3D 表示要先定坐标系: 相机点经旋转 R 和平移 t 变到世界坐标, 姿态用旋转矩阵或四元数。点云、体素、mesh、隐式场各有分辨率和拓扑代价; 空间关系必须指定参考系, 不能只背 "左/右"。

VLA 把视觉、语言与动作接在一起; 动作 token 要定义坐标、单位、频率与量化误差, 分层策略区分高层子目标和低层控制。真实训练还要示教、时间对齐、接触状态、延迟和安全约束; 这个一维 MPC 替代不了它们。

## 怎样验证

固定同一个拟合模型和起点 2, 只改执行器增益 (0.7 → 0.35) 和是否每步重新观察, 比较终态距离、平均预测误差和同状态反向动作的预测差; 迁移到机器人还要真实传感/执行延迟、部分可观测和接触任务, 先离线验证再受控执行。

## 与真实系统的差距

一维线性、全状态可观测、无延迟的环境。学到的是这个分布下的转移近似, 推不出模型掌握了真实物理因果, 也推不出安全的机器人控制。

## 常见误区与自测

部署动力学变化后, 闭环为什么可能优于开环?

<details><summary>展开解析</summary>

因为闭环每步用新观测修正下一步决策。增益从 0.7 变 0.35 后, 开环一直信预测状态, 终态停在 0.28553; 闭环重新观察后终态 0.00706。但这不保证模型和控制器在所有环境都稳定。
