# 学习世界模型: 预测和反馈的差别

## 直觉

学习型世界模型是从交互经验数据中拟合出的环境动力学预测器: 输入当前状态与候选动作, 输出预测的下一时刻状态。本实验环境状态为标量 $x$, 真实物理转移规律为 $x_{\text{next}}=0.9x+0.7a$, 即下一状态等于当前状态的 0.9 倍加上控制动作 $a$ 的 0.7 倍, 其中系数 0.7 代表执行器增益 (单位动作推动状态变化的力度); 世界模型并不知晓真实方程, 仅利用 120 条带噪转移样本 (记录当前状态、执行动作与下一状态) 拟合出参数 A 为 0.9002、B 为 0.7007 (分别对应真值 0.9 与 0.7)。
控制器采用一步模型预测控制 (model predictive control, MPC) 将状态从初值 2 推向目标 0: 每步枚举候选动作并调用世界模型预测下一状态, 择优执行; 当部署环境与训练期动力学匹配时, 终态顺利收敛至 0.0062。
部署阶段将真实执行器增益从 0.7 减半至 0.35 以模拟环境偏移:
- 开环控制全程采信模型自回归预测而不读取真实观测, 末步预测状态已达 0.006, 真实物理状态却滞留在 0.286 (精确终态为 0.28553)。
- 闭环控制每步以真实状态观测重置规划起点, 终态依然收敛至 0.00706。
世界模型提供前瞻预测能力, 而真实环境中的稳健控制还必须依靠观测反馈不断修正预测偏差。

## 核心原理

本实验的世界模型并非硬编码真实物理参数, 而是直接从带噪交互样本中经最小二乘回归拟合得到。
动力学拟合包含两个步骤:
1. 随机采样生成 120 条状态转移样本: 当前状态 $x$ 在 -2 至 2 之间均匀取值, 动作 $a$ 在 -1 至 1 之间均匀取值, 下一状态按真实方程计算后叠加高斯观测噪声。
2. 采用最小二乘法 (最小化预测值与观测值残差平方和) 拟合线性动力学模型 $x_{\text{next}}=Ax+Ba$, 全程不读取真实参数。
在线规划采用一步受限 MPC:
1. 在动作上下界 -1 至 1 之间均匀离散化出 41 个候选动作。
2. 利用拟合好的世界模型预测每个候选动作作用后的下一状态 $\hat{x}$。
3. 选取控制代价 $\hat{x}^2+0.03a^2$ 最小的动作执行, 该目标同时惩罚状态偏离目标 0 的幅度与控制动作自身的幅值开销。
部署阶段将真实环境的执行器增益下调为 0.35, 在此失配条件下对比两种控制回路:
- 开环模式每步将模型上一步预测出的状态直接作为下一步规划输入。
- 闭环模式每步采集真实环境状态观测并以此重新执行一步规划。

动力学失配下开环滚动会将单步模型偏差跨步累积放大, 而闭环反馈每步用真实观测截断误差传播链。开环运行时控制器把上一步的预测状态当作当前真实状态继续推演, 未被纠正的模型高估误差会一路累加: 实验记录的最后三步中, 开环内部预测状态已降至 0.007、0.007、0.006, 规划器误判已抵达目标而输出动作 0, 导致真实物理状态停在 0.353、0.317、0.286, 仅靠状态自身每步乘以 0.9 的自然衰减缓慢回落。闭环运行每步以真实状态观测重置起点, 虽然失配模型做出的单步预测依然有偏, 但历史偏差不会带入下一时刻, 因而 12 步全程的平均预测误差从开环的 0.47642 降至闭环的 0.12118。
评估学习型世界模型时因此必须分开考核三个层面:
- 单步状态转移预测误差。
- 给定动作序列下的多步开环滚动预测 (rollout) 累积误差。
- 接入反馈控制器后的闭环任务完成率。
此外, 在同一状态下将输入动作从 -1 切换为 1 时, 本例模型的预测输出相差 1.4014 (即 $2 \times 0.7007$), 这仅表明拟合函数具有动作敏感性; 若训练数据来自被动观测日志且存在未观测混杂因素 (同时影响历史动作选择与状态演化的隐变量), 该数值差并不能直接证明真实环境中的干预因果效应。

真实三维具身任务远超一维标量系统, 构建 3D 空间表示首先必须明确定义参考坐标系与刚体变换约定。相机传感器捕获的三维点位于相机局部坐标系下, 需经由旋转矩阵 $R$ 与平移向量 $t$ 刚体变换至统一的世界坐标系; 刚体在空间中的朝向姿态则通常采用正交旋转矩阵或单位四元数参数化。
常见三维场景几何表示在空间分辨率、内存开销与可表达的拓扑结构上各具权衡:
- 点云: 离散表面采样点的三维坐标集合。
- 体素: 规则划分的三维空间网格。
- mesh: 由顶点与三角面片拼接而成的显式多边形表面。
- 隐式场: 以连续坐标函数零水平集或密度场刻画几何表面。
处理空间方位指令时必须显式锚定参考坐标系: 相机视角下的左侧与机器人本体坐标系下的左侧往往并不重合, 模型不能脱离参考系孤立记忆「左/右」方位词。

视觉-语言-动作模型 (vision-language-action, VLA) 将多视角视觉观测、自然语言任务指令与底层控制动作统一接入同一序列建模框架。由于连续控制量往往需离散化为动作 token 自回归输出, 系统设计必须预先明确定义动作 token 所属的坐标系、物理量纲、控制下发频率, 以及连续动作量化为离散 token 所引入的截断精度损失。
复杂长程操作通常采用分层控制策略解耦时间尺度:
- 高层语义策略负责任务拆解并输出阶段性子目标。
- 低层运动控制器负责高频闭环跟踪具体控制指令。
真实具身智能训练与部署还高度依赖高质量人类遥操作示教、多传感器严格时间同步、物理接触力状态感知、通信执行延迟补偿及硬件安全围栏; 本实验的一维无延迟线性 MPC 仅演示预测与反馈机制, 无法替代上述任何一项物理工程环节。

## 怎样验证

实验固定同一份最小二乘拟合所得的世界模型与初始状态 2, 仅正交切换两项部署条件:
- 真实环境的执行器增益 (保持训练期的 0.7 或衰减至失配的 0.35)。
- 规划器每步是否读取真实环境状态观测 (开环滚动或闭环重规划)。
横向对比三项量化读数:
- 控制结束时真实状态距目标 0 的绝对距离 (终态距离)。
- 12 个控制步内模型预测状态与真实物理状态的平均绝对偏差 (平均预测误差)。
- 固定同一当前状态时输入动作取 -1 与 1 的单步预测差值。
将世界模型控制器迁移至真实物理机器人时, 还必须额外应对传感采集与执行器响应延迟、状态部分可观测以及刚柔接触非线性突变, 严格遵循先离线仿真验证、再在具备硬件急停保护的受控场地内逐步实测的流程。

## 与真实系统的差距

一维线性、全状态可观测、无延迟的环境。学到的是这个分布下的转移近似, 推不出模型掌握了真实物理因果, 也推不出安全的机器人控制。

## 常见误区与自测

部署动力学变化后, 闭环为什么可能优于开环?

<details><summary>展开解析</summary>

因为闭环控制在每一步都利用最新采集的真实状态观测重置规划起点, 从而及时修正模型失配带来的下一步动作决策。当真实执行器增益从 0.7 衰减至 0.35 后, 相同幅值的动作仅能推动状态行进原有一半的位移, 而未在线更新的世界模型仍按 0.7007 的旧增益做乐观估计。
两种回路在失配环境下的演化轨迹截然不同:
- 开环控制将模型乐观预测的状态直接当作真实状态递推, 几步之后内部预测值已逼近 0, 控制器误以为抵达目标而停止输出有效控制量, 真实物理状态仅靠每步乘以 0.9 的自由衰减缓慢下降, 最终滞留在 0.28553。
- 闭环控制每步核对真实状态观测, 发现实际状态尚未归零便持续施加补偿动作, 最终将真实状态收敛至 0.00706。
实验边界在于闭环反馈并不能保证任意失配程度下的全局稳定性: 本例仅为一维、全状态精确可观测且零通信延迟的理想线性系统, 严重模型失配或大延迟非线性系统仍可能引发闭环振荡发散。
