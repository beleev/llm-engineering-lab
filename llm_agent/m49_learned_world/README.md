# 学习世界模型: 预测和反馈的差别

## 直觉

学得的世界模型是从经验数据里拟合出来的预测器: 给它当前状态和一个动作, 它预测下一个状态。demo 的世界只有一个数 x, 真实规律是 $x_{\text{next}}=0.9x+0.7a$, 意思是下一个状态等于当前状态的 0.9 倍加上动作 a 的 0.7 倍, 这个 0.7 叫执行器增益 (动作推动状态的力度); 模型没见过这条规律, 只用 120 条转移样本 (每条记一次状态、动作和下一个状态) 拟合出 A/B = 0.9002/0.7007 (分别对应 0.9 和 0.7)。控制器用一步 MPC (model predictive control, 模型预测控制) 把状态从 2 推向 0: 每一步都用模型预测每个候选动作的结果, 挑预测最好的去执行; 真实规律和训练时一样 (动力学匹配) 时, 终态到 0.0062。部署时执行器增益从 0.7 掉到 0.35: 开环 (只信模型预测、不看真实状态) 走到最后, 预测说已经到 0.006, 真实状态还在 0.286, 终态 0.28553; 每步重新观察真实状态的闭环终态 0.00706。世界模型负责预测, 控制器还得在预测出错之后回去看现实。

## 核心原理

这组实验里的世界模型是真拟合出来的, 不是把真实参数直接写进去。demo 先随机生成 120 条转移样本: 状态 x 取 -2 到 2 之间, 动作 a 取 -1 到 1 之间, 下一个状态按真实规律算出后再加一点噪声; 然后用最小二乘 (找一组 A、B, 让模型预测和样本之间差的平方和最小) 拟合 $x_{\text{next}}=Ax+Ba$, 模型没有读过真实的 A/B。规划用一步 MPC: 在 -1 到 1 之间均匀取 41 个有界的候选动作, 用模型预测每个动作执行后的状态 $\hat{x}$, 选代价 $\hat{x}^2+0.03a^2$ 最小的那个。这个代价在说: 预测状态越接近 0 越好, 同时别用太大的动作。部署时把真实执行器增益改成 0.35, 比较两种用法: 开环只信模型预测出的状态, 闭环每步都用实际观测到的状态重新规划。

开环的误差会一步步累积, 闭环不会。开环时, 控制器下一步当作「当前状态」的, 就是自己上一步的预测; 预测错了没人纠正, 错误会被带进下一步。执行记录的最后三步里, 开环的预测状态已经是 0.007、0.007、0.006, 动作都是 0, 控制器以为任务完成了; 真实状态却是 0.353、0.317、0.286, 只靠每步乘 0.9 慢慢衰减。闭环每步都从真实观测出发, 单步预测仍会因为增益变了而偏, 但偏差不会带进下一步, 所以 12 步的平均预测误差开环是 0.47642, 闭环是 0.12118。评测世界模型因此要同时测三样: 一步预测误差、固定一串动作后多步滚动预测 (rollout) 的误差、闭环任务能不能完成。另外, 同一状态下把动作从 -1 换成 1, 模型的预测差 1.4014 (等于 2 乘 0.7007), 这只说明模型里有动作依赖; 如果数据是被动观察来的、有混杂因素 (某个没记录的因素同时影响了动作和结果), 这个差不能直接证明真实世界里的因果关系。

真实的具身任务不是一维的, 3D 表示要先定坐标系。相机看到的点在相机自己的坐标系里, 要经过一个旋转 R 和一个平移 t 才能变到世界坐标; 物体的姿态 (朝向) 用旋转矩阵或四元数表示。场景可以存成点云 (一堆三维点)、体素 (三维的像素格子)、mesh (三角面片拼成的表面) 或隐式场 (用一个函数描述表面), 它们在分辨率和能表达的形状结构 (拓扑) 上各有代价。描述空间关系时必须先指定参考系: 从相机看的左边和从机器人看的左边可能不是同一边, 不能只背 "左/右"。

VLA (vision-language-action, 视觉-语言-动作模型) 把看到的画面、收到的语言指令和要做的动作接进同一个模型。动作也要切成 token 输出, 所以要先定义动作 token 的坐标系、单位、控制频率, 以及把连续动作量化成离散 token 时会丢多少精度。分层策略把任务拆成两层: 高层决定下一个子目标, 低层负责具体的控制动作。真实训练还需要人类示教数据、时间对齐、接触状态、延迟和安全约束; 这个一维 MPC 替代不了其中任何一样。

## 怎样验证

固定同一个拟合出来的模型和起点 2, 只改两件事: 真实执行器增益 (0.7 还是 0.35), 以及是否每步重新观察真实状态。比较三个读数: 终态离 0 有多远 (终态距离)、12 步里预测状态和真实状态的平均差 (平均预测误差)、同一状态下动作取 -1 和 1 时的预测差。迁移到机器人还要考虑真实的传感和执行延迟、只能看到部分状态 (部分可观测) 和接触任务, 要先离线验证, 再在受控条件下执行。

## 与真实系统的差距

一维线性、全状态可观测、无延迟的环境。学到的是这个分布下的转移近似, 推不出模型掌握了真实物理因果, 也推不出安全的机器人控制。

## 常见误区与自测

部署动力学变化后, 闭环为什么可能优于开环?

<details><summary>展开解析</summary>

因为闭环每一步都用新的观测修正下一步的决策。一步步看: 增益从 0.7 掉到 0.35 后, 同样的动作只能把状态推动原来一半的距离, 但模型还以为增益是 0.7007。开环把模型预测的状态当成真实状态, 预测显示已经接近 0, 控制器就停手了, 真实状态只靠每步乘 0.9 的自然衰减往下走, 终态停在 0.28553。闭环每步重新看真实状态, 发现还没到就继续施加动作, 终态到 0.00706。但这不保证模型和控制器在所有环境都稳定: demo 是一维、状态全看得见、没有延迟的环境。
