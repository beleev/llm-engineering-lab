# 任务恢复：旧检查点遇到新代码

能读回旧消息不等于能继续旧任务。恢复前要核对状态格式、流程版本、工具约定和当前权限；已提交的动作还要查收据。

## 怎么跑

```bash
python -m llm_agent.m57_checkpoint_migration.demo
```

## 先看这几件事

- schema_version 决定如何读取持久状态；新增可选字段可补默认值，丢失必填字段、未知节点与不兼容工具约定应在副作用前拒绝。
- flow_version 决定业务规则。新版代码不能静默改变旧任务承诺，也不能让旧任务继承已经撤销的权限；兼容性和执行授权分别检查。
- 外部服务提交与本地检查点是两个事务。实验在中间真正退出子进程；重启后核对稳定操作键和参数，使用已有收据完成本地状态，不重复入账。

## 怎样验证

保存 v1 暂停任务，交给 v2 执行器；验证字段默认值、节点/字段/工具不兼容拒绝、授权撤销、新旧流程差异，以及外部提交后强退恢复只有一笔副作用。
