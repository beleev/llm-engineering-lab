# 专业领域：证据时效、地域与复核

## 直觉

专业任务的错误往往不是句子不通，而是引用了过期规则、错误地域或不适用的人群。

## 核心原理

用完全虚构的医疗、法律、金融资料测试地域、日期、版本和证据过滤。找不到适用证据就拒绝作确定判断；专家复核状态来自外部记录，不能由模型自己宣称。

领域继续预训练补语言分布，SFT 适配格式与任务，RAG 提供可更新证据；三者作用不同。独立测试应按机构、时间、文档族和人群拆分，并保留域外基准检查遗忘。

工作流验收包括引用正确、适用范围、关键遗漏、错误严重度和升级流程。高代价错误要单独计数；拒答覆盖率、专家复核负担与每成功任务成本一并报告。

数据最小化、访问隔离和参数隐私是不同层次；缓存与日志也可能泄漏敏感内容。审查责任、证据快照与撤回规则应可追溯，不能以模型高置信替代专家签字。

## 运行

```bash
python -m llm_agent.m52_domain_workflows.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

比较不加约束、证据过滤和带外部复核的输出状态。全部术语与规则均为虚构测试夹具，不提供专业结论；真实上线需由领域专家制定标签与验收阈值。

## 与真实系统的差距

所有地区、日期和规则均为虚构夹具，不提供医疗、法律或投资建议。未实现真实专家系统；这里验证资料和工作流边界。

## 常见误区与自测
