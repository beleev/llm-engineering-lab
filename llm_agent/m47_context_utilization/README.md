# 有效上下文：看得到，不等于用得上

## 直觉

模型能接收很长输入，不代表能稳定利用中间的一小段证据。理论可达、检索命中和正确组合是三件事。

## 核心原理

固定问题和答案，移动证据到头/中/尾，再交叉长度、干扰量和单/双证据。对真实模型应比较答案、证据引用和逐跳支持，而非仅测一个 needle。

本例读出器公开加入首尾偏好，观察 softmax 权重分配；移除偏好仍会受干扰稀释。检索缩短候选集合只在评分能认出证据时有帮助。

递归记忆把旧块压缩成状态，分层注意力先找块再读块；两者都增加跨段信息通道，但压缩丢细节、路由选错块仍会失败。另见 foundation/hierarchical_memory 的数组级对照。

## 运行

```bash
python -m llm_agent.m47_context_utilization.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

18 个位置×长度×证据组合全部执行。这里是显式机制模型，不是某个 LLM 的 Lost in the Middle 实测；真实评测要控制输出预算和检索器变化。

## 与真实系统的差距

这是带公开位置偏好的 softmax 阅读器，不是实测 LLM 的 Lost in the Middle 曲线。不能把本例阈值或窗口长度外推成任何模型的有效上下文。
