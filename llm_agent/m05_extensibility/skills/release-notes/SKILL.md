# 发布说明模板

1. 标题: `vX.Y.Z — 一句话主题`。
2. 分三节: 新增 / 修复 / 破坏性变更; 每条以动词开头, 末尾附 PR 编号。
3. 破坏性变更必须给出迁移步骤和最小示例。
4. 面向用户描述影响, 不复述实现细节; 内部重构除非影响性能, 否则不写。

## 语气

- 中文, 简洁, 不用营销词。
- 数字优先: "启动快 40%" 好过 "显著更快"。

## 检查清单

- [ ] 每条变更都能对应到一个已合并的 PR
- [ ] 破坏性变更在最上方再提示一次
- [ ] 版本号符合 semver
