# PEFT: Prompt、Prefix、Adapter 与 LoRA

## 直觉

PEFT (parameter-efficient fine-tuning, 参数高效微调) 冻结预训练基座的全部原始权重, 仅更新少量新增适配参数。本组实验在同一个单层注意力冻结基座上对比四类参数挂载位置:
- Soft Prompt: 在输入 embedding 序列前端拼接可学习的连续向量。
- KV Prefix: 直接在注意力层内的 K 与 V 序列前端拼接可学习前缀状态。
- Adapter: 在注意力层输出端串联先降维、经非线性激活再升维的瓶颈残差网络。
- LoRA: 在线性投影矩阵旁并联由两个低秩矩阵乘积构成的权重增量。
实验基座仅含单层自注意力, 每条输入样本包含 3 个 8 维 token, 回归目标为末尾 token 前两维之和, 四种方案均在相同 32 条样本上训练 160 步。
训练收敛读数如下:
- Soft Prompt 仅含 16 个可训练参数, MSE 从初始的 1.5684 降至 1.0521。
- KV Prefix、Adapter 与 LoRA 均含 32 个可训练参数, 末步 MSE 分别降至 0.7128、0.5444 与 0.7207。
冻结基座权重并不意味着只能在输入端调整提示词: 不同挂载位置决定了不同的梯度回传路径与表征干预自由度, 在线部署时付出的显存与算子代价也各不相同。

## 核心原理

Prompt Tuning 仅学习 2 个输入端 embedding 向量且须穿过冻结的 Q/K/V 线性投影, 而 Prefix Tuning 直接参数化当前层的 K/V 前缀状态, 在真实多层 Transformer 中需逐层独立注入。
在自注意力层内, 输入表示需分别右乘冻结的 Q、K、V 投影矩阵以生成查询、键与值向量, 两条前缀式适配路径的作用点存在本质差异:
- Prompt Tuning (Soft Prompt): 在输入序列前端拼接 2 个可学习的 8 维向量 (共 16 个参数), 该向量与普通输入 token 一样必须先经过冻结的 K、V 投影矩阵变换才能参与注意力加权, 因此所能张成的有效键值方向受限于冻结投影矩阵的列空间。
- Prefix Tuning (KV Prefix): 绕过输入端线性投影, 直接学习 2 个 8 维键前缀与 2 个 8 维值前缀 (共 32 个参数) 并拼接至本层 K、V 序列前端; 扩展至深层模型时, 需为每一层自注意力分别配置独立的 K/V 前缀参数。
本例在统一的单层冻结基座上评测两条路径, 回归头仅读取序列末尾位置的输出表示, 该位置可通过注意力权重聚合前方全部真实 token 与前缀向量的信息。

瓶颈 Adapter 将注意力输出先线性降维、经非线性激活后再升维并汇入残差分支, 而 LoRA 为线性投影矩阵并联低秩增量 $\Delta W = AB$, 部署单任务模型时可将增量无损合并回基座权重。
在单层注意力输出 8 维表示 h 后, 瓶颈 Adapter 依次执行四步运算:
1. 右乘 8×2 降维矩阵将维度压缩至瓶颈维 2。
2. 施加 ReLU 非线性激活。
3. 右乘 2×8 升维矩阵恢复至 8 维。
4. 通过残差连接叠加回原输出 h。
LoRA 则针对冻结的 8×8 值投影矩阵 W, 旁路引入 8×2 矩阵 A 与 2×8 矩阵 B, 以乘积 $\Delta W = AB$ 构造 rank 至多为 2 的低秩修正项, 等效投影变为 $W + \Delta W$。本实现将 Adapter 的升维矩阵与 LoRA 的矩阵 B 均初始化为全 0, 确保训练第 0 步旁路输出严格为 0, 因此二者的初始 MSE 均等于冻结基座本身的 1.5489。
四类方案的在线部署开销差异显著:
- Soft Prompt 与 KV Prefix: 占用有效上下文长度, 且前缀键值状态需常驻推理 KV cache。
- 瓶颈 Adapter: 因内部包含非线性激活 ReLU, 无法代数折叠进前序线性层, 在线推理必然增加串行算子延迟。
- LoRA: 单任务部署时可将 $\Delta W$ 离线累加至原权重 W, 推理阶段不产生额外线性算子开销。

多个同构 LoRA 模块虽可在权重空间按系数线性叠加, 但下游任务收益并不保证线性可加, 且合并前必须严格核对基座版本、rank 配置与挂载目标层。权重空间加权求和即将不同任务独立训练出的低秩增量 $\Delta W_i$ 按权重系数叠加至同一基座矩阵 W。由于各增量模块在训练阶段彼此独立优化、未建模跨模块特征交互, 直接叠加可能引发子空间干扰, 组合表现未必等于各单任务能力之和; 同时 $\Delta W$ 强绑定于特定基座权重快照与指定投影层, 跨基座版本或错配目标层叠加会导致表征崩溃。相比之下, Soft Prompt 与 KV Prefix 作用于序列激活维度而非权重空间, 不能作为 $\Delta W$ 直接并入线性层。在多用户持续个性化场景中, 需系统对比每用户独立 adapter、全局共享 adapter 与多 adapter 动态组合三种架构在跨用户串扰与旧任务遗忘上的权衡。

## 怎样验证

四类适配模式共享同一个单层冻结基座、同一批 32 条样本与 160 步训练预算 (采用 Adam 优化器, 学习率为 0.035), 统一报告可训练参数量、训练前后 MSE 并执行基座权重不变性断言; 由于各路径参数规模未完全配平 (16 对比 32), 实验读数仅用于验证各挂载路径的梯度可微性与拟合有效性, 不构成通用方法优劣排名。
训练结束后代码逐元素比对 Q/K/V 投影矩阵与初始快照是否严格相等 (对应输出表中的「冻结基座未变 true」), 并断言四种模式末步 MSE 均显著低于初始值。鉴于 Soft Prompt 仅含 16 个参数而其余三种方案含 32 个参数, 且 MSE 直接在这 32 条训练样本上评估、未划分独立留出测试集, 读数高低仅证明梯度成功回传至新增参数模块, 不可外推为泛化性能排序。

## 与真实系统的差距

固定 32 条合成样本验证参数路径与梯度。没有留出泛化结论；Prompt Tuning 与提示词写作不是一回事。

## 常见误区与自测

在本例中, KV Prefix 与 Soft Prompt 最核心的结构区别是什么?

<details><summary>展开解析</summary>

Soft Prompt 优化的是输入端 embedding 向量, 必须穿过冻结的 Q/K/V 投影矩阵才能转化为键值向量; KV Prefix 则跳过输入投影, 直接参数化注意力层内部的 K/V 前缀状态。
两条前向与梯度路径的具体差异如下:
- Soft Prompt: 将 2 个可学习向量拼接在输入序列最前端, 进入注意力层后须与普通 token 一同右乘冻结的 K、V 投影矩阵; 优化器仅能调整投影前的输入向量, 最终生成的键值表示受冻结投影矩阵的列空间约束。
- KV Prefix: 将 2 个键向量与 2 个值向量直接定义为可训练张量, 绕过线性投影并拼接在本层 K、V 序列前端, 拥有直接干预注意力键值分布的自由度。
二者的可训练参数量也随之不同: Soft Prompt 为 2 乘 8 共 16 个参数, KV Prefix 包含键值两组各 2 乘 8 共 32 个参数。此外, 本例仅为单层注意力基座, 在多层 Transformer 中实现 Prefix Tuning 还须明确逐层 K/V 前缀的注入位置与参数化方式。

</details>
