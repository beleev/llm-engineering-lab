# LoRA — 低秩适配

[![LoRA — 用 B·A 拟合一个低秩的 ΔW llm_finetune/methods/lora.py](../../../docs/screenshots/finetune-lora-1.png)](https://beleev.github.io#/finetune/lora)

[打开相关交互实验：LoRA — 用 B·A 拟合一个低秩的 ΔW llm_finetune/methods/lora.py](https://beleev.github.io#/finetune/lora)

## 直觉

冻结 W, 旁边挂一条 "先降到 r 维再升回去" 的支路, 只训这条支路。省掉的是**梯度 + Adam 状态 + 每个任务一份完整权重**, 不是训练步数。

## 核心原理

### 核心公式

`y = W x + (α/r)·B A x`，A ∈ R^{r×d_in} (Kaiming uniform)，B ∈ R^{d_out×r} (全零 ⇒ 第 0 步输出与基座逐位相同)。
训完 `W' = W + (α/r)BA` 合并回普通 `nn.Linear`。

## 运行

```bash
python -m llm_finetune.run_finetune.lora.train_lora    # ~14 s
```

## 运行后应该看到什么

基座已会 copy (留出集 EM 1.0), 适配到 sort, 各 300 步, r=8, 注入全部 7 种线性层:

| | 可训参数 | Adam 状态 | 末步 loss | 留出集 EM |
|---|---|---|---|---|
| 全参 lr=3e-3 | 99,648 | 778 KiB | **0.119** | **0.809** |
| LoRA lr=3e-3 | 19,456 | 152 KiB | 0.504 | 0.281 |
| LoRA lr=1e-2 | 19,456 | 152 KiB | 0.384 | 0.352 |

合并前后 logits 最大差 6e-06 (断言 < 1e-4); adapter 76 KiB。

**结论: 同样步数下全参收敛更快; LoRA 需要 ~3–10× 的 lr 才跟得上, 且仍然落后。** "LoRA 比全参收敛快" 这种说法, 多半是病态初始化 (初始 loss ≈ 250) + 只背几条样本 + 给 LoRA 单独调大 lr 共同造成的假象。
(可训比例 19.5% 看起来不小, 是因为 d_model=64: 比例 ≈ 2r/d, d=4096 时同样的 r 只占 0.4%。)

## 与真实系统的差距

- **模型太小, 测不出低秩够不够用**: 基座只有 99,648 参数、d_model=64, r=8 就占了 19.5% 的参数。真实模型 d=4096 时同样的 r 只占 0.4%, 低秩假设在那个比例下成不成立, 这里看不到。
- **基座是 150 步 SFT 出来的 copy 模型**: 它只会一个任务。真实基座在大语料上预训练过, 适配新任务时能复用的表示多得多。
- **注入了全部 7 种线性层**: 脚本传 `target_modules=ALL_LINEARS`。`apply_lora` 的默认值只注入注意力的 4 个投影。注入哪些层、r 和 α 取多少, 在真实配置里都要调, 脚本固定 r=8、α=16。
- **只算了 Adam 状态的大小, 没量显存**: 表里的 778 KiB / 152 KiB 是 "可训参数 × 8 字节"。前向的激活和反传的中间量仍要过整个基座, 这部分 LoRA 省不掉, 脚本没有量。
- **没有演示多适配器切换**: 脚本导出了 76 KiB 的 adapter, 然后直接合并。同一个基座挂多个适配器、按请求切换, 这种用法没有演示。
- **dropout 没开**: `LoRALinear` 支持对低秩支路做 dropout, 脚本用默认的 0。

## 常见误区

- "LoRA 更快 / 更好"。它更省显存和存储; 效果上限 ≤ 全参。
- A、B 都零初始化 → 梯度恒为 0; 都随机 → 第 0 步就破坏了基座。
- 只断言合并后的输出形状: 合并写错 (漏了 α/r、转置) 形状照样对。要断言**数值**相等。
- 沿用全参的 lr: B 从 0 起步, ΔW 的有效步长小, 表中第二行就是后果。

## 自测题

1. d_in = d_out = 4096, r = 8, 一层 LoRA 多少参数, 占原层多少? — 8×(4096+4096) = 65,536, 约 0.39%。
2. 为什么是 B 置零而不是 A? — 置零哪个都能让 BA=0。∂L/∂B ∝ (Ax)ᵀ、∂L/∂A ∝ Bᵀ·: 被置零的那个第 1 步就有梯度, 另一个从第 2 步才开始动。惯例置零 B; 两个都置零则梯度永远为 0。
3. 合并之后还能继续训练 LoRA 吗? — 本实现合并 = 换回普通 Linear, 适配器不复存在; 要继续训就重新 `apply_lora`。
