# 隐私：记忆提取、DP 与参数遗忘

## 直觉

拒绝复述某条记录不代表模型没有记住它；攻击没成功，也不等于已经证明隐私安全。

## 核心原理

合成 one-hot 键让线性模型实际记住记录值；查询可提取它们。成员推断用固定损失阈值区分训练与非训练记录，同时报告 TPR/FPR，而非仅报告攻击准确率。

DP 路径逐样本裁剪再加高斯噪声。固定大小、替换一条记录的邻接关系下，均值梯度敏感度不超过 2C/n；全批访问不使用采样放大。每步 ρ=1/(2σ²)，组合后转换为 ε=ρ+2√(ρ log(1/δ))。

删除路径从岭回归充分统计量扣除记录，再与删除后的独立重训比较。一般 LLM 不能这样精确求解；需同时报告忘记集、保留集、攻击与重训参照，输出屏蔽只属于访问控制。

数据授权与隐私是不同问题。保留许可证、用途与版本；输出相似性可用长串匹配和人工复核，但高相似/低相似都不能单独裁定权利状态。内容来源、生成过程和签名链提供证据，不自动赋予授权。

## 运行

```bash
python -m llm_finetune.run_finetune.privacy_unlearning.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

仅用合成记录重现三条路径。固定公开随机种子方便教学复现，却不提供真实私密数据的 DP 保护；真实发布必须使用合适随机源、审计 accountant 与全部数据访问。

## 与真实系统的差距

全部是合成记录。公开固定种子仅用于复现演示，不能用于保护真实私密数据；该精确遗忘方法仅适用于此凸闭式模型，不适用于一般 LLM。

## 常见误区与自测

成员推断攻击失败，能证明模型满足差分隐私吗？

单次攻击只检验一个攻击器。DP 需要定义邻接、敏感度、噪声、组合和所有发布通路。
