# 隐私: 记忆提取、DP 与参数遗忘

## 直觉

这组实验用 8 条合成记录训练一个线性模型, 看它会不会把记录记住、能不能被问出来、怎样防、怎样删。每条记录是一个 one-hot 键 (12 维向量里只有一位是 1, 相当于一个编号) 加一个数值, 第 1 条的数值是 0.2; 训完查第 1 条的键, 模型输出 0.19802。成员推断 (攻击者拿一条记录, 猜它在不在训练集里) 用「模型在这条记录上误差很小就猜在」的规则, TPR (真训练记录里被猜中的比例) 是 1.0, FPR (没训练过的记录里被误猜成成员的比例) 是 0.0。拒绝复述某条记录不代表模型没记住它; 换成 DP-SGD (每条记录的梯度先裁剪长度、再加随机噪声的训练方法) 后 TPR 掉到 0.125, 但攻击没成功也不等于已经证明隐私安全。第三条路径做机器遗忘 (让模型变得像从没见过某条记录): 把第 1 条从模型里删掉, 它的输出变成 0.0, 和去掉它重训的结果一致。

## 核心原理

合成 one-hot 键让线性模型实际记住 8 条记录值, 按键查询就能提取。模型用岭回归训练 (普通线性回归再加一个 0.01 的惩罚项, 防止权重过大): 12 个权重各对应键的一位, 每个键只有一位是 1, 所以第 i 条记录只影响第 i 个权重, 训完这个权重等于记录数值除以 1.01, 第 1 条就是 0.2 ÷ 1.01 = 0.19802。拿第 1 条的键去查, 输出就是这个权重, 记录的数值几乎原样被读了出来。成员推断用固定的损失阈值 0.01 区分训练与非训练记录: 训练过的 8 条, 模型的平方误差都远小于 0.01, 全被判成成员; 没训练过的 4 个键对应的权重还是 0, 输出 0, 和它们的真实数值 0.3 到 1.2 差得远, 平方误差至少 0.09, 没有一条被误判。同时报告 TPR/FPR, 不只报攻击准确率, 这样才看得出攻击是真能认出成员, 还是把什么都猜成成员; 阈值不在这份评测标签上调, 因为对着答案调出来的阈值会让攻击显得比实际更准。

DP 路径逐样本裁剪 (C = 1) 再对均值梯度加高斯噪声 (σ = 4), 跑 40 步。差分隐私 (differential privacy, DP) 要保证: 训练集里换掉任意一条记录, 训练结果的分布几乎不变, 于是从结果推不出那条记录在不在。DP-SGD 每一步先算每条记录各自的梯度, 长度超过 C = 1 的按比例缩到 1, 让单条记录对这一步的影响有上限; 再对 8 条取平均, 加上标准差为 σ × 2C/n = 4 × 2 × 1 ÷ 8 = 1 的高斯噪声。2C/n 是敏感度: 在固定大小、替换一条记录的邻接关系下 (两个数据集条数相同, 只差被换掉的那一条), 每条裁剪后的梯度长度不超过 C, 换一条最多让总和变 2C, 平均最多变 2C/n。全批访问不用采样放大: 如果每步只随机抽一部分记录, 某条记录这一步可能没被用到, 隐私账可以算得更省, 这叫采样放大; 本例每步都用全部 8 条, 不打这个折扣。隐私账用 zCDP (一种便于逐步累加的记账方式) 记: 每步 ρ=1/(2σ²), 按步相加后转换为 ε=ρ+2√(ρ log(1/δ)), 这个式子把累计的 ρ 换算成常用的 ε, ε 越小保护越强, δ 是允许保证失效的极小概率; δ=1e-6 时 ε=9.561。代价是精度: 每步每个权重分到的平均梯度最多 1/8 = 0.125, 噪声标准差却是 1, 保留集 MSE 从 0.00011 升到 0.34323。

删除路径从岭回归的充分统计量里扣掉那条记录, 再和去掉它重训的结果比对, 差在 1e-12 以内。岭回归的解只由两个汇总量决定: XᵀX (每条记录的键与自身外积之和) 和 Xᵀy (每条记录的键乘数值之和), 有了它们就能解出权重, 这种汇总量叫充分统计量。删一条记录只要从两个汇总量里各减去它那一份, 再解一次方程, 不用回头读其余数据。机器遗忘最硬的参照是去掉这条记录从头重训, 代码断言两者的权重差在 1e-12 以内; 删完后待删记录输出变成 0.0, 保留集 MSE 仍是 0.00011。成员推断 TPR 从 1.0 变成 0.875: 被删的那条现在平方误差是 0.04, 不再被猜成成员, 其余 7 条仍被猜中。一般 LLM 不能这样精确求解, 要同时报告忘记集 (要删的记录)、保留集 (其余记录)、攻击与重训参照; 只屏蔽输出属于访问控制, 不改参数, 参数里的 0.19802 还在。

数据授权与隐私是两个问题。隐私问的是模型会不会泄露某条记录, 授权问的是这批数据有没有被允许拿来训练和使用。保留许可证、用途与版本, 事后才能查清每条数据从哪来、被允许做什么。输出相似性可以用长串匹配 (找模型输出和训练文本里一字不差的长片段) 和人工复核来查, 但高相似或低相似都不能单独裁定权利状态: 相似度只是一项证据, 能不能用还要看授权本身。内容来源、生成过程和签名链 (给内容的每一道经手环节附上可验证的签名) 提供证据, 不自动赋予授权。

## 怎样验证

只用 8 条合成记录, 固定公开种子, 跑记忆、裁剪加噪、删除并核对重训三条路径, 比较保留集 MSE (被删那条以外 7 条记录的平均平方误差)、待删记录输出 (查第 1 条的键得到的值)、成员推断 TPR/FPR 和 ε 上界。判定方法: 记忆路径断言 TPR 为 1、FPR 为 0; 删除路径断言和重训结果一致、待删记录输出为 0、保留集 MSE 不变; DP 路径的隐私看 ε, 攻击率只作旁证。固定种子只为教学复现, 不提供真实私密数据的 DP 保护, 因为种子公开就能复算出加过的噪声; 真实发布要用合适随机源、审计 accountant (累计记录 ε 花了多少的程序) 与全部数据访问通路。

## 与真实系统的差距

全部是合成记录。公开固定种子仅用于复现演示，不能用于保护真实私密数据；该精确遗忘方法仅适用于此凸闭式模型，不适用于一般 LLM。

## 常见误区与自测

成员推断攻击失败, 能证明模型满足差分隐私吗?

<details><summary>展开解析</summary>

不能。单次攻击只检验一个攻击器。一步步看: 本例的攻击器只有一条规则, 平方误差小于 0.01 就猜是成员; DP 路径下 8 条训练记录只有 1 条被猜中 (TPR 0.125), 这只说明这个阈值攻击没打中, 换一个更聪明的攻击器可能打中更多。差分隐私是对训练机制本身的保证, 不靠攻击结果: 要先定义邻接 (两个数据集差多少算相邻)、敏感度 (换一条记录梯度最多变多少)、加多大噪声、多步怎样组合累加, 以及模型对外有哪些发布通路, 再由这些推出 ε。本例的 ε=9.561 就来自这些假设, 换不换攻击器, 它都不变。

</details>
