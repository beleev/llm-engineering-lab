# 隐私: 记忆提取、DP 与参数遗忘

## 直觉

本实验用 8 条合成记录训练线性模型, 对比参数记忆提取、差分隐私防护与事后参数遗忘三条路径。每条记录由 12 维 one-hot 键与一个标量目标值组成, 其中第 1 条记录的真值为 0.2; 模型训练完成后按第 1 条记录的键查询, 输出为 0.19802。
成员推断 (判定目标样本是否参与过训练) 以预测误差低于阈值作为判定规则, 测得 TPR (训练样本被判为成员的比例) 为 1.0, FPR (非训练样本被误判为成员的比例) 为 0.0。
仅在输出侧拒绝复述并不改变参数记忆; 改用 DP-SGD (逐样本梯度裁剪并注入高斯噪声) 训练后 TPR 降至 0.125, 但经验攻击成功率下降本身仍不等同于差分隐私保证。
机器遗忘路径则直接从模型统计量中移除第 1 条记录, 使该键的查询输出归零为 0.0, 并与剔除该样本后重新训练的结果保持一致。

## 核心原理

合成 one-hot 键使岭回归模型将 8 条训练记录的值直接编码进对应权重, 按键查询即可原样提取。模型采用带 0.01 正则系数的岭回归: 12 个权重分别对应 12 维 one-hot 键的各个维度, 第 i 条记录仅激活第 i 个权重, 闭合解等于目标值除以 1.01, 因此第 1 条记录对应的权重为 $0.2 / 1.01 \approx 0.19802$, 按该键查询即直接返回该权重。
成员推断使用固定平方误差阈值 0.01 区分成员与非成员:
- 已训练的 8 条记录预测平方误差均远低于 0.01, 全部被判为成员。
- 未参与训练的 4 个键对应权重保持为 0, 预测输出为 0, 与 0.3 至 1.2 的真实数值相比平方误差至少为 0.09, 无一被误判。
评测同时遵循两项约束:
- 同时报告 TPR 与 FPR 而非单一攻击准确率, 以区分有效识别与无差别判正。
- 判定阈值不在当前评测集标签上调优, 避免因事后拟合标签而高估攻击能力。

DP-SGD 路径通过逐样本梯度裁剪与均值梯度加噪限制单条记录的参数影响, 以精度损失换取可计算的隐私预算上界。差分隐私 (differential privacy, DP) 要求替换训练集中任意单条记录后训练输出分布几乎不变, 从而使外部无法推断特定记录是否参与训练。
本例将裁剪阈值 C 设为 1、噪声倍数 σ 设为 4 并迭代 40 步, 每步执行三项操作:
1. 独立计算每条记录的样本梯度。
2. 将范数超过 1 的样本梯度按比例缩放至 C (即 1), 为单条记录的单步贡献设定上界。
3. 对 8 条裁剪后梯度求均值, 并注入标准差为 $\sigma \cdot 2C/n = 4 \times 2 \times 1 / 8 = 1$ 的高斯噪声。
其中 $2C/n$ 为替换邻接定义 (数据集容量固定为 n, 仅替换 1 条记录) 下的均值敏感度: 单条裁剪梯度范数不超过 C, 替换 1 条记录最多使梯度总和变化 $2C$、均值变化 $2C/n$。由于每步均做全量 batch 访问 (使用全部 8 条样本), 不适用子采样隐私放大折扣。
隐私预算采用 zCDP 累加记账: 单步隐私代价为 $\rho = 1/(2\sigma^2)$, 按步线性累加后通过 $\varepsilon = \rho + 2\sqrt{\rho \log(1/\delta)}$ 换算为 $(\varepsilon, \delta)$-DP, 其中 ε 越小保护越强, δ 为允许保证失效的极小概率上界; 取 δ 为 1e-6 时累计 ε 为 9.561。相应代价是效用下降: 单步每个权重分到的有效均值梯度上界仅为 $1/8 = 0.125$, 而注入噪声标准差为 1, 导致保留集 MSE 从 0.00011 升至 0.34323。

精确遗忘路径从岭回归的充分统计量中扣除待删记录并重解方程, 所得权重与剔除该记录后重训的偏差不超过 1e-12。岭回归的闭合解完全由两项汇总矩阵决定:
- $X^\top X$: 各样本键向量的外积之和。
- $X^\top y$: 各样本键向量与目标值乘积之和。
这两项汇总量构成模型的充分统计量; 删除单条记录只需从两项统计量中分别减去该样本的贡献并重新求解线性方程组, 无需遍历其余训练样本。机器遗忘的基准参照是剔除目标记录后从头重训, 代码断言两者权重的最大绝对差在 1e-12 以内; 删除后待删键输出变为 0.0, 其余 7 条保留集 MSE 仍为 0.00011, 成员推断 TPR 从 1.0 降至 0.875 (被删记录的平方误差变为 0.04, 不再低于判定阈值, 其余 7 条仍被判为成员)。
通用非线性 LLM 不存在此类精确充分统计量闭合解, 评估遗忘时需同时报告:
- 遗忘集 (待删除记录) 上的残留指标。
- 保留集 (其余正常记录) 上的效用保持度。
- 成员推断攻击与从头重训基线的分布对比。
仅在输出层屏蔽特定内容属于访问控制, 并未修改模型参数, 权重中的 0.19802 依然存在。

数据授权合规与参数隐私保护属于两个正交维度, 需要分别建立证据链与核查机制。隐私关注模型参数与输出是否泄露单条个体记录, 数据授权则关注训练语料本身是否具备合法训练与分发许可。完整留存数据的许可证类型、允许用途与版本记录, 才能在事后追溯每批语料的来源与权利边界。输出相似性可通过长串精确匹配与人工复核做排查, 但无论高相似还是低相似都无法单独裁定权利状态: 文本相似度仅是一项技术旁证, 合法性仍取决于底层授权条款。内容溯源记录、生成日志与密码学签名链仅提供流转真实性证据, 并不会自动赋予使用授权。

## 怎样验证

实验固定公开随机种子与 8 条合成记录, 依次运行参数记忆、DP-SGD 裁剪加噪、充分统计量删除并核对重训三条路径, 对比四项读数:
- 保留集 MSE (除第 1 条待删记录外其余 7 条记录的均方误差)。
- 待删记录输出 (按第 1 条记录键查询所得预测值)。
- 成员推断的 TPR 与 FPR。
- 差分隐私预算 ε 上界。
验收判定标准:
- 记忆路径断言成员推断 TPR 为 1、FPR 为 0。
- 删除路径断言参数与剔除重训结果一致、待删记录输出为 0、保留集 MSE 保持不变。
- DP 路径的隐私强度以 ε 上界为准, 经验攻击率仅作辅助旁证。
实验边界在于固定公开种子仅服务于确定性教学复现, 不能为真实私密数据提供 DP 保护, 因为公开种子可直接复算出所注入的伪随机噪声; 生产环境发布必须采用密码学安全随机源, 并对隐私预算 accountant (累计追踪 ε 消耗的记账器) 及全部外部数据访问通路做完整审计。

## 与真实系统的差距

全部是合成记录。公开固定种子仅用于复现演示，不能用于保护真实私密数据；该精确遗忘方法仅适用于此凸闭式模型，不适用于一般 LLM。

## 常见误区与自测

成员推断攻击失败, 能证明模型满足差分隐私吗?

<details><summary>展开解析</summary>

不能。单次经验攻击失败仅说明当前特定攻击器未能奏效, 不能替代训练机制的数学证明。本例的攻击器仅采用平方误差小于 0.01 即判为成员的固定阈值规则; DP 路径下 8 条训练记录中仅有 1 条命中 (TPR 为 0.125), 这只能说明该简单阈值攻击效果受限, 若换用更强的自适应攻击器仍可能获得更高识别率。
差分隐私是针对训练随机化机制本身的分布性质保证, 不依赖具体攻击实验结果, 必须预先明确以下前提并做理论推导:
- 邻接关系定义 (两个数据集相差多少条记录视为相邻)。
- 梯度敏感度上界 (替换单条记录最多引起的梯度变化量)。
- 随机噪声分布与尺度。
- 多步迭代的组合记账规则。
- 模型对外暴露的全部参数与查询发布通路。
本例的隐私预算上界 ε (等于 9.561) 完全由上述机制参数导出, 不随外部攻击器的强弱而改变。
