# IPO: 偏好间隔为何有有限目标

## 直觉

本组实验对比两种离线偏好优化目标:
- DPO: 直接基于成对偏好标签最小化 logistic 偏好损失。
- IPO (identity preference optimization): 将偏好目标改为围绕有限间隔的平方回归损失。
实验控制条件如下:
- 训练数据为 4 对单 token 偏好样本, 每对回答仅含 1 个 token, 由标签指定优胜回答 (chosen) 与劣势回答 (rejected)。
- 参考模型固定为冻结的均匀分布。
- 两种方法均采用 SGD 优化器训练 400 步。
核心观测指标是对数概率比差值 h (即 log-ratio margin): 定义为当前策略赋予 chosen 与 rejected 的对数概率之差减去参考模型上的对应差值, h 越大代表策略相对参考模型越偏向 chosen。
训练 400 步后的读数对比显著:
- DPO 将平均 h 推高至 4.35871 且仍在持续发散增大。
- IPO 的平均 h 稳定停在 1.0, 精确等于理论目标值 1/(2β) (本例超参数 β 取 0.5)。
成对标签仅表明 chosen 优于 rejected, 并未要求将 rejected 的生成概率压至零; IPO 显式设定有限的相对对数概率间隔作为收敛终点, 抵达目标后梯度即归零。

## 核心原理

IPO 损失在 h 等于 1/(2β) 处取得全局极小值, 超出该阈值后梯度会反向将其拉回; DPO 的 logistic 损失在确定性可分偏好下则会无界推大间隔。对数概率比差值定义为 $h = [\log \pi(\text{chosen}) - \log \pi(\text{rejected})] - [\log \pi_{\text{ref}}(\text{chosen}) - \log \pi_{\text{ref}}(\text{rejected})]$, 前半部分为待训策略模型 $\pi$ 在正负回答上的对数概率差, 后半部分为冻结参考模型 $\pi_{\text{ref}}$ 上的对应差值; 本例中参考模型为均匀分布, 后半部分恒等于 0。
两种目标函数的几何形态截然不同:
- IPO 最小化 $(h - 1/(2\beta))^2$, 当 h 偏离有限目标值 1/(2β) 时无论偏小还是偏大均产生二次惩罚, 因此一旦 h 超过 1/(2β), 梯度便会将其拉回目标点。
- DPO 最小化 $-\log \sigma(\beta h)$ (其中 $\sigma$ 为 sigmoid 函数), 该损失随 h 增大单调递减但仅在无穷远处趋近于 0; 本例中 4 对样本各自拥有独立参数、胜负关系完全可分, 因此梯度持续驱使 h 无界增长。
当 β 取 0.5 时, IPO 的平均 h 收敛并停在 1.0, 对应策略相对参考模型将 chosen 与 rejected 的概率比拉开至 e 倍 (约为 2.7 倍); 而 DPO 训练 400 步后平均 h 已达 4.35871 且尚未停止增长。

本实现通过掩码排除 padding 位置并对回答有效 token 的对数概率取均值, 该归约方式改变了序列长度的缩放尺度, 必须在实验配置中显式声明。针对多 token 回答计算序列对数概率通常存在两种口径:
- 按序列求和: 将回答中所有有效 token 的对数概率直接累加。
- 按长度取均值: 将有效 token 对数概率之和除以有效 token 数量。
由于单个 token 的对数概率均不大于 0, 采用求和口径时回答越长累加值越负, 导致差值 h 随序列长度剧烈缩放; 采用均值口径则消除了序列长度对量纲的直接放大。IPO 的有限收敛目标 1/(2β) 直接作用在 h 上, 一旦切换求和与均值口径, 同一 β 所约束的概率间隔物理含义即发生改变, 因此两种归约口径严禁混用。本例中每条回答仅含 1 个有效 token, 均值与求和在数值上等价, 显式实现掩码均值是为了保证向多 token 序列迁移时口径一致。

偏好优化实现须严格遵循参考模型冻结、同源 prompt 成对标注及 prompt 不计入回答损失三项工程约束; 其中超参数 β 控制收敛目标间隔而非参数更新步长。
三项实现约束的具体规范如下:
- 参考模型冻结: 训练全程关闭参考模型梯度, 仅用其前向对数概率计算 h 的基准项, 防止比较基准随训练漂移。
- 同源成对标注: 每条训练样本须由同一 prompt 下的 chosen 回答与 rejected 回答配对构成。
- 屏蔽 prompt 损失: 对数概率归约仅覆盖回答区间的 token, 代码中将 prompt 区间 token 的标签置为 -100 以从损失计算中剔除。
在 IPO 目标下, β 决定 h 最终收敛的目标位置 1/(2β), β 越小则允许拉开的相对概率间隔越大; 单步参数更新幅度则由优化器学习率独立控制 (本例 SGD 学习率为 0.2)。
此外, 本实验采用无噪声可分玩具样本, 以下三类真实场景边界仍需独立评测:
- 循环或矛盾偏好: 同一对候选在不同标注者之间出现胜负反转。
- 随机标签噪声: 人工或自动偏好集中混入错标样本对。
- 分布外回答泛化: 模型在未见 prompt 或分布外候选回答上的排序表现。

## 怎样验证

固定同一组 4 对单 token 偏好样本、同一冻结均匀参考分布及 400 步训练预算, 分别运行 DPO 与 IPO 训练, 对比训练损失与对数概率比间隔 (log-ratio margin, 即 h), 检验 margin 是否精确收敛至 1/(2β), 而非仅检查训练集偏好准确率。实验代码断言 IPO 末步 margin 与 1 的绝对误差小于 0.001, 且 DPO 末步 margin 严格大于 IPO。
仅凭训练集偏好准确率无法区分两类目标: 本例中两种方法训练结束后各样本对的 h 均大于 0, chosen 概率均高于 rejected, 训练集准确率同为满分, 核心差异体现在 margin 是否收敛于有限目标值; 迁移至长文本实验时, 还须额外控制 chosen 与 rejected 的序列长度差及参考模型初始先验概率, 因为二者均会直接影响 h 的数值尺度。

## 与真实系统的差距

四个独立的条件 logits，验证 loss 的梯度与平衡点，不代表真实偏好泛化，也不说明 IPO 总比 DPO 好。

## 常见误区与自测

当对数概率比间隔超出目标值 1/(2β) 后, IPO 的平方损失会如何作用?

<details><summary>展开解析</summary>

梯度会反向将间隔拉回目标值。平方损失在目标点两侧均施加对称惩罚, 一旦 h 超出 1/(2β), 损失对 h 的梯度即改变符号。
具体而言, IPO 的单样本损失为 $(h - 1/(2\beta))^2$, 对 h 求偏导可得 $2(h - 1/(2\beta))$, 梯度方向严格取决于 h 相对目标值的位置:
- 当 h 小于 1/(2β) 时, 导数为负, 梯度下降驱动 h 增大。
- 当 h 大于 1/(2β) 时, 导数为正, 梯度下降驱动 h 减小并回落至目标值。
- 当 h 等于 1/(2β) 时, 导数为 0, 参数停止沿间隔方向更新。
相比之下, DPO 损失 $-\log \sigma(\beta h)$ 对 h 的导数恒为负值, 仅随 h 增大渐近趋于 0, 因此在可分偏好上会持续推高 h。本例训练 400 步后, IPO 的平均 margin 稳定停在 1.0, 而 DPO 则推升至 4.35871。

</details>
