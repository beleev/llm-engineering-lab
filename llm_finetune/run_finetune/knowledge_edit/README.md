# 知识编辑：改对一个事实，伤到多少邻居

## 直觉

改参数里的事实不像改数据库的一行。共享表示会让一次更新影响相似实体、别名和关联事实。

## 核心原理

线性记忆 W 将键映射到值，秩一更新 ΔW=u vᵀ 让目标键命中新值。加入邻域协方差约束可减少保护键上的变化，但目标与邻居高度重合时存在冲突。

编辑验收分为 efficacy（原问题）、paraphrase（改写/别名）、locality（无关事实）和 portability（需要新事实的关联推理）。本例测前三项的线性代理；别名成功不能替代真实语言改写泛化。

ROME/MEMIT 在真实 Transformer 中还涉及定位、激活收集和求解，本例不是其完整复现。RAG 更新外部证据、记忆条目修订、参数编辑和 machine unlearning 应分开描述。

## 运行

```bash
python -m llm_finetune.run_finetune.knowledge_edit.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

固定旧模型，对同一目标做三种更新，同时输出目标误差与保护邻域误差。真实编辑还要批量累积、撤销、关联问答和校准测试，避免只挑原问题验收。

## 与真实系统的差距

三维线性关联记忆，说明低秩编辑约束，不声称复现 ROME/MEMIT 或 LLM 的事实存储。别名向量是给定的。
