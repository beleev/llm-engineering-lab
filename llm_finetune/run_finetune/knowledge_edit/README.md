# 知识编辑: 改对一个事实, 伤到多少邻居

## 直觉

知识编辑是不重新训练, 直接改模型参数, 让模型对某个问题给出新答案。这组实验用一个最小的线性记忆代替模型: 权重 W = [1, 2, 3], 输入一个 3 维的键 (代表一个问题), 输出是 W 和键的内积 (代表答案); 目标是把键 [1, 0, 0] 的输出从 1 改成 7, 同时看相关邻居键 [0.8, 1, 0] (和目标相似的另一个问题) 与无关键 [0, 0, 1] 的输出被带动了多少。全局修改 (W 的每个数都加 6)、秩一编辑 (只沿目标键的方向改)、约束邻域 (改的同时专门保护邻居) 三种更新都把目标键的输出从 1 改到了 7.0, 但相关邻居的变化分别是 10.8、4.8、0.0475, 无关事实的变化是 6.0、0.0、0.0。改参数里的事实不像改数据库的一行: 同一个 W 被所有键共用, 共享表示会让一次更新波及相似实体、别名和关联事实。

## 核心原理

线性记忆 W 把键映射到值, 秩一更新 ΔW=u vᵀ 沿键方向让目标键命中新值 7.0, 无关键的变化是 0.0。秩一更新是说改动量 ΔW 可以写成一个列向量 u 乘一个行向量 vᵀ; 本例 W 只有一行, u 就是要补上的差 7 − 1 = 6, vᵀ 决定往哪个方向改。秩一编辑取目标键本身的方向, 得到 ΔW = [6, 0, 0], 只改 W 的第一个数: 无关键 [0, 0, 1] 只用到第三个数, 输出不变; 相关邻居 [0.8, 1, 0] 在第一维上有 0.8, 输出被带动 0.8 × 6 = 4.8。加入邻域协方差约束 (本例对邻居方向加 100 倍权重) 把相关邻居的变化从 4.8 压到 0.0475。代码把方向换成 C⁻¹k (k 是目标键, C = I + 100 n nᵀ, I 是单位矩阵, n 是邻居键), 这样解出的 ΔW 是所有能让目标命中 7 的改动里, 让「ΔW 各数平方和 + 100 × 邻居输出变化的平方」最小的那一个; 这个式子在说邻居的输出每变一点, 代价按 100 倍算。本例解出 ΔW 约为 [6, −4.75, 0]: 第一个数照样加 6, 第二个数减 4.75, 正好把邻居被带动的部分抵消掉。目标与邻居高度重合时, 两个要求会冲突: 极端情况下邻居就是目标键本身, 同一个键不可能既输出旧值又输出新值。

编辑验收分四项: efficacy (原问题)、paraphrase (改写/别名)、locality (无关事实) 和 portability (需要新事实的关联推理)。efficacy 看被编辑的那个问题本身答对没有; paraphrase 看换个说法或换个名字再问, 能不能得到新答案; locality 看不该变的事实有没有被误改; portability 看要用新事实再推一步的问题有没有跟着更新。本例用线性代理测前三项: 目标键测 efficacy, 别名键 [0.95, 0.05, 0] (和目标键几乎同向, 代表同一实体的另一个名字) 测 paraphrase, 无关键测 locality。别名键原来的输出是 1.05, 三种方法改完后的回答是 7.05 / 6.75 / 6.5124; 约束邻域比秩一编辑低, 是因为它把 W 的第二个数调低了 4.75, 别名键在第二维上有 0.05, 跟着被拉低了约 0.24。别名成功不能替代真实语言的改写泛化: 本例的别名向量是手工给定的, 真实模型里一句改写问法对应什么内部表示, 要用真实语言任务去测。

ROME/MEMIT 在真实 Transformer 里还要定位层、收集激活和求解, 本例不是它们的完整复现。ROME 是在真实语言模型里改单条事实的方法: 先找出这条事实主要由哪一层的 MLP 权重决定, 再收集大量文本在这一层的激活 (中间计算结果), 统计出键的协方差矩阵 C, 最后解出权重改动; MEMIT 是一次改很多条事实的版本。C 记录了哪些键方向经常出现, 常出现的方向改动代价高, 这就是协方差约束这个名字的来源; 本例跳过了定位和统计, W、键和 C 都是手写的三维小例子。RAG 更新外部证据、记忆条目修订、参数编辑和 machine unlearning 是四件事, 要分开描述: RAG (retrieval-augmented generation, 回答前先检索外部文档) 改的是检索库里的文档, 模型参数不动; 记忆条目修订改的是系统另外存的记忆记录; 参数编辑直接改权重, 本例做的就是这个; machine unlearning (机器遗忘) 是让模型表现得像没学过某些数据。

## 怎样验证

固定同一个旧模型 W = [1, 2, 3] 和同一个目标 (键 [1, 0, 0] 改为 7), 做全局加常数、秩一编辑、约束邻域三种更新, 同时输出目标误差、相关邻居和无关事实的变化, 以及别名键的回答。判定方法: 代码先断言三种方法的目标输出与 7 相差不到 1e-8, 在这个前提下比较谁对邻居和无关事实改得少; 还断言秩一编辑的无关事实变化为 0, 约束邻域的邻居变化小于秩一编辑。真实编辑还要测批量累积 (连续改很多条后, 前面改的还在不在)、撤销 (能不能把改动退回去)、关联问答和校准 (模型对新答案的把握程度是否合理), 不能只挑原问题验收。

## 与真实系统的差距

三维线性关联记忆，说明低秩编辑约束，不声称复现 ROME/MEMIT 或 LLM 的事实存储。别名向量是给定的。

## 常见误区与自测

原问题编辑成功, 能说明知识已可靠更新吗?

<details><summary>展开解析</summary>

不能。目标命中只覆盖 efficacy 这一项。一步步看: 本例三种方法都把目标键的输出改到了 7.0, 只看原问题, 三者一模一样。可是全局修改让相关邻居变了 10.8、无关事实变了 6.0, 秩一编辑仍让邻居变了 4.8, 只有约束邻域把邻居变化压到 0.0475; 别名键的回答也各不相同 (7.05 / 6.75 / 6.5124)。所以原问题答对时, 改写泛化、无关事实保持和关联推理都可能单独失败, 每一项都要分别测。
