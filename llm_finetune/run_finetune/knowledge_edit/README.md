# 知识编辑: 改对一个事实, 伤到多少邻居

## 直觉

知识编辑旨在不执行全量重训练的前提下局部修正模型权重, 使模型针对特定事实查询返回更新后的目标值。本组实验以三维线性关联记忆模拟参数化知识库: 初始权重向量 W 为 [1, 2, 3], 输入 3 维查询键向量时输出二者内积; 编辑目标是将目标键 [1, 0, 0] 的输出由 1 精确修改为 7, 同时监测方向重叠的相关邻居键 [0.8, 1, 0] 与正交无关键 [0, 0, 1] 的输出偏移幅度。
三种参数编辑方案均将目标键输出从 1 精确更新至 7.0, 但对邻域及无关记忆的连带扰动差异显著:
- 全局常数平移 (W 各分量统一加 6): 相关邻居输出偏移 10.8, 无关事实输出偏移 6.0。
- 无约束秩一编辑 (仅沿目标键方向更新): 相关邻居输出偏移 4.8, 无关事实输出偏移降至 0.0。
- 邻域协方差约束编辑 (精确命中目标的同时惩罚邻居偏移): 相关邻居输出偏移压缩至 0.0475, 无关事实输出偏移保持 0.0。
修改神经网络权重中的事实不同于按主键更新关系型数据库记录: 同一组权重被所有查询共享, 特征子空间的非正交重叠会使单次局部编辑不可避免地牵动相似实体、同义别名与下游关联推理。

## 核心原理

在线性关联记忆中, 秩一更新 $\Delta W = u v^\top$ 沿目标键方向修正权重, 可使目标键精确命中 7.0 且正交无关键偏移为 0.0。秩一更新将参数增量分解为列向量 u 与行向量 $v^\top$ 的外积; 本例中 W 为单行向量, 标量残差 u 等于目标差值 7 减 1 即 6, 行向量 $v^\top$ 则指定权重空间中的写入方向。
无约束秩一编辑直接取目标键方向, 解得增量 [6, 0, 0], 仅修改 W 的第一维分量:
- 正交无关键 [0, 0, 1] 仅激活第三维分量, 输出完全不变。
- 相关邻居键 [0.8, 1, 0] 在第一维具有 0.8 的投影分量, 输出被连带拉高 0.8 乘 6 即 4.8。
引入邻域协方差约束 (本例对邻居键方向施加 100 倍惩罚权重) 可将相关邻居偏移从 4.8 压低至 0.0475。算法将更新方向修正为与 $C^{-1} k$ 成比例 (其中 k 为目标键, 协方差矩阵 $C = I + 100 n n^\top$, I 为单位矩阵, n 为邻居键), 该闭式解等价于在满足目标键精确输出 7 的等式约束下, 最小化「$\Delta W$ 的二范数平方加上 100 倍邻居输出变化平方」, 对邻居输出的任何偏移施加百倍惩罚。本例求解得增量约为 [6, −4.75, 0]: 第一维仍增加 6 以命中目标, 同时第二维下调 4.75 以精确抵消邻居键在第一维受到的牵连。
当目标键与需保护的邻居键高度共线时, 命中新值与保持旧值两项约束将产生本质冲突: 极限情形下若两键完全重合, 同一线性映射无法对完全相同的输入同时输出两个不同数值。

完整的知识编辑验收须覆盖 efficacy (原问题命中)、paraphrase (同义改写与别名泛化)、locality (无关事实保持) 与 portability (基于新事实的多跳关联推理) 四个正交维度。
四项指标的评测侧重点如下:
- efficacy: 检验直接用于编辑的那条原始查询是否稳定输出新事实。
- paraphrase: 检验更换句式表述或实体别名后能否泛化输出同一新事实。
- locality: 检验邻近相似实体及无关背景事实是否免受连带篡改。
- portability: 检验依赖该更新事实继续向后推理的组合问题是否同步更新 (如更新某国首都后询问新首都所在时区)。
本例通过三维线性代理量化前三个维度:
- 以目标键检验 efficacy。
- 以方向高度接近目标键的别名键 [0.95, 0.05, 0] 检验 paraphrase。
- 以相关邻居键与正交无关键检验 locality。
别名键在编辑前的初始输出为 1.05, 全局修改、秩一编辑与邻域约束编辑后的输出依次为 7.05、6.75 与 6.5124; 邻域约束方案的别名响应略低于无约束秩一编辑, 原因在于其将 W 第二维下调了 4.75, 而别名键在第二维恰好带有 0.05 的非零分量, 进而被连带拉低约 0.24。
需要指出, 线性代理上的别名数值接近目标并不能替代真实自然语言的改写泛化证明: 本例的别名向量为人工构造, 真实语言模型中句法改写映射为何种隐层激活须在真实文本基准上实测。

在真实 Transformer 语言模型中应用 ROME 或 MEMIT 还须执行因果层定位、大规模激活协方差统计与多层联合求解, 本例三维线性代理并非其完整复现。
真实模型中 ROME 编辑单条事实的完整管线包含三步:
1. 通过因果中介分析定位承载目标事实召回的关键中层 MLP 投影矩阵。
2. 在大规模通用语料上前向采集该层输入键激活, 估计背景键分布的二阶矩协方差矩阵 C。
3. 求解带协方差约束的秩一权重增量并写回原矩阵; MEMIT 则进一步将更新分摊至连续多层以支持成批事实同时写入。
背景协方差矩阵 C 刻画了自然语料高频激活的特征方向, 对高频方向施加高惩罚可保护通用语言能力; 本例省略了因果定位与语料统计环节, W、查询键与 C 均为手工给定的三维教学张量。
工程实践中还须严格区分四类不同的知识修正技术路径:
- RAG 外部知识库更新: 直接替换检索索引中的外部文档证据, 模型参数完全不变。
- 显式外部记忆修订: 增删改智能体系统外挂的键值或图谱记忆条目。
- 参数化知识编辑: 如本例所示直接对模型内部权重施加局部代数修正。
- machine unlearning (机器遗忘): 消除特定训练样本或敏感能力在模型参数与输出分布上留下的记忆痕迹。

## 怎样验证

固定同一初始权重 W ([1, 2, 3]) 与同一编辑目标 (将键 [1, 0, 0] 的输出更新为 7), 依次执行全局加常数、无约束秩一编辑与邻域协方差约束编辑三种更新, 同步输出目标键误差、相关邻居键与正交无关键的输出变化量以及别名键响应。
自动化校验遵循两项断言标准:
- 首先断言三种编辑方案在目标键上的输出与真值 7 的绝对误差均小于 1e-8, 在同等满足 efficacy 的前提下横向对比邻域扰动与无关事实保持能力。
- 进一步断言无约束秩一编辑在正交无关事实上的变化量严格为 0, 且邻域约束编辑在相关邻居上的偏移严格小于无约束秩一编辑。
在真实大模型上评估参数编辑系统时, 除单步原问题命中外还必须补充四项压力测试:
- 序列与批量累积退化: 连续编辑成百上千条事实后, 先前写入的事实是否被覆盖以及通用能力是否崩塌。
- 可逆撤销能力: 能否精确回滚单次错误编辑而不残留参数扰动。
- 多跳关联问答 (portability): 依赖新事实的下游推理链是否同步生效。
- 编辑后概率校准: 模型赋予新事实及邻近未编辑事实的置信度是否合理。

## 与真实系统的差距

三维线性关联记忆，说明低秩编辑约束，不声称复现 ROME/MEMIT 或 LLM 的事实存储。别名向量是给定的。

## 常见误区与自测

被编辑的原问题精确输出新答案, 能否证明模型内部知识已完成可靠更新?

<details><summary>展开解析</summary>

不能。原问题命中新值仅验证了 efficacy 单一维度。在本例中, 三种参数修改方案均将目标键输出精确更新至 7.0, 若仅观测原问题读数则三者表现完全一致; 但它们对模型其余记忆造成的副作用截然不同:
- 全局常数平移使相关邻居输出偏移 10.8, 正交无关事实偏移 6.0。
- 无约束秩一编辑虽保住了正交无关键, 仍使相关邻居偏移 4.8。
- 唯有邻域协方差约束编辑将相关邻居偏移压低至 0.0475。
同时, 三种方案在别名键上的泛化输出也分化为 7.05、6.75 与 6.5124。因此即使原问题完全答对, 同义改写泛化 (paraphrase)、邻域与无关事实保持 (locality) 以及多跳关联推理 (portability) 仍可能各自失效, 验收时必须分项独立评测。

</details>
