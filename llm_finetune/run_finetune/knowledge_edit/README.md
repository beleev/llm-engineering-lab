# 知识编辑: 改对一个事实, 伤到多少邻居

## 直觉

三种更新都把目标键的输出从 1 改到了 7.0, 但相关邻居的变化分别是 10.8、4.8、0.0475, 无关事实的变化是 6.0、0.0、0.0。改参数里的事实不像改数据库的一行: 共享表示会让一次更新波及相似实体、别名和关联事实。

## 核心原理

线性记忆 W 把键映射到值, 秩一更新 ΔW=u vᵀ 沿键方向让目标键命中新值 7.0, 无关键的变化是 0.0。加入邻域协方差约束 (本例对邻居方向加 100 倍权重) 把相关邻居的变化从 4.8 压到 0.0475; 目标与邻居高度重合时, 两个要求会冲突。

编辑验收分四项: efficacy (原问题)、paraphrase (改写/别名)、locality (无关事实) 和 portability (需要新事实的关联推理)。本例用线性代理测前三项, 别名键 [0.95, 0.05, 0] 的回答是 7.05 / 6.75 / 6.5124; 别名成功不能替代真实语言的改写泛化。

ROME/MEMIT 在真实 Transformer 里还要定位层、收集激活和求解, 本例不是它们的完整复现。RAG 更新外部证据、记忆条目修订、参数编辑和 machine unlearning 是四件事, 要分开描述。

## 运行

```bash
python -m llm_finetune.run_finetune.knowledge_edit.demo
```

需要 Python ≥ 3.10, 依赖使用仓库的 numpy / torch; 不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

固定同一个旧模型 W 和同一个目标 (键 [1, 0, 0] 改为 7), 做全局加常数、秩一编辑、约束邻域三种更新, 同时输出目标误差、相关邻居和无关事实的变化; 真实编辑还要测批量累积、撤销、关联问答和校准, 不能只挑原问题验收。

## 与真实系统的差距

三维线性关联记忆，说明低秩编辑约束，不声称复现 ROME/MEMIT 或 LLM 的事实存储。别名向量是给定的。

## 常见误区与自测

原问题编辑成功, 能说明知识已可靠更新吗?

<details><summary>展开解析</summary>

不能。目标命中只覆盖 efficacy; 本例三种方法目标都是 7.0, 邻居变化却从 10.8 到 0.0475。改写泛化、无关事实保持和关联推理都可能单独失败。
