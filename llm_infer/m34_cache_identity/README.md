# 缓存身份：相同 token 不一定能复用

KV 的身份不仅是 token，还包含解释这些 token 的模型与输入约定。命中更快，也可能泄露其他租户是否使用过某个前缀。

## 怎么跑

```bash
python -m llm_infer.m34_cache_identity.demo
```

## 先看这几件事

- 缓存键绑定授权共享域、不可变模型标识、adapter 标识及 token 前缀；多模态还需要绑定内容摘要。仅同 token 无法证明 KV 相同。
- 共享域由可信身份网关决定。客户端声明的租户或 salt 不能覆盖鉴权结果；同域可复用，跨域隔离需要明确的命名空间。
- salt 减少特定缓存侧信道风险，不提供服务进程、网络或显存隔离。命中/未命中的合成代价仅展示泄露渠道，不能报告成真实攻击率。

## 怎样验证

先由 A 身份写缓存，再改租户、模型/adapter 版本或身份声明；核对命中与正确性，同域可复用，跨域不共享，错误版本不能静默返回旧值。

### 跨租户共用

| 指标 | 实际结果 |
| --- | --- |
| 缓存命中 | true |
| 返回值匹配模型约定 | true |
| 身份越权被拒绝 | false |
| 跨隔离域复用 | true |
| 缓存条目 | 1 |
| 合成命中代价 | 1 |

命中 1 / 未命中 5 是合成代价，不是测量时延或攻击成功率。salt 只隔离缓存键，不隔离服务进程、网络和显存；多模态还要绑定内容摘要。
