# 端侧预算：能放下、能跑快、能持续吗

## 直觉

手机上能加载模型只是第一关。上下文缓存、功率和持续运行后的降频都可能成为瓶颈。

## 核心原理

总内存包括权重、KV cache、工作区和运行时。量化权重不自动量化 KV；长上下文下，缓存可能吞掉原本省下的内存。

简化 roofline 取 max(运算量/算力, 搬运量/带宽)，再用功率×时间估计每 token 能量。热降频会改变持续带宽与算力；冷启动峰值不能代表十分钟后的速度。

联合设计从目标质量和设备约束出发，选择模型宽深、量化格式、编译器布局与内核；需要算子支持才能兑现理论压缩。电池寿命还取决于整机其他负载和电源效率。

Green AI 应报告每成功任务能耗、硬件利用率、重试和生命周期假设。低功率设备若运行更久，不一定总能量更低；没有设备实测就不能给碳排或续航承诺。

## 运行

```bash
python -m llm_infer.m31_edge_budget.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

全部参数是公开假设：1B 参数、2 GiB 内存等。切换精度和热态观察可行性及成本；真实选型还需测量量化质量、温度、功率曲线和电池。

## 与真实系统的差距

预算模型，不是手机或芯片跑分，不提供特定设备续航承诺。真实能耗需扣除/报告空闲基线并说明测量边界。
