# 多语言: 采样、分词与翻译偏差

## 直觉

本组实验基于英中两种语言各两句短语 (英文为 enable mail 与 disable mail, 中文为「开启邮件」与「不要开启邮件」) 构建经验频率分类器: 统计训练样本中各短语关联的二元标签 (开启记 1, 不开启记 0), 预测时返回多数票标签。在仅含英文词条的初始词表下, 「不要开启邮件」因无法匹配整词而被逐字切分为 6 个单字 token; 扩充「不要」「开启」「邮件」 3 个中文词条后, 同一短语可按整词切分为 3 个 token。
在固定 160 条训练样本预算下对比两种采样策略:
- 按自然语料频率采样 (中文语料占比 10%, 即每次抽样有 10% 概率抽中中文), 中文仅分到 21 条样本。
- 按语言均衡采样 (两种语言各占 50% 采样概率), 中文样本增至 82 条。
表达相同语义时, 不同语言在非对称词表下消耗的 token 预算不同; 而在同一总样本预算下, 自然频率采样还可能导致低资源语言严重欠训练。

## 核心原理

本实验对英中短语执行实际随机抽样并按经验频率估计类别标签, 横向对比按规模采样 ([139, 21])、按语言均衡采样 ([78, 82]) 与错误翻译标签三组条件。经验频率分类器不具备跨句泛化能力, 仅统计训练集内各短语的出现频次及标签多数票, 方括号内数字分别对应 160 条总预算中英文与中文实际分到的样本条数。同时, 正向最长匹配分词器量化了同一句中文的 token 膨胀比 (6 对比 3): 初始词表不含中文多字词条, 「不要开启邮件」被迫逐字切分为 6 个 token, 增补 3 个中文词条后缩减为 3 个 token。多语言实验核算算力预算时需显式统计实际消耗的 token 数而不能仅按句数对齐: 同一语义在不同词表下的 token 数相差一倍, 仅按句数对齐会使各语言实际消耗的序列预算与上下文容量互不相等。

跨语言迁移可通过共享子词词表、embedding 与主干参数实现, 也可借助双语平行语料对齐隐层表示或跨语言共享 adapter 模块。
常见跨语言参数共享与对齐机制包括:
- 共享子词与 embedding: 将多语言文本映射至同一词表空间与输入向量矩阵。
- 共享主干参数: 由同一套 Transformer 权重联合建模多种语言。
- 平行语料对齐: 利用互译句对拉近不同语言在隐空间中的语义表示。
- 跨语言共享 adapter: 在冻结主干中插入供多语言共用的轻量化适配模块。
然而, 参数共享并不天然保证正向迁移: 高资源语言的梯度往往主导参数更新方向, 如本例按自然频率采样时英文 139 条对比中文 21 条, 共享参数几乎完全受英文样本支配。
因此验证跨语言迁移效果需设立三组受控基线:
- 单语基线: 仅使用目标低资源语言数据独立训练。
- 自然混训: 按原始语料规模比例混合多语言训练。
- 平衡混训: 提高低资源语言采样权重后混合训练。
唯有对比三组基线, 才能区分参数共享带来的是正迁移增益还是跨语言干扰。

直接翻译构建的数据集容易丢失否定极性、敬语层级、习语搭配与地域常识: 本例在翻译标签偏差条件下将「不要开启邮件」的标签误标为「开启」, 直接导致中文否定句判定由正确变为错误。具体机制在于, 翻译污染条件下训练集中「不要开启邮件」对应的监督标签被置为 1 (开启), 频率分类器统计出的多数票标签随之变为 1, 使「中文否定正确」指标从 true 翻转为 false; 由于输入文本本身未变而监督标签反转, 继续增加此类样本只会强化错误映射。
多语言评测集必须独立保留母语原生题、代码混合文本 (单句内多语种混用)、不同文字系统及本土文化语境样本, 这些真实语言现象无法由英文基准直译覆盖。评测标签须经母语使用者独立核验并完整记录译者分歧, 因为否定词脱落或语用失真唯有母语者能够可靠识别, 而译者存在分歧的样本往往对应跨语言语义不等价的边界情形, 需在测试集中显式标注。

多语言温度采样按 p(language) ∝ n^α 分配采样概率, 通过指数超参数 α 连续调节低资源语言的上采样倍率。
设 n 为某语种的原始语料规模, α 取值于 0 到 1 之间:
- 当 α 等于 1 时, 退化为按原始语料规模比例采样 (对应本例英文 139 条对比中文 21 条)。
- 当 α 等于 0 时, 转化为各语种等概率均匀采样 (对应本例英文 78 条对比中文 82 条)。
- 当 α 取 0 到 1 之间的折中值时, 既能提高低资源语言的采样占比, 又避免极端过采样。
实验需同步报告各语种的数据重复率、任务准确率、校准误差及单次正确回答的 token 成本, 因为上采样会使小规模语料被高频重复抽取。在本例中, 中文语料池仅包含 2 句不重复短语, 即使均衡采样将中文配额提升至 82 条, 这 82 条样本也只是对既有两句短语的重复抽样, 并不等价于拓展了新的语义覆盖。

## 怎样验证

固定 160 条样本采样预算与同一个经验频率短语分类器, 按以下步骤验证:
1. 分别运行按自然频率采样、按语言均衡采样与错误翻译标签三组条件。
2. 对照「中文否定正确」布尔指标, 定位预测错误源于训练样本覆盖不足还是翻译标签污染。
本实验采用的查表式短语分类器不具备跨语言表示迁移能力, 真实多语言大模型评测须留出未见实体与母语原生表达。
具体归因判据如下:
- 按自然频率采样时中文虽仅分到 21 条样本, 「中文否定正确」依然为 true, 表明该玩具词表下的样本覆盖已足够支撑多数票估计。
- 错误翻译标签条件下中文虽均衡分到 82 条样本, 「中文否定正确」却变为 false, 确证错误源于翻译标签极性反转而非样本量不足。
由于本例分类器仅记忆已知短语频次、无法泛化至未见句式, 真实多语言评测必须构建独立于训练集的未见实体集与母语者原生测试题。

## 与真实系统的差距

两种受控语言模板，不是低资源语言 benchmark。分词器扩词还需处理新增 embedding、旧分词兼容和训练成本。

## 常见误区与自测

完成语言均衡采样训练后, 为何仍须使用母语原生题独立评测?

<details><summary>展开解析</summary>

机器翻译或跨语言投射数据容易引入标签反转与文化语境偏差: 本例在语言均衡采样后中文样本虽达 82 条, 一旦采用丢失否定语义的翻译标签, 中文否定句即被判错。语言均衡采样仅改变了各语种的训练样本配额, 将中文样本从 21 条提升至 82 条, 但无法校验或纠正监督信号本身的语义失真。在错误翻译标签条件下, 尽管中文同样拥有 82 条训练样本, 「不要开启邮件」因翻译环节遗漏否定极性而被标为开启, 分类器据此学到错误映射, 致使「中文否定正确」由 true 变为 false。若测试集同样由同源翻译流程生成, 测试标签会携带相同偏差并与错误预测迎合, 从而掩盖缺陷; 唯有使用母语者独立撰写的原生测试题验收, 才能暴露翻译引入的系统性偏差。

</details>
