# 多语言：采样、分词与翻译偏差

## 直觉

同样一句意思，不同语言可能消耗不同数量的 token；同样一份数据预算，也可能几乎没有训练到低资源语言。

## 核心原理

实验实际采样双语短语并估计类别，分别比较按规模、按语言均衡和错误翻译标签。简化分词器计算相同语义的 token 膨胀，预算应按 token 而非句数对齐。

跨语言迁移可以共享词嵌入、子词与参数，也可以用平行语料对齐表示或共享 adapter。共享并不保证正迁移：高资源梯度可能压过低资源语言，需做单语、混训、平衡混训对照。

翻译测试集可能抹掉否定、敬语、习语和地方常识。保留原生作者题、代码混合文本、不同文字系统与文化语境；由本地使用者校验标签，记录译者分歧。

温度采样 p(language) ∝ n^α 用 α 调节低资源上采样；同时报告各语言数据重复率、准确率、校准与每正确任务 token 成本。小语种反复重复同一数据不等于获得新覆盖。

## 运行

```bash
python -m llm_train.m26_multilingual.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

先跑三个采样条件，再核对错误来自训练覆盖还是翻译标签。当前短语分类不验证通用跨语言语义迁移；真实模型需留出未见实体和原生表达。

## 与真实系统的差距

两种受控语言模板，不是低资源语言 benchmark。分词器扩词还需处理新增 embedding、旧分词兼容和训练成本。

## 常见误区与自测

语言均衡训练后还要单独测原生题，原因是什么？
