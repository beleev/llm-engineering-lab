# 多语言: 采样、分词与翻译偏差

## 直觉

这组实验用两种语言各两句短语 (英文 enable mail / disable mail, 中文 开启邮件 / 不要开启邮件) 做一个最简单的分类器: 从训练样本里数每句短语对应的标签 (开启记 1, 不开启记 0), 预测时按多数标签回答。「不要开启邮件」在原词表里被切成 6 个单字 token, 加 3 个本地词条后是 3 个: 原词表只认识英文词, 遇到中文只能一个字一个字地切, 加上「不要」「开启」「邮件」三个词条后才能整词切。160 条预算按频率抽 (每次抽样有 10% 的概率抽到中文, 对应中文语料只占一成), 中文只分到 21 条, 均衡后 (两种语言各 50%) 是 82 条。同样一句意思, 不同语言消耗的 token 数不同; 同样一份数据预算, 也可能几乎没训练到低资源语言。

## 核心原理

实验实际抽样英中两种短语并从频率估计标签, 比较按规模抽样 ([139, 21])、按语言均衡 ([78, 82]) 和错误翻译标签三个条件。「从频率估计标签」是指分类器不理解句子, 只记住训练集里每句短语各出现几次、标签是什么, 预测时取多数; 方括号里是 160 条样本里英文和中文各分到多少条。简化分词器算出同一句话的 token 膨胀 (6 对 3): 分词器从左到右找词表里能匹配的最长词条, 原词表里没有任何中文词条, 「不要开启邮件」只能逐字切成 6 个 token, 加了 3 个中文词条后切成 3 个。预算要按 token 而不是句数对齐, 因为同一句话在两个词表下 token 数差一倍, 按句数对齐的预算给每种语言的 token 容量并不相等。

跨语言迁移可以共享词嵌入、子词与参数, 也可以用平行语料对齐表示或共享 adapter。跨语言迁移是指让模型在高资源语言上学到的能力也能用在低资源语言上: 共享词嵌入和子词是让两种语言的文本进同一张词表、同一组向量; 共享参数是让同一个模型同时学两种语言; 平行语料是同一句话的两种语言版本, 用来把两种语言的表示拉到一起; adapter 是插在模型里的一小块可训练参数, 可以几种语言共用。共享不保证正迁移: 高资源语言的梯度可能压过低资源语言, 本例按频率抽时英文 139 条对中文 21 条, 参数更新几乎全由英文样本决定。所以要做单语、混训、平衡混训三组对照: 只用目标语言训、按自然比例混着训、按语言均衡混着训, 三组比过才知道共享到底帮了还是害了。

翻译测试集可能抹掉否定、敬语、习语和地方常识: 本例把「不要开启邮件」的标签翻成「开启」, 否定判断就从正确变成错误。机制是: 翻译标签条件下, 训练样本里「不要开启邮件」这句话的标签被写成了 1 (开启), 分类器从频率学到的多数标签也就是 1, 于是「中文否定正确」从 true 变成 false; 句子本身一个字没改, 错的是标签, 所以多喂这种数据只会把错误学得更牢。测试集要保留原生作者题、代码混合文本、不同文字系统与文化语境: 原生作者题是母语使用者直接写的题而不是翻译过来的, 代码混合文本是一句话里夹着两种语言, 这些在翻译测试集里都不会出现。标签由本地使用者校验, 记录译者分歧, 因为只有本地使用者能看出一句翻译是否丢了否定或礼貌语气, 两位译者意见不同的题本身就是测试集里最该标出来的题。

温度采样 p(language) ∝ n^α 用 α 调低资源语言的上采样比例: n 是某种语言的语料量, α 是 0 到 1 之间的指数; α 等于 1 就是按语料规模抽 (本例的 139 对 21), α 等于 0 就是每种语言一样多 (本例的 78 对 82), 中间的 α 让低资源语言被抽到的比例比它的语料占比高一些, 又不至于完全均衡。同时报告各语言的数据重复率、准确率、校准与每正确任务 token 成本 (答对一道题平均花多少 token), 因为上采样之后低资源语言的样本会被反复抽到, 重复率就是衡量这一点的数。中文池只有 2 句不同短语时, 均衡抽到 82 条也只是反复重复同一批数据, 不等于新覆盖: 82 条里每一条都是那两句话之一, 分类器多看几十遍也没有学到任何新句子。

## 怎样验证

固定 160 条抽样预算和同一个短语分类器, 先跑按频率、语言均衡、翻译标签三个条件, 再核对「中文否定正确」的错误来自训练覆盖还是翻译标签; 当前短语分类不验证通用跨语言语义迁移, 真实模型要留出未见实体和原生表达。判定方法是看「中文否定正确」这个布尔读数: 按频率只抽到 21 条中文它仍是 true, 说明本例的覆盖够用; 翻译标签条件下中文有 82 条它却是 false, 说明错误来自标签而不是条数。本例的分类器只会数短语, 不会理解没见过的句子, 真实模型的多语言评测要留出训练集里没出现过的实体和母语者写的原生表达。

## 与真实系统的差距

两种受控语言模板，不是低资源语言 benchmark。分词器扩词还需处理新增 embedding、旧分词兼容和训练成本。

## 常见误区与自测

语言均衡训练后还要单独测原生题, 原因是什么?

<details><summary>展开解析</summary>

因为翻译数据可能带来标签和语境偏差: 本例均衡采样后中文样本 82 条, 否定句一旦用翻译标签就判错。均衡采样只调整训练分布, 代替不了原生语言的独立验收。一步步看: 均衡采样解决的是「中文样本太少」, 它把中文从 21 条提到 82 条; 但这 82 条的标签对不对, 均衡采样管不了。翻译标签条件下中文同样是 82 条, 「不要开启邮件」的标签在翻译时丢了否定, 分类器学到的就是错的, 「中文否定正确」从 true 变成 false。如果测试集也是翻译来的, 它会带着同样的错误, 测出来反而是「对」的; 只有用母语者直接写的原生题去测, 才能发现否定被翻丢了。
