# 数据课程: 相同样本数, 学到的一样吗

## 直觉

同样 960 条样本: 随机 9:1 配比学到斜率 1.5383, 测试 MSE 0.261668; 由窄到宽的课程学到 2.0011, MSE 5e-06。数据选择是在预算内决定下一步学什么: 容易的窄域样本有助于起步, 但一直重复它, 预算就花在已经学会的截距上。

## 核心原理

本例先学截距再学斜率: 窄域 (x 集中在 0 附近) 主要约束截距, 宽域 (x 在 ±2 之间) 才提供斜率信息。课程前 40 步只喂窄域、后 80 步喂宽域; 主动策略每步先试算两个域的候选梯度, 选验证损失更低的那个。训练池、选域用的验证集和最终测试集分别构造。

一阶影响近似只看验证梯度与样本梯度的内积; 完整影响函数还要 Hessian 逆或它的近似。高损失样本不能直接叫高价值样本: 异常标注也会一直高损失。

真实语料先记录来源、许可证、用途与版本, 再做文档去重、语言识别、PII 检测和切分。语言识别要允许混合语言和不确定; PII 正则有漏检与误报, 替换后还要复查上下文。低资源语言不应因质量分数偏低被整体删掉。

长度课程改的是有效 token、padding、位置分布和训练难度; SFT 还要控制任务与回答长短。报告时写每域 token 和总 FLOPs; 继续预训练要保留旧域回放, 并测遗忘。

同配比乱序对照把窄域 320、宽域 640 条的配比原样保留, 只打乱域顺序, 测试 MSE 2e-06, 和课程的 5e-06 同一量级。9:1 随机基线 (880 / 80 条) 同时改变了配比, 它和课程的差异不能全归因于顺序。

## 运行

```bash
python -m llm_train.m23_data_curriculum.demo
```

需要 Python ≥ 3.10, 依赖使用仓库的 numpy / torch; 不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

固定模型、随机种子和 960 条样本预算, 比较静态配比、课程、主动选域三种策略的测试 MSE; 再把验证分布改偏, 检查主动选择是否过拟合验证域, 额外的候选梯度计算要计入总成本。

## 与真实系统的差距

二维回归机制实验。验证分布若错误，主动选择也会偏；没有证明课程在 LLM 上普遍更好。

## 常见误区与自测

主动选域的训练样本数相同, 就能称为算力公平吗?

<details><summary>展开解析</summary>

不能。主动策略每步多算两个域的候选梯度和验证损失; 样本预算相同只控制了一种资源, 不能据此宣布总算力公平。
