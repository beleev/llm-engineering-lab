# 数据课程: 相同样本数, 学到的一样吗

## 直觉

这组实验用一个只有两个参数的线性回归 (预测值 = 截距 + 斜率 × x, 真值是截距 1、斜率 2) 来比较三种挑训练数据的策略。训练数据来自两个域:
- 窄域的 x 都挤在 0 附近。
- 宽域的 x 均匀散在 -2 到 2 之间。
三种策略都只许用 960 条样本。同样 960 条样本:
- 随机配比: 9:1 (按两个域的语料规模抽, 窄域 880 条、宽域 80 条), 学到斜率 1.5383, 测试 MSE 0.261668 (MSE 是测试集上预测值和真值之差的平方取平均, 越小越准)。
- 由窄到宽的课程: 先喂窄域再喂宽域 (窄域 320 条、宽域 640 条), 学到 2.0011, MSE 5e-06。
数据选择是在预算内决定下一步学什么: 容易的窄域样本有助于起步, 但一直重复它, 预算就花在已经学会的截距上, 斜率一直学不到。

## 核心原理

本例先学截距再学斜率: 窄域 (x 集中在 0 附近) 主要约束截距, 宽域 (x 在 ±2 之间) 才提供斜率信息。原因是 x 接近 0 时「斜率 × x」几乎等于 0, 预测值基本只由截距决定, 所以窄域样本只能把截距推向 1, 对斜率几乎没有拉力; 宽域的 x 够大, 斜率错多少预测就错多少, 梯度才会推动斜率。
两种策略的做法:
- 课程前 40 步只喂窄域、后 80 步喂宽域 (每步一批 8 条, 120 步共 960 条)。
- 主动策略每步先试算两个域的候选梯度, 选验证损失更低的那个, 也就是分别用两个域的数据各试着更新一步, 看哪个更新让验证集上的损失更低, 就选那个域来正式更新。
训练池、选域用的验证集和最终测试集分别构造:
- 训练池是两个域各 240 条带噪声的样本。
- 验证集是 -2 到 2 之间的 81 个点。
- 测试集是 -1.9 到 1.9 之间的 101 个点。
选域时看的数据和最终打分的数据不是同一份。

一阶影响近似只看验证梯度与样本梯度的内积; 完整影响函数还要 Hessian 逆或它的近似。影响函数回答的问题是「多学这条样本一步, 验证损失会变多少」: 沿样本梯度走一小步, 验证损失的变化在一阶近似下等于步长乘以验证梯度和样本梯度的内积, 内积越大这条样本越有用。本例的主动策略没有算内积, 而是把这一步真的试走一遍再量验证损失, 等于直接算这个变化量; 完整影响函数还要再乘 Hessian (损失函数的二阶导矩阵) 的逆, 修正曲面弯曲对这一步的放大或缩小, 算起来贵得多。高损失样本不能直接叫高价值样本: 异常标注也会一直高损失, 模型怎么学都学不对它, 按损失挑样本会一直把预算花在这种噪声上。

真实语料先记录来源、许可证、用途与版本, 再做文档去重、语言识别、PII 检测和切分。
各环节的要点:
- 先记来源和许可证, 是因为之后发现某批数据不能用时要知道该删哪些; 记版本, 是为了同一份语料改过之后还能对上实验结果。
- 语言识别要允许混合语言和不确定: 一篇文档里中英夹杂很常见, 强行贴一个语言标签, 要么误删要么误留。
- PII (personally identifiable information, 姓名、电话、邮箱这类能认出具体个人的信息) 常用正则表达式找, PII 正则有漏检与误报, 替换后还要复查上下文, 因为把一串数字当电话号码删掉, 可能把一句话删得不通。
- 低资源语言不应因质量分数偏低被整体删掉: 用一个统一的质量分数筛, 低资源语言的文本分数普遍偏低, 一刀切会把整门语言连同其中的好样本一起删掉。

长度课程改的是有效 token、padding、位置分布和训练难度; SFT 还要控制任务与回答长短。长度课程是按序列长短安排训练顺序, 比如先短后长。它改的不只是顺序: 一批短序列里有内容的有效 token 少, padding (为了把一批序列补到同样长度而填的空位) 多, 模型见到的位置编号也集中在前面, 长序列才会用到靠后的位置, 所以换了长度课程就等于换了模型见过的 token 数、位置分布和难度。SFT (supervised fine-tuning, 用问答对做的监督微调) 里长度还和任务类型、回答长短绑在一起, 不控制就分不清提升来自课程还是来自回答变长。
还有两条要求:
- 报告时写每域 token 和总 FLOPs (浮点运算次数, 算力的计量单位), 因为按条数算的预算在不同长度下算力并不相同。
- 继续预训练要保留旧域回放 (继续喂一部分旧数据), 并测遗忘, 也就是测旧任务有没有退步。

同配比乱序对照把窄域 320、宽域 640 条的配比原样保留, 只打乱域顺序, 测试 MSE 2e-06, 和课程的 5e-06 同一量级。做法是把课程那 120 步的域序列 (40 步窄、80 步宽) 随机洗牌, 每一步抽到的样本批次和课程完全相同, 变的只有先后。它的结果和课程几乎一样好, 说明在这个任务上「先窄后宽」的顺序本身没带来多少额外好处, 起作用的主要是宽域拿到了 640 条而不是 80 条。9:1 随机基线 (880 / 80 条) 同时改变了配比, 它和课程的差异不能全归因于顺序: 想证明顺序有用, 就要和这条同配比乱序对照比, 而不是和随机基线比。

## 怎样验证

固定模型、随机种子和 960 条样本预算:
1. 比较静态配比、课程、主动选域三种策略的测试 MSE。
2. 再把验证分布改偏, 检查主动选择是否过拟合验证域。
额外的候选梯度计算要计入总成本。判定方法是测试 MSE 越低越好, 但只在预算、种子、模型都相同时才能互相比较; 「把验证分布改偏」是指把选域用的验证集换成和测试集不同的分布, 如果主动策略这时测试 MSE 变差, 说明它学到的是验证集而不是任务。主动策略每步多算两份候选梯度, 比较总成本时要把这部分算进去, 不能只数训练样本。

## 与真实系统的差距

二维回归机制实验。验证分布若错误，主动选择也会偏；没有证明课程在 LLM 上普遍更好。

## 常见误区与自测

主动选域的训练样本数相同, 就能称为算力公平吗?

<details><summary>展开解析</summary>

不能。主动策略每步多算两个域的候选梯度和验证损失; 样本预算相同只控制了一种资源, 不能据此宣布总算力公平。随机和课程策略每一步只做一件事, 拿 8 条样本算一次梯度、更新一次参数。主动策略每一步要:
1. 先对两个域各算一次整个域 (240 条) 的梯度, 各试更新一次。
2. 再在 81 个点的验证集上各算一次损失。
3. 选出域之后才做那次真正的更新。
它用的训练样本仍是 960 条, 但每步多做的计算是随机策略的好几倍。要比总算力, 得把候选梯度和验证损失的计算一并计入。
