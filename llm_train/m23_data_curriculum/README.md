# 数据课程：相同样本数，学到的一样吗

## 直觉

数据选择是在预算内决定下一步学什么。容易的样本有助于起步，但一直重复容易样本，会把预算花在已经学会的部分。

## 核心原理

本例先学截距再学斜率：窄域主要约束截距，宽域提供斜率信息。课程按阶段改域；主动策略比较候选梯度更新后的验证损失。训练、选域验证和最终测试分别构造。

一阶影响近似看验证梯度与样本梯度的内积；完整影响函数还需要 Hessian 逆或近似求解，不能把高损失样本直接称为高价值样本。异常标注也可能一直高损失。

真实语料先记录来源、许可证、用途与版本，再做文档去重、语言识别、PII 检测和切分。语言识别应允许混合语言和不确定；PII 正则有漏检与误报，替换后还要复查上下文。低资源语言不应因质量分数偏低被整体删除。

长度课程改变的是有效 token、padding、位置分布和训练难度；SFT 还要控制任务与回答长短。报告每域 token 和总 FLOPs，继续预训练保留旧域回放并测遗忘。

额外报告同配比乱序对照：窄域 320、宽域 640 条保持不变，仅打乱域顺序。9:1 随机基线同时改变了配比，不能把它与课程的全部差异归因于顺序。

## 运行

```bash
python -m llm_train.m23_data_curriculum.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

固定模型、随机种子与训练样本预算，比较静态、课程、主动策略；再把验证分布改偏，检查主动选择是否过拟合验证域。额外候选梯度计算必须计入总成本。

## 与真实系统的差距

二维回归机制实验。验证分布若错误，主动选择也会偏；没有证明课程在 LLM 上普遍更好。

## 常见误区与自测

主动选域的训练样本数相同，就能称为算力公平吗？

<details><summary>展开解析</summary>

主动策略额外计算候选梯度与验证损失。样本预算相同只控制了一种资源，不能据此宣布总算力公平。
