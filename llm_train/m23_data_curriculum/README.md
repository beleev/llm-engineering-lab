# 数据课程: 相同样本数, 学到的一样吗

## 直觉

本组实验通过一个双参数线性回归模型 (预测值为截距加斜率乘以 x, 真值为截距 1、斜率 2) 比较三种训练数据选择策略。训练样本来自两个数据域:
- 窄域: 自变量 x 集中在 0 附近。
- 宽域: 自变量 x 均匀分布在 -2 到 2 之间。
三种策略均限定使用 960 条样本。在相同 960 条样本预算下:
- 随机配比: 按 9:1 的语料规模采样 (窄域 880 条、宽域 80 条), 学得斜率 1.5383, 测试集 MSE 为 0.261668。
- 由窄到宽的课程: 先输入窄域再输入宽域 (窄域 320 条、宽域 640 条), 学得斜率 2.0011, 测试集 MSE 降至 5e-06。
数据选择本质上是在固定预算内决定下一步提供何种信息: 简单的窄域样本有助于初期拟合截距, 但持续重复窄域样本会将预算消耗在已收敛的截距上, 导致斜率长期缺乏有效约束。

## 核心原理

本例呈现先拟合截距、再拟合斜率的阶段特性: 窄域 (x 集中在 0 附近) 主要约束截距, 宽域 (x 分布在 -2 到 2 之间) 才提供有效的斜率梯度。当 x 接近 0 时, 斜率与 x 的乘积接近 0, 预测值几乎完全由截距决定, 因此窄域样本仅能将截距推向真值 1, 对斜率几乎不产生梯度信号; 宽域的 x 幅度足够大, 斜率偏差会直接放大为预测误差, 从而驱动斜率更新。
两种调度策略的具体执行方式如下:
- 课程策略: 前 40 步仅输入窄域样本, 后 80 步输入宽域样本 (每步 batch 为 8 条, 120 步共计 960 条)。
- 主动策略: 每步分别用两个域的数据试算候选梯度并各做一次试更新, 评估哪一候选更新在验证集上的损失更低, 再选用该域执行正式参数更新。
训练池、选域验证集与最终测试集相互独立构造:
- 训练池: 两个域各含 240 条带噪声样本。
- 验证集: 分布在 -2 到 2 之间的 81 个采样点。
- 测试集: 分布在 -1.9 到 1.9 之间的 101 个采样点。
用于选域决策的验证集与最终评测的测试集严格分离。

一阶影响近似仅计算验证集梯度与训练样本梯度的内积, 而完整影响函数还需引入 Hessian 逆矩阵或其近似。影响函数旨在度量「沿某条样本梯度更新一步后验证损失的变化量」: 在一阶泰勒近似下, 验证损失的下降量等于步长乘以验证梯度与样本梯度的内积, 内积越大表明该样本对降低验证损失越有效。本例的主动策略未采用内积近似, 而是直接执行候选更新并实测验证损失变化; 完整影响函数则需进一步左乘损失函数二阶导矩阵 (Hessian) 的逆, 以校正损失曲面曲率对更新步的缩放效应, 计算开销显著更高。此外, 高损失样本并不等价于高价值样本: 标注噪声与异常点同样会长期维持高损失, 单纯按高损失筛选样本会将训练预算持续消耗在不可学习的噪声上。

真实语料管线应先登记来源、许可证、用途与版本号, 再依次执行文档去重、语言识别、PII 检测与分块切分。
各环节的工程约束如下:
- 元数据与版本登记: 记录数据来源与许可证有助于在合规风险出现时精准下线对应批次; 记录语料版本号则确保数据清洗规则迭代后仍能复现并对齐历史实验结果。
- 语言识别容错: 单篇文档常包含中英混排等跨语言内容, 语言分类器需支持混合语言与低置信度标记, 强行指定单一语言标签会导致误删或污染。
- PII 检测与上下文复核: PII (personally identifiable information, 个人身份信息) 常借助正则表达式识别, 但正则规则存在漏检与误报, 脱敏替换后需抽检上下文连贯性, 避免将普通数值误判为电话号码而破坏语义。
- 低资源语言保护: 单一全局质量打分器往往对低资源语言给出偏低分数, 若采用统一阈值过滤, 会将低资源语言及其中的高质量样本整体剔除。

长度课程会同时改变有效 token 占比、padding 比例、位置编码分布与训练难度, 在 SFT 阶段还会与任务类型和回答长度耦合。按序列由短到长编排训练顺序时, 改变的不仅是样本先后关系: 短序列 batch 若与固定窗口对齐会产生较多 padding、有效 token 较少, 且激活的位置索引集中在前缀区间, 只有进入长序列阶段才会覆盖大位置索引, 因此切换长度课程实质上同步改变了累计有效 token 数、位置分布与任务难度。在 SFT 场景下, 序列长度往往与任务复杂度及目标回答长度强相关, 若不加以控制便无法区分收益来自课程顺序还是长回答分布本身。
实验报告与持续训练还需满足两项要求:
- 算力与容量口径: 报告各数据域的有效 token 数与总 FLOPs, 因为相同样本条数在不同序列长度下消耗的算力并不等价。
- 旧域回放与遗忘评测: 继续预训练阶段需按比例混入旧域回放数据, 并同步评测旧域基准以量化灾难性遗忘。

同配比乱序对照完整保留窄域 320 条、宽域 640 条的样本配比, 仅随机打乱域顺序, 测试 MSE 为 2e-06, 与课程策略的 5e-06 处于同一量级。具体做法是将课程策略共 120 步的域调度序列 (40 步窄域、80 步宽域) 随机重排, 每一步采样的样本 batch 与课程策略完全一致, 唯一变量是呈现先后顺序。该对照取得了与课程策略同等量级的精度, 表明在本例线性回归任务中, 「先窄后宽」的课程顺序本身并未提供显著增益, 核心收益来自宽域样本量从 80 条增至 640 条。相比之下, 9:1 随机基线 (窄域 880 条、宽域 80 条) 同时改变了域配比与顺序, 其与课程策略的差距不能归因于顺序效应; 验证课程顺序本身是否有效, 必须以同配比乱序对照为基准。

## 怎样验证

固定模型初始化、随机种子与 960 条训练样本预算, 按以下步骤执行验证:
1. 对比静态随机配比、由窄到宽课程与主动选域三种策略的测试集 MSE。
2. 将选域验证集的分布替换为有偏分布, 检验主动选域策略是否过拟合验证集分布。
评测时需将额外的候选梯度计算开销计入总成本。测试集 MSE 越低代表拟合越准, 但横向比较仅在模型、随机种子与预算一致的前提下成立; 若将验证集替换为与测试集不一致的有偏分布后主动策略的测试集 MSE 明显退化, 则表明该策略拟合的是验证集偏置而非目标任务本身。由于主动选域每步需额外计算两个域的候选梯度与验证损失, 核算总算力成本时必须纳入该部分开销, 不能仅统计正式更新所消耗的训练样本数。

## 与真实系统的差距

二维回归机制实验。验证分布若错误，主动选择也会偏；没有证明课程在 LLM 上普遍更好。

## 常见误区与自测

主动选域消耗的训练样本数与基线相同, 能否据此认定总算力公平?

<details><summary>展开解析</summary>

不能。主动选域每步需额外计算两个候选域的梯度与验证集损失; 训练样本预算相同仅对齐了正式更新的数据量, 不能据此认定总算力公平。静态随机配比与课程策略每步仅对 8 条样本计算一次梯度并执行一次参数更新, 而主动选域每步需依次完成三项计算:
1. 分别对两个域的全量训练池 (各 240 条样本) 计算候选梯度并各做一次试更新。
2. 分别在含 81 个采样点的验证集上前向评估候选模型的验证损失。
3. 选定验证损失更低的域后, 再抽取 batch 执行正式参数更新。
尽管正式用于更新的训练样本仍为 960 条, 但每步附加的候选评估计算量远超静态策略。评估总算力公平性时, 必须将候选梯度与验证损失的计算开销一并计入。

</details>
