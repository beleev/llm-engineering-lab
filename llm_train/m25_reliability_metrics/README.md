# 可靠性：校准、拒答与人工评价

## 直觉

准确率告诉你答对多少，校准告诉你“有多确定”是否可信。二者要分开测。

## 核心原理

可靠性图把置信度分桶，对照平均置信度与准确率；ECE 是桶差的加权绝对值，依赖分桶。Brier 对每个样本的概率误差平方求均值，同时反映校准与区分能力。温度缩放应在独立校准集拟合。

拒答提高剩余答案准确率时，必须一起报告 coverage、risk 与各群体覆盖率。群体差异需按任务难度和样本量解释；群体准确率相同不能证明个体公平。HELM 式比较固定场景，同时报告质量、校准、鲁棒性、毒性与成本。

人工成对评价先规定正确性与风格量表，随机左右顺序、隐藏模型身份、允许平局、重复部分题目并记录分歧。Cohen κ 校正偶然一致；高一致性仍可能是共同偏见。

Bradley–Terry 用 sigmoid(s_A−s_B) 拟合胜率；排名要用按题目/用户聚类的 bootstrap 区间，避免把重复投票当独立样本。LLM Judge 需左右交换、长度配平、自评与异模型裁判消融，再用人工子集核验。

## 怎样验证

实验固定同一组正确/错误标签，只改变置信度或拒答阈值，并实际拟合成对胜负得分。真实校准必须使用未参与阈值选择的测试集；不要从教学数组推断某个模型可靠。

## 与真实系统的差距

确定性评测夹具，不是模型能力榜单。拒答提高已答准确率会减少覆盖；Kappa 受标签流行率影响。

## 常见误区与自测
