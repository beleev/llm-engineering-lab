# 可靠性: 校准、拒答与人工评价

## 直觉

同一组 20 条答案, 准确率都是 0.7: 全部报 0.95 的置信度时 ECE 0.25、Brier 0.2725, 按两组真实正确率报 0.9 / 0.5 时 ECE 0.0、Brier 0.17。准确率告诉你答对多少, 校准告诉你「有多确定」是否可信, 二者要分开测。

## 核心原理

可靠性图把置信度分 5 桶, 每桶对照平均置信度与正确率; ECE 是各桶差的加权绝对值, 结果依赖分桶。Brier 对每个样本的概率误差平方求均值, 同时反映校准与区分能力。温度缩放要在独立校准集上拟合; 本例的校准概率由已知总体构造, 没有用测试标签去调。

只回答置信度 ≥ 0.8 的那一半, 已答准确率从 0.7 升到 0.9, 但 coverage 只剩 0.5; 拒答提高准确率时必须一起报告 coverage、risk 与各群体覆盖率。两个切片准确率 0.9 / 0.5 的差异要按任务难度和样本量解释, 群体准确率相同也不能证明个体公平。HELM 式比较固定场景, 同时报告质量、校准、鲁棒性、毒性与成本。

人工成对评价先规定正确性与风格量表, 再随机左右顺序、隐藏模型身份、允许平局、重复部分题目并记录分歧。两位标注者在 8 题上的 Cohen κ 是 0.5, κ 校正的是偶然一致; 高一致性仍可能是共同偏见。

Bradley–Terry 用 sigmoid(s_A−s_B) 拟合胜率, 本例三个模型的胜负计数拟合出得分 [0.733, -0.294, -0.439], 绝对零点无意义。排名要配按题目/用户聚类的 bootstrap 区间, 别把重复投票当独立样本。LLM Judge 要做左右交换、长度配平、自评与异模型裁判消融, 再用人工子集核验。

## 怎样验证

固定同一组 20 条正确/错误标签, 只改置信度或拒答阈值, 比较 ECE、Brier、coverage 和已答准确率, 并实际拟合成对胜负的 BT 得分; 真实校准必须用没参与阈值选择的测试集, 不要从这组教学数组推断某个模型可靠。

## 与真实系统的差距

确定性评测夹具，不是模型能力榜单。拒答提高已答准确率会减少覆盖；Kappa 受标签流行率影响。

## 常见误区与自测

拒答后准确率提高, 最需要一起报告什么?

<details><summary>展开解析</summary>

coverage 和 risk, 成对报。选择性回答改变了被评价的样本集合: 本例拒答一半后准确率从 0.7 升到 0.9, coverage 只剩 0.5; 还要检查某些群体是不是被过度拒答。
