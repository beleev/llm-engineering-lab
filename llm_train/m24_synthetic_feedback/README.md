# 合成数据: 多代反馈与长尾消失

## 直觉

这组实验用一个只有六个类别的分布模拟「拿模型自己生成的数据训练下一代模型」: 六类分布里真实概率是 0.55、0.25、0.12、0.05、0.02、0.01, 尾部两类只占 0.03 的质量 (质量就是概率, 六类加起来是 1)。每一代从上一代估计的分布里抽样本, 再按样本里各类的频率重新估计分布, 当作下一代; 连采 30 代, 换 32 个随机种子重复。只用上一代的 192 条合成样本连采 30 代, 32 个种子里有 25 次尾部直接归零, 也就是那两个小类的概率被估成了 0。生成得更多, 不一定知道得更多: 小概率事实一旦没被采到, 下一代就再也生成不出来, 因为下一代是按估出来的概率抽样, 概率为 0 的类永远抽不到。

## 核心原理

实验从六类真实分布出发, 每代按上一代估计的概率采样, 再用频率重新估计。具体是: 第 0 代的概率就是真实分布; 每一代按当前概率抽样本, 数一数每类各出现几次, 用「出现次数除以总数」当下一代的概率。这是实际抽样而不是预设的下降曲线, 所以每一代都会随机抖动, 一个类只要某一代一条都没抽到, 频率就是 0, 之后再也抽不到。32 个种子各跑 30 代, 报告平均总变差距离和尾部消失次数, 把单次随机波动和系统性退化分开: 总变差距离 (TV 距离) 是估计分布和真实分布逐类相减取绝对值、求和再除以 2, 0 表示完全一致, 1 表示毫无重叠; 尾部消失次数是 32 次运行里最后一代尾部两类概率为 0 的次数, 归零一次可能是运气, 25 次就是机制。

每代混入 128 条真实锚点, 消失的类别会被重新引入, 尾部消失次数从 25 降到 1。真实锚点是每代直接从真实分布抽的样本, 不经过上一代的估计: 即使上一代把某个类估成了 0, 这 128 条里仍有机会抽到它, 下一代的频率就不再是 0, 平均 TV 距离也从 0.2459 降到 0.0563。只偏好常见类的过滤器会把真实锚点也删掉, 32 个种子尾部全部归零: 本例的过滤器只保留前四类, 第五、六类的样本不论来自合成还是真实都被丢掉, 锚点带回来的尾部在过滤这一步又被删光, 32 次运行最后一代的尾部质量全是 0。所以质量过滤要同时看可验证正确性、覆盖和难度, 不能只看教师打分: 教师 (给样本打分的模型) 偏好它熟悉的常见模式, 只按它的分数筛, 筛掉的正是稀有但正确的样本。

真实/合成比例、去重和难度要做因子对照: 固定总训练 token, 分别扫描混合比例、实体级去重开关与难度分桶; 独立测试按来源和稀有实体拆分。因子对照的意思是一次只动一个变量: 固定总 token 数只改真实和合成的比例, 看结果怎么变; 再固定比例只开关去重; 再只换难度分桶。不这样做, 几个变量一起变, 就说不清提升来自哪一个。测试集要按来源 (真实还是合成) 和稀有实体 (出现次数很少的人名、地名、概念) 拆开报告, 因为总平均会被常见样本淹没, 尾部丢了也看不出来。去重键要对应样本实体, 不是本例的六个类别, 否则会人为把分布拉均匀: 如果拿类别当去重键, 同一类的样本会被当成重复而合并, 大类被砍得最多, 分布就被人为拉平了, 这不是去重, 是改分布。

合成指令与答案要留下教师版本、采样参数、验证器与拒绝原因。这些记录是为了事后能追溯一条合成数据是哪个模型、在什么采样设置下生成的, 又是被哪条规则放行或拒绝的; 没有记录, 发现问题时就分不清是教师模型、采样温度还是验证器的问题。教师错误会被一代代放大: 教师生成的错误答案进入下一代训练集, 下一代学会这个错误后又当教师去生成更多同样的错误, 和本例里尾部一旦归零就永远归零是同一类反馈效应。高保留率不能代替新知识或泛化证据: 验证器放行了绝大多数样本, 只说明这些样本符合验证器的规则, 不说明它们带来了模型原本不会的东西, 也不说明模型在没见过的题上会更好。

三条路径在过滤前每代都是 192 条: 纯合成 192 条, 混合 64 条合成加 128 条真实。偏置过滤删掉低频类后保留数会减少, 因为它在混合路径的 192 条基础上再把第五、六类的样本全部丢掉, 真正进入频率估计的条数小于 192。这里的结果用来展示过滤损失, 不是等保留量下的通用过滤器排名: 过滤路径的 TV 距离 0.0645 看起来和混合路径的 0.0563 差不多, 但它的尾部质量是 0.0, 这正说明一个总体距离指标可以在尾部完全消失时仍然好看。要公平比较不同过滤器, 得先把保留下来的样本数对齐, 本例没有做这件事。

## 怎样验证

固定 6 类真实分布、30 代和 32 个种子, 比较只用上一代、加入真实锚点、偏置过滤三条采样路径的 TV 距离和尾部消失次数, 再改 rounds 和种子复查尾部; 研究真实 LLM 的 model collapse 必须训练多代模型并固定总预算, 本例只隔离有限采样和选择偏差。判定看两个数: 平均 TV 距离越小, 最后一代的分布越接近真实; 尾部消失次数越多, 说明小类越容易被丢掉, 这个数比 TV 距离更能暴露长尾问题。改 rounds (代数) 和种子是为了确认尾部归零不是某个种子或某个代数的巧合; model collapse (模型崩溃, 指多代用合成数据训练后模型分布逐渐退化) 在真实 LLM 上还牵涉训练本身, 本例只模拟了采样和过滤这两个环节。

## 与真实系统的差距

有限类别的多项式估计器，不是 LLM。只说明有限采样和选择偏差如何丢失长尾，不把所有合成数据都叫 model collapse。

## 常见误区与自测

过滤后通过率很高, 为什么稀有知识仍可能消失?

<details><summary>展开解析</summary>

因为偏置过滤按类别删样本, 低频类每代都被系统性删掉。即使混入真实锚点, 同一个过滤器也会把锚点里的尾部再删一次, 32 个种子尾部质量全是 0。一步步看: 过滤器的规则是只保留前四类, 它对第一到第四类的样本全部放行, 从「通过率」看表现很好; 但第五、六类一条也过不去。混合路径每代有 128 条真实锚点, 其中属于尾部两类的平均不到 4 条 (128 乘 0.03), 这几条在过滤这一步被删掉, 下一代估出来的尾部概率仍是 0。通过率衡量的是「被放行的样本占多少」, 它对「哪些类从来没被放行」不敏感, 所以通过率高和稀有知识消失可以同时成立。

</details>
