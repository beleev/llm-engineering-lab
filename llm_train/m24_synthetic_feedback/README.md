# 合成数据：多代反馈与长尾消失

## 直觉

生成得更多，不一定知道得更多。小概率事实一旦没有被采到，下一代模型可能再也生成不出来。

## 核心原理

实验从六类真实分布开始，每代采样并重新估计概率。重复 32 个种子报告总变差距离和尾部消失次数，区分单次随机波动与系统性退化。

真实数据锚点能重新引入消失类别；只偏好常见类的过滤器会把真实锚点也删掉。质量过滤应同时看可验证正确性、覆盖和难度，不宜只看教师打分。

真实/合成比例、去重和难度要做因子对照：固定总训练 token，分别扫描混合比例、实体级去重开关与难度分桶；独立测试按来源和稀有实体拆分。去重键应对应样本实体，不是本例的六个类别，否则会人为把分布变均匀。

合成指令与答案还需留教师版本、采样参数、验证器与拒绝原因。教师错误会被循环放大；高保留率不能代替新知识或泛化证据。

三条路径在过滤前每代均生成 192 条：纯合成为 192 条，混合为 64 合成加 128 真实。偏置过滤会降低保留数；当前结果用于展示过滤损失，不是等保留量的通用过滤器排名。

## 运行

```bash
python -m llm_train.m24_synthetic_feedback.demo
```

需要 Python ≥ 3.10，依赖使用仓库的 numpy / torch；不需要模型 API。网页在现有章节中提供同一实验的执行记录回放。

## 怎样验证

先比较三种实际采样路径，再改变 rounds 和种子复查尾部。要研究真实 LLM 的 model collapse，必须训练多代模型并固定总预算；本例只隔离有限采样和选择偏差。

## 与真实系统的差距

有限类别的多项式估计器，不是 LLM。只说明有限采样和选择偏差如何丢失长尾，不把所有合成数据都叫 model collapse。

## 常见误区与自测

过滤后通过率很高，为什么稀有知识仍可能消失？

<details><summary>展开解析</summary>

偏置过滤会系统性删除低频类别；即使混入真实样本，也无法恢复被同一过滤器再次删除的尾部。

</details>
