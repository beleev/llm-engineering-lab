# 合成数据: 多代反馈与长尾消失

## 直觉

本组实验用六类别离散分布模拟「以模型自生成数据迭代训练下一代模型」的多代反馈过程: 六个类别的真实概率依次为 0.55、0.25、0.12、0.05、0.02、0.01, 尾部两个低频类别合计仅占 0.03 的概率质量 (六类概率之和为 1)。
每一代按以下两步迭代:
1. 从上一代估计出的类别分布中抽取有限样本。
2. 按当前样本中各类别的经验频率重新估计分布, 作为下一代的采样分布。
实验连续迭代 30 代, 并跨 32 个随机种子重复评测。若每代仅使用来自上一代的 192 条合成样本连续迭代 30 代, 32 个随机种子中有 25 次出现尾部概率质量归零, 即末尾两个低频类别的概率被估计为 0。
单纯扩大合成数据迭代轮数并不会增加知识覆盖: 低概率事实一旦在某代未被采中, 其经验概率即变为 0, 后续世代按该估计分布采样时将永久失去生成该类别的能力。

## 核心原理

本实验从六类别真实分布出发, 每代按上一代估计出的多项分布实际采样, 再以样本经验频率更新下一代分布。
具体迭代流程如下:
1. 第 0 代分布直接初始化为真实类别分布。
2. 每一代按当前分布随机抽取样本并统计各类别频次。
3. 将各类别出现频次除以总样本数, 作为下一代的多项分布参数。
该过程采用真实的有限样本随机抽样而非预设衰减函数, 各代频率存在随机涨落; 一旦某一类别在任意一代出现 0 次, 其估计概率即锁定为 0, 成为不可逆的吸收态。
实验跨 32 个随机种子各迭代 30 代, 同时报告平均总变差距离与尾部消失次数, 以区分单次随机涨落与系统性分布退化:
- 总变差距离 (TV 距离): 估计分布与真实分布逐类绝对差之和除以 2, 取值 0 代表完全重合, 取值 1 代表支撑集完全分离。
- 尾部消失次数: 32 次独立运行中末代尾部两类概率质量归为 0 的次数; 单次归零可能源于偶然采样偏差, 而 32 次中出现 25 次归零则确证了多代自采样的长尾退化机制。

每代混入 128 条真实锚点样本可重新引入已归零的低频类别, 将尾部消失次数从 25 次降至 1 次。真实锚点直接从原始真实分布独立采样, 不依赖上一代的分布估计: 即使上一代将某类别概率估计为 0, 这 128 条真实样本仍有正概率采中该类并使其下一代频率恢复非零, 末代平均 TV 距离也从 0.2459 降至 0.0563。
然而, 仅偏好高频类别的过滤器会将真实锚点中的长尾样本一并剔除, 导致 32 个随机种子的尾部概率质量全部归零: 本例偏置过滤器仅保留前四个高频类别, 第五、第六类的样本无论来自合成采样还是真实锚点均被直接丢弃, 使得锚点恢复的长尾覆盖在过滤阶段被彻底抹除, 32 次运行的末代尾部质量均为 0。
因此, 合成数据质量过滤必须综合评估可验证正确性、分布覆盖度与样本难度, 不能单纯依赖教师模型打分: 教师模型往往对常见高频模式给出更高置信度, 单一高分截断会系统性剔除罕见但正确的长尾知识。

评估合成数据管线需对真实与合成配比、去重策略及难度分布执行单因子受控对照。实验应固定总训练 token 预算, 依次独立扫描混合比例、实体级去重开关与难度分桶, 并在按来源与稀有实体拆分的独立测试集上报告指标。
单因子对照要求每次仅改变一个干预变量:
1. 固定总 token 预算与其余超参数, 仅扫描真实数据与合成数据的混合比例。
2. 固定最优混合比例, 单独对比实体级去重开启与关闭的差异。
3. 固定配比与去重策略, 单独切换样本难度分桶方案。
若多个变量同时变动, 便无法归因性能变化来自配比、去重还是难度分布。
评测阶段需将测试集按数据来源与长尾稀有实体切片报告, 避免总体均值掩盖高频样本之外的长尾退化。此外, 去重键应绑定具体样本实体而非粗粒度类别标签 (如本例的六个类别), 否则同类样本会被当作重复项合并, 高频大类被大量裁剪而人为将类别分布拉平。

合成指令与回答的生成管线必须完整记录教师模型版本、采样超参数、验证器版本及拒识原因。保留全链路血缘元数据有助于在下游暴露缺陷时精准追溯样本由哪一版本教师模型、在何种采样温度与解码参数下生成, 以及依据哪条校验规则被放行或拦截; 缺乏血缘记录将无法定位质量退化源于教师能力、解码配置还是验证规则。
多代自训练中教师模型的系统性错误会被逐代放大: 教师生成的事实性错误一旦混入下一代训练集, 子代模型内化该错误后继续充当下一轮教师, 会生成更高比例的同源错误, 与本例低频类别归零后不可恢复同属闭环正反馈退化。
此外, 验证器的高样本保留率不能替代新知识注入或分布外泛化的证据: 保留率高仅表明候选样本满足既有校验规则, 既不证明样本引入了基座未知的信息, 也不保证留出测试集上的泛化提升。

三条采样路径在进入过滤器前每代均抽取 192 条样本: 纯合成路径为 192 条合成样本, 混合路径为 64 条合成样本加 128 条真实锚点。偏置过滤路径在混合路径 192 条候选样本的基础上将第五、第六类低频样本全部剔除, 因此实际用于更新频率估计的保留样本数少于 192 条。
本实验旨在揭示偏置过滤对长尾覆盖的破坏, 而非在等保留样本量下对通用过滤器做横向排名: 偏置过滤路径的末代平均 TV 距离为 0.0645, 表面上与未过滤混合路径的 0.0563 接近, 但其尾部概率质量已降至 0.0, 表明全局分布距离指标在长尾完全灭绝时仍可能呈现良好读数。若要公平对比不同过滤策略的优劣, 需通过超采样将过滤后的有效保留样本数严格对齐, 本实验未做该等量对齐。

## 怎样验证

固定 6 类真实分布、30 代迭代步数与 32 个随机种子, 对比纯自采样、混入真实锚点与偏置过滤三条路径的末代平均 TV 距离和尾部消失次数, 并调整迭代代数 (rounds) 与随机种子复核长尾表现; 研究真实 LLM 的 model collapse (模型崩溃, 多代依赖合成数据训练引发的分布退化) 还须实际训练多代参数模型并对齐总计算预算, 本例仅隔离有限样本重采样与过滤选择偏差两个机制。
评测时需联合判读两项指标:
- 平均 TV 距离: 数值越低表明末代整体分布越接近真实分布。
- 尾部消失次数: 计数越高表明低频类别越易灭绝, 该指标比全局 TV 距离更能直接暴露长尾丢失。
扫描不同 rounds 与随机种子是为了验证尾部归零属于稳定的统计规律而非特定代数或种子的偶然现象; 真实 LLM 的 model collapse 还会叠加函数逼近误差与优化动力学, 本实验仅建模了离散重采样与过滤环节。

## 与真实系统的差距

有限类别的多项式估计器，不是 LLM。只说明有限采样和选择偏差如何丢失长尾，不把所有合成数据都叫 model collapse。

## 常见误区与自测

质量过滤器的整体通过率很高时, 为何长尾稀有知识仍可能完全消失?

<details><summary>展开解析</summary>

偏置过滤器会按模式偏好系统性拦截低频类别, 导致长尾样本在每一代均被定向剔除。即使每代混入真实锚点样本, 同一过滤器仍会将真实锚点中的尾部样本再次滤除, 致使 32 个随机种子的末代尾部概率质量全部降为 0。在本例中, 过滤器对前四个高频类别的样本全部放行, 因此整体样本通过率很高, 但第五、第六类样本一条也无法通过。混合路径每代引入的 128 条真实锚点中, 属于尾部两类的样本期望不足 4 条 (128 乘以 0.03), 这些稀缺锚点在过滤阶段被全部剔除, 下一代估计出的尾部概率依然为 0。整体通过率仅反映放行样本占总候选数的比例, 对特定低频子集的零通过率并不敏感, 因此高整体通过率与稀有知识消失可以同时成立。

</details>
