# M20 — μP: 超参随宽度迁移

运行: `python -m llm_train.m20_mup.demo` (约 4.5 秒)

## 直觉
m19 定了模型多大。接下来要定学习率。

大模型没法反复扫学习率, 一次就是几百万美元。自然的想法是在小模型上扫好, 再搬到大模型。标准参数化 (SP) 下这行不通: 网络变宽, 最优 lr 会跟着变。

原因在 Adam:
- 它每个元素的更新大小约等于 lr, 和梯度大小无关。
- 隐藏层有 width 个输入。width 个 ≈lr 的同向小更新加在一起, 下一层激活的变化 ∝ lr·width。
- 宽 4 倍, lr 就得小 4 倍。

μP (maximal update parametrization) 按宽度改写初始化和每层学习率, 让每层更新对输出的影响与宽度无关。这样最优 lr 不随宽度移动。在窄的 proxy 模型上扫, 直接用到宽模型 (μTransfer)。

## 核心数据结构与控制流
- `demo.py:init_and_lrs` — SP 和 μP 的全部差别都在这里, 一共三处 `/ m`: 输出层初始化的标准差除以 m (方差除以 m²), 隐藏层的 lr 除以 m, 输出层的 lr 除以 m。
- `demo.py:train` — 两层隐藏层 ReLU MLP, 手写反向, Adam + 线性衰减到 0, 每步取新数据, 返回最后 10 步平均 loss。
- `main` — 3 个宽度 × 10 个 lr × 2 种参数化, 各取 argmin。

## 核心公式 (Adam, Tensor Programs V 表 3; m = width / base_width)
| 层 | 初始化方差 | Adam 学习率 |
|---|---|---|
| 输入层 (fan_in = d_in 固定) | 1/fan_in | η |
| 隐藏层 | 1/fan_in | η / m |
| 输出层 | 1/(fan_in·m²) (标准差多除一个 m) | η / m |

- m = 1 时与 SP 完全一样, 所以 base 宽度上调出的 η 两种参数化通用。
- 输出层这一行以代码为准: `randn / sqrt(width) / m`。论文表 3 的输出层方差是 1/(fan_in·m), demo 比它多缩了一个 m。

## 运行后应该看到什么
```
[SP]   宽度  最优 log2(lr)   各 log2(lr) 的 loss = -13 … -4
          32             -5   … 0.0262 0.0186 0.0248
         128             -7   … 0.0184 0.0162 0.0288 …
         512            -11   … 0.0258 0.0215 0.0227 …
[μP]     32             -5   … 0.0262 0.0186 0.0248
         128             -5   … 0.0107 0.0101 0.0128
         512             -5   … 0.0090 0.0088 0.0101
SP  最优 log2(lr) 随宽度 = [-5, -7, -11]
μP  最优 log2(lr) 随宽度 = [-5, -5, -5]
把 base 的 lr 直接用到宽度 512 = SP loss 0.0976 (该宽度最优 0.0215) / μP loss 0.0088 (最优 0.0088)
μP 同一 lr 下 loss 随宽度 = [0.0186, 0.0101, 0.0088]
```
- **SP**: 宽 16 倍, 最优 lr 左移了 6 个 2 倍格点 (≈ 64 倍), 比 "∝ 1/width" 还多。把 base 的 lr 直接搬过去, loss 差 4.5 倍。
- **μP**: 三个宽度的最优点都在 2⁻⁵, 而且同一 lr 下越宽越好。

## 与真实系统的差距
- 只有 3 个宽度, 最宽 512, 训练 150 步。μTransfer 论文在 Transformer 上验证到 ~6.7B 参数的迁移, 这里只能说明机制。
- lr 网格是 2 倍一格。μP 在 128 / 512 宽度上最优点附近很平 (0.0107 / 0.0101 / 0.0128), argmin 落在 -5 有一定运气。
- SP 那条曲线也不光滑 (width=512 在 -9 到 -7 之间来回跳), 是短训练加大 lr 的不稳定。
- 用了线性衰减到 0。换成常数 lr、取最后 20 步的平均时, μP 的最优点在 -5 / -7 / -8 之间漂, 迁移没这么干净。宽网络在低 lr 那一侧改善更多。
- 只迁移了 lr。μP 也管初始化尺度、输出乘子等。深度方向的迁移要另加 depth-μP, 这里没演示。
- 真实 Transformer 的 μP 还要把注意力 logit 的缩放从 1/√d_head 改成 1/d_head。
- 还有更简单的替代: 直接拟合 "最优 lr 随规模的幂律", 不改参数化。很多团队这样做, 例如 DeepSeek LLM。

## 常见误区
- "μP 让模型更好" —— 它不改变最优点的 loss, 只让最优超参不随宽度移动。省的是调参成本。
- "μP 只是 lr 除以宽度" —— 输入层的 lr 不缩, 输出层的初始化也要改。只缩 lr 不对。
- "SGD 和 Adam 的 μP 规则一样" —— Adam 的更新大小与梯度大小无关, 缩放规则和 SGD 不同。

## 自测题
1. base 宽度 256, 目标宽度 4096, Adam μP 下隐藏层 lr 是多少? **答: η × 256/4096 = η/16。**
2. 为什么 SP + Adam 下宽网络需要更小的 lr? **答: 每个元素更新 ≈ lr, fan_in = width 个同向更新叠加, 激活变化 ∝ lr·width。**
3. μP 下输入层的 lr 为什么不随宽度缩? **答: 它的 fan_in 是固定的 d_in。每个输出坐标的更新量本来就与宽度无关。**
