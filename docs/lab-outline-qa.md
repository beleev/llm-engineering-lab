# 实验台选中框与焦点框裁剪修复

2026-11-08。原反馈来自“语音交互 · 打断与快慢响应”：第二个事件按钮的紫色上边框消失。

## 原因与改动

`.lab-viz` 只有 `overflow-x: auto`，浏览器同时把纵向溢出计算为 auto。按钮贴着滚动区边缘时，向外画的 outline 被裁剪。修复前的桌面检查在 111 个目录入口中复现了 69 个页面的选中或键盘焦点框裁剪。

- 公共 `.lab-viz` 留出 6px 描边空间，覆盖全局 3px outline + 3px offset；负 margin 抵消内边距，保持内容起点和图表宽度。保留横向滚动，避免宽图溢出页面。
- Packing 和序列并行的内层滚动区复用 `.lab-scroll`。只改外层不能解决内层的裁剪。
- 浮点范围、KV 预算、top-k、裁判偏差、KTO，以及 A2A/Computer Use 节点等七处贴近 SVG viewBox 边缘的控件改用内描焦点框。保留 SVG 裁剪，不改坐标换算和数据。
- SFT 固定列网格使用实际内容宽度，防止最右列溢出网格自身边界后吞掉滚动区的末尾留白。
- 手机顶栏允许收缩，章节简介和源码路径允许换行，修复 GRPO 页面被长标题/路径撑宽至约 400px 的问题（视口 375px）。

新增检查使用浏览器实际 computed style、元素矩形和各级滚动裁剪边界，而不是断言 CSS 中写了某个 padding 值。检查默认选中状态，以及各实验台首尾控件获得键盘焦点后的状态。对正常位于横向视口之外的内容不误报；布局稳定后再读 SVG 焦点样式。
