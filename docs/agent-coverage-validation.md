## 几个关键结果

- Coding Agent：错误候选无法通过真实子进程测试；读取反馈后修复，三个固定测试通过。预算耗尽时回滚，测试文件摘要保持不变。
- 异步运行：提交前取消不入账；提交后取消仍保留 10 元模拟业务写入。SQLite 重开后同键重试只有一笔；已终止任务的取消幂等，检查点前失败也会唤醒等待者。
- Agent 训练：小 LLaMA 在隔离实体上的符号协议通过率由 0 到 1；在线 RL 确实发生非零优势更新，留出得分仍为 1。没有据此声称 RL 优于 SFT。
- 中期训练：仅训新域，新域探测为 1、旧域为 0；混合旧域回放，两域都为 1。这里测固定符号映射的保持，不是未知知识泛化。
- 自蒸馏：无额外信息时两分布一致、KL 为零；给教师分支验证提示后，学生在无提示的不同起点测试通过。教师提示通道不参与梯度更新，运行时提示恒为零。
- 向量索引：12 个固定查询，精确扫描 288 次距离计算、召回率 1；单叶树 36 次、0.8333；预算受限图 144 次、0.6667。没有为了迎合“图一定更好”修改实验结论；增加图预算至全体点数才与精确基准一致。

## 已明确保留的实验边界

语音使用合成波形与给定事件，具身使用一维动力学；树状 / 图状检索和 ANN 是机制简化，不是完整 RAPTOR、GraphRAG、ANNOY 或 HNSW 产品。提示对照、用户模拟、裁判校准和多智能体策略采用固定环境。真实浏览器定位依赖夹具颜色；小模型训练使用符号动作。各章分别注明这些条件。

本轮补齐的是书的知识范围和适合本库的可复现实验，不把模拟、研究讨论或标题覆盖等同于通用生产能力。来源索引、边界测试和导出检查用于后续更新时继续审查知识 diff。
