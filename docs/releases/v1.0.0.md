# v1.0.0 — LLM Engineering Lab

首个正式版本：从 NumPy 手写 Transformer，到模型架构、规模化训练模拟、微调对齐、推理优化和 Agent。六阶段 Python 实验可在 CPU 上运行，配套中文交互教程。

[在线教程](https://beleev.github.io/llm-engineering-lab/) · [项目与运行说明](https://github.com/beleev/llm-engineering-lab/tree/v1.0.0)

## 这个版本包含什么

- 23 个 PyTorch 模型，涵盖语言模型、MoE、多模态与视觉生成。
- 21 个训练专题、27 个推理专题、19 个 Agent 专题，以及微调对齐方法与集成示例。
- 86 章教程、108 个交互实验台、284 道自测题。实验通过基线对照和断言验证结论，文档区分真实计算、模拟与代价估算。
- README 顶部的英文简介和三个真实实验台预览；六个包首页与教学章统一栏目，配上截图或结构图。40 个小写 `readme.md` 改为 `README.md`，引用同步更新。
- 静态 Open Graph / X 分享元数据、1200 × 630 预览图和 favicon；贡献指南、双语 issue 模板、`CITATION.cff`。
- 正文与题库按阶段加载，阅读量在构建时统计。入口 JS 从 575.28 kB 降至 169.65 kB（未压缩的 minified 产物，约减少 70.5%）；gzip 从 226.67 kB 降至 64.90 kB。新增拆包检查，防止正文被重新打进首页。

## 使用与边界

需要 Python 3.10+；模型和微调使用 PyTorch，其余实验主要使用 NumPy 或标准库。网页构建使用 Node.js 20。具体命令见根 README。

这些是教学规模的实现：模拟多卡通信不等于实际多机训练，代价模型不等于 GPU 性能基准；默认 Agent 使用规则模型，Claude API 适配器需自行配置。默认测试前应取消设置 `ANTHROPIC_API_KEY`，以免可选示例发起真实请求。

## 验证

本地检查通过源码引用、公式、自测题、演进链、生产构建和拆包检查。87 个页面入口（含首页）逐一打开，阅读时长与实验台计数和拆包前一致。跨阶段导航、自测、深链接刷新、键盘滑杆和 390 px 页面布局抽查通过，浏览器脚本错误为 0。完整 Python 冒烟与训练脚本由 GitHub Actions 在 Python 3.10 / 3.13 上执行，结果见 [Tests 工作流](https://github.com/beleev/llm-engineering-lab/actions/workflows/test.yml)。
