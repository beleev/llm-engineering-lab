# v1.1.0 — LLM Engineering Lab

六阶段 LLM 工程教程：从 NumPy 手写 Transformer，到模型架构、训练、微调对齐、推理服务和 Agent。实验可在 CPU 上运行，配套中文交互教程、执行记录和源码。

[在线教程](https://beleev.github.io/llm-engineering-lab/) · [安装与运行](https://github.com/beleev/llm-engineering-lab/tree/v1.1.0#安装与运行) · [验证指南](https://github.com/beleev/llm-engineering-lab/blob/v1.1.0/docs/validation.md)

## 教程与交互

- 6 个阶段、26 个主题组、101 个三级章节与 6 个阶段总览。
- 178 个实验入口、396 道自测题、248 条术语速查。
- 冲刺、主干和完整阅读路线；学习进度、本地自测记录、章节别名与页内深链接。
- 明暗主题、窄屏布局、键盘操作、可见焦点框与源码展开；正文和题库按阶段加载。

## 实验范围

- **Agent**：工具发现、权限、上下文与记忆、RAG、异步任务、幂等恢复、协作、完成验收、轨迹学习、小模型训练、语音交互与视觉操作。
- **研究主题**：25 组实验、76 个执行条件，涵盖数据选择、合成反馈、可靠性评测、PEFT、偏好学习、知识编辑、隐私、可解释性、多模态与推理图。
- **工程流程**：9 组实验、49 个执行条件，涵盖模型交付、文档生命周期、MCP 版本与授权、异步 RL、发布回滚、profiler、多租户调度、检查点恢复与缓存身份。
- **基础机制**：多轮模板与监督位置、trace/span、RFT、流式接口、语义检索、多维并行预算、服务容量与感受野。

## 运行与边界

Python 3.10+，Web 构建使用 Node.js 20。仓库依赖包括 NumPy 和 PyTorch；基础 Agent 实验使用标准库，可选浏览器验证需安装 Playwright。安装与各模块命令见 README。

网页中的 Python 回放展示实际执行记录，切换条件不会现场训练或调用 API。实验明确区分真实计算、确定性模拟与代价模型；小模型、固定夹具和 CPU 结果不代表真实大模型质量、多机 GPU 性能或生产服务保证。

## 验证

Python 行为测试、源码引用、公式、自测题、章节归属、生产构建与分包检查分别验证对应约束。浏览器检查涵盖条件切换、事件步进、键盘、窄屏、明暗主题和刷新。验证命令及范围见验证指南，自动化结果见 [GitHub Actions](https://github.com/beleev/llm-engineering-lab/actions)。
