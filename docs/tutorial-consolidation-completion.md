本轮对应 [章节复核报告](tutorial-consolidation-audit.md) 的 R1–R4、M1–M4、O1–O3 和 K1–K3。审查基线为 `fe70ee9`；下面记录实施后的行为。未将真实 GPU 性能、完整 OS 沙箱或分布式工作流框架列为本轮已实现功能。

## 教程结构

- 六阶段、26 个二级分组保留；三级章节 107 → 101，加六个阶段总览，共 107 个学习入口。
- 低精度稳定性/格式、LoRA/DoRA、缓存/上下文成本、编排/协作、记忆生命周期/隐私，五对章节合并。保留原实验，以页内段落区分主干和进阶。
- QK-Norm 进入 Attention，YaRN 进入 Position；SWA 的感受野进入 Attention，DeltaNet 与混合线性结构进入 Mamba 后的独立进阶段落。明确 DeltaNet 与 Mamba 的机制不同。MTP 保留自己的训练目标与草稿生成。
- 两处摘要重复已改写；PP 公式集中到调度章节；取消时序集中到异步章；子 Agent 机制集中到协作章；记忆类型回到记忆基础。DSA 的掩码实验指引更新到 Attention。
- FP32 master 与 LoRA 收敛结论限定为本章配方和实验条件，不把一次小实验写成普遍规律。

LoRA 的主干实验仍在页面前部，DoRA 标为进阶；源码展开、长公式与实验条件切换沿用原站点组件。空指标显示“不适用”，避免把没有样本误看成零。窄屏中的长运行命令在卡片内换行，避免文字被截断。深链接需等待页面切换和异步实验布局后再定位。

## 三组新增实验

| 审查项 | 主讲入口 | 实现与反例 |
| --- | --- | --- |
| K1 多租户公平性 | 服务调度 | [m33](../llm_infer/m33_tenant_scheduling/README.md)：同一到达轨迹对比 FIFO、固定优先级、公平量子轮转和租户配额；逐租户统计超时、拒绝、等待与 goodput |
| K2 跨版本恢复 | 会话持久化与恢复 | [m57](../llm_agent/m57_checkpoint_migration/README.md)：旧格式默认值迁移、节点/字段/工具不兼容拒绝、权限重验、流程版本与外部提交后强退恢复 |
| K3 缓存身份 | 前缀缓存 | [m34](../llm_infer/m34_cache_identity/README.md)：可信共享域、模型/adapter 版本、同域复用、跨域隔离与伪造租户声明拒绝 |

新增 3 组、18 个条件；与之前 6 组、31 个条件合计 **9 组工程回放、49 个条件**。新增三道自测，题库共 **396 道**。所有回放由 Python 执行导出，浏览器切换的是执行记录。

固定调度轨迹中，B 租户在固定优先级下 4 个请求全超时，公平轮转后全部完成。配额将 A 队列峰值限制为 8；这些是 tick 服务量模拟，不是 GPU 毫秒测量。

检查点实验在外部 SQLite 提交后，用 `os._exit(17)` 真正结束子进程；新版执行器恢复时查已有收据，最终只有一笔 10 单位提交。不兼容节点、缺字段、工具版本变更和权限撤销均在提交前拒绝。它不恢复任意 Python 调用栈，也不实现分布式租约。

缓存实验用实际字典和确定性计算指纹：同 token、不同 adapter、忽略版本时会错误返回旧值；加入可信身份与版本后拒绝错误复用。合成代价 1/5 只说明可观察信号，不能作为攻击率或性能数字。cache salt 不提供完整进程隔离。
