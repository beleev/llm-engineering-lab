# 按研究方向长图交叉检查知识覆盖

检查日期：2026-11-08。仓库基线：`1658f58b63beb93e37ec14fe3f2f6b4769fda34d`。来源是用户提供、开头标注 2026/08/25 的长图（1348 × 43840）；图片摘要及逐项证据存于 [机器可读清单](image-knowledge-audit.json)。来源日期只用于识别图片，不把图片当成权威或实时研究结论。

结论：**仍有知识缺口，但不能把“已讲到的基础机制”和“完整研究方向”混成一个完成度。** 原有模型、训练、微调、推理、Agent 主线有较多可运行实验；缺口集中在数据学习策略、置信校准、参数知识编辑、隐私与遗忘、机制解释、端侧约束，以及多模态/专业领域的任务级方法。

这次按图中 45 个非 Summary 二级主题核对：16 项“核心有闭环”，26 项“部分覆盖”，3 项“未见系统覆盖”。**这不是 16/45 的课程完成率，也不意味着只有 3 个知识点缺失。** 每个主题大小不同，部分覆盖的主题内部同样有明确空白；例如“知识编辑与幻觉缓解”中的幻觉缓解已有机制，但参数知识编辑仍缺失。图中 Scaling Laws 位于第一部分导言，单独核对后并入 1.1，未漏掉。

## 判断口径

- **核心有闭环**：主要机制已有讲义、可执行实现及断言/对照设计；不承诺完整论文、真实数据泛化或生产实现。
- **部分覆盖**：有相关讲解或实验，但重要子知识点缺失、只有一句介绍，或只有架构没有任务级方法。
- **未见系统覆盖**：检索中英文及常见别名，并复核邻近模块后，没有找到成体系内容。证据栏列出最接近的已有内容，不将其冒充覆盖证据。

范围包含六个 Python 包的讲义和代码、Web 正文/术语/自测/实验映射，以及运行中的目录入口。检索命中后检查语义，避免 `got` 局部变量被误当 GoT、MoE 路由坍塌被误当合成数据 model collapse、量化校准被误当回答置信校准。未以目录数量、关键词命中数量或 ai-agent-book 标题映射代替内容判断。

“补充/边界”一栏同时保留知识缺口和实现深度限制：前者是后续课程扩充候选，后者不应一律变成新增模块。

## 对上一轮初查的修正

1. **持续预训练与遗忘并非空白**：[m37](../llm_agent/m37_midtraining/README.md) 继续训练全部 next-token 位置，真实更新小 LLaMA 权重，并比较旧域保持。此次复跑：base 旧域/新域为 100%/0%；domain-only 为 0%/100%；replay 为 100%/100%。这是固定符号映射，不代表真实领域泛化。缺的是课程学习、主动选择及更广的数据实验，而不是重新建一个持续预训练模块。
2. **合成数据不是全无**：m25、RLAIF、RFT 已有生成/筛选机制；缺的是递归使用生成数据的分布退化、长尾保持与混合比例实验。
3. **OPD、Mamba、PRM、测试时计算已覆盖**，无需仅因长图再次出现就新增重复章节。
4. **世界模型已有概念和控制邻近实验**：m36 是给定的一维动力学；没有训练世界模型。应记“部分”，不能记“完全没有”或“已经完整”。
